# Fantasy V4 original short SFX

Five synthesized, royalty-free original sound cues produced for Project E using deterministic sine tones and noise envelopes (no sampled copyrighted material).

- slash.wav — Bas gauntlet strike and fire-cast
- arcane.wav — Rio enchanted disk
- nature.wav — Nema forest binding
- hit.wav — locally controlled hero receives damage
- level.wav — locally controlled hero gains a level

16 kHz / 16-bit PCM / mono, duration 0.18–0.36 seconds. Loaded in `scripts/presentation/fantasy_audio.gd` using `AudioStreamPlayer`; no external libraries and no remote requests. Observe only your own hero; hidden enemies never trigger cues. The F7 inspection stage remains muted.
