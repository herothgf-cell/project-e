# Project E Korean font

`ProjectEKorean.woff2` is a Korean/Latin/UI-symbol subset of **Noto Sans CJK KR Regular**, bundled so Korean game text renders without relying on an installed Windows or Linux font.

- Original: [Noto CJK Sans](https://github.com/notofonts/noto-cjk/tree/main/Sans).
- Original file: `Sans/OTF/Korean/NotoSansCJKkr-Regular.otf`.
- Original copyright: © 2014–2021 Adobe (http://www.adobe.com/).
- License: SIL Open Font License 1.1; the complete, unmodified license is in [OFL.txt](OFL.txt).
- Modification on 2026-10-26: fontTools subset retaining Basic Latin, Hangul syllables and Jamo, general punctuation, arrows and geometric symbols; font family renamed **Project E Korean**. No letter outlines were redrawn. The subset is losslessly stored in WOFF2 format.

This covers every Hangul syllable, not only the current UI strings. A future localization into other scripts needs its own font coverage. Keep this notice and OFL.txt with source distributions and exported builds.
