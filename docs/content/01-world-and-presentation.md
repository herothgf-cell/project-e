# 세계관과 표현 방향

- 버전/작성일: v0.1 / 2026-10-21
- 상태: 검토 가능한 창작 제안. 명칭·서사·색·제작 수량은 확정 브랜드나 구현 결과가 아니다.
- 범위: 경기의 맥락, 시각·소리의 문법, 초기 콘텐츠의 제작 기준을 정한다.
- 관련: [프로젝트 개요](../00-project-brief.md), [공통 규칙](../01-core-rules.md), [맵](02-arena-and-objectives.md), [영웅 목록](../characters/README.md), [콘텐츠 매트릭스](../03-content-matrix.md)
- 사용 방법: 게임 판정은 공통 규칙, 개별 기술은 영웅 문서가 우선한다. 이 문서의 연출은 판정을 바꾸지 않는다.

## 1. 유지할 경험과 새로 만들 정체성

| 구분 | 이번 설계의 기준 |
|---|---|
| 사용자 확정 | 독립 PC 게임, Steam 출시 목표, 핵심 재미 유지, 기존 작품과 구별되는 정체성 |
| 이번 설계의 기준 | 빠른 3대3·세 라인 전투와 가까운 라인 지원 |
| 이번 설계의 기준 | 경기 중 능력치 성장, 병력과 함께 결정하는 공성 |
| 독자 설계 제안 | 원소 공학을 다루는 공방 길드, 수로·도자기·구리·천의 밝은 경기장 |
| 독자 설계 제안 | 바스의 돌파, 리오의 회수 궤적, 네마의 연결 장치라는 서로 다른 조작 주제 |
| 초기 제작 원칙 | 캐릭터 실루엣과 위험 영역을 먼저 읽고, 장식과 설정은 그다음 읽는다. |
| 제외 범위 | 기존 작품의 영웅·맵·고유 대사·유닛 외형·음악을 재현하는 작업 |

세계는 생활 설비를 수리하고 정원을 유지하는 공방들의 연합으로 제안한다.
원소 에너지는 기계와 공예품을 움직이는 재료이며, 피나 육체 훼손을 대신하는 전투 효과의 근거다.
경기는 세 명의 작업자가 상대 설비의 출력을 멈추는 정식 검증 행사다.
승리의 핵심은 여전히 상대 핵 파괴이며, 설정을 이유로 별도 퍼즐·점령 점수·날씨 효과를 추가하지 않는다.
길드의 경쟁은 기술과 협업을 겨루는 일이다. 전투 전 세계의 위기나 긴 배경 이야기를 알아야 할 필요는 없다.
Project E, 수로 공방, 바스·리오·네마는 작업용 명칭이며 전 세계의 명칭 중복이나 상표 검토를 마쳤다는 뜻이 아니다.

## 2. 경기장에서 일어나는 일

수로 공방은 물을 공급하는 본 설비 옆에 마련된 시험용 경기 구역이다.
두 팀은 같은 규격의 보조 병력과 방어 설비를 받아 상대의 공명핵을 정지시킨다.
물은 배경 수로와 노출된 관을 흐르지만 미끄러짐·유속·도하 피해를 만들지 않는다.
병력은 작은 운반·수리 기계이며, 파괴될 때 외피가 분리되고 에너지가 흩어지는 모습으로 표현한다.
영웅의 사망은 장비가 안전 정지되어 기지에서 재정비되는 사건으로 해석한다.
재정비 연출은 실제 사망·부활 시간과 일치하며, 설정상의 구조 장면 때문에 조작 복귀를 늦추지 않는다.
공명핵 파괴는 큰 폭발 대신 중심 링이 멈추고 밝은 에너지가 가라앉는 형태로 제안한다.
관중·길드 표식·정원 도구는 맵 가장자리에 두어 전장 안에서 적 유닛처럼 보이지 않게 한다.
영구적인 영웅 강화는 서사에도 넣지 않는다. 다음 경기에서는 모두 동일한 시작 상태로 돌아간다.

## 3. 명칭과 표현의 대응

| 게임 용어 | 세계 안의 의미 | 플레이어에게 보여 줄 표현 |
|---|---|---|
| 영웅 | 길드의 현장 작업자 | 선택 화면에서는 영웅, 대사에서는 작업자라는 표현 사용 가능 |
| 위력 | 장비의 출력 조율 | 수치 패널은 반드시 위력으로 통일 |
| 에너지 | 장비가 소비하는 원소 동력 | 파란 막대와 에너지라는 이름을 함께 사용 |
| 성장 포인트 | 경기 중 허용된 조율 기회 | 경험치·크레딧과 다른 아이콘을 사용 |
| 크레딧 | 경기용 수리 물자의 구매 한도 | 실제 통화·계정 재화처럼 연출하지 않음 |
| 근접/원거리/공성 병력 | 세 종류의 보조 기계 | 역할 이름을 이름 앞에 표시 |
| 경험치 셀 | 시험 구역의 작은 축전 부품 | 셀 파괴 보상만 있으며 점령 상태는 없음 |
| 외곽/내곽 방어탑 | 설비 접근을 제한하는 안전 장치 | 외곽·내곽의 단계와 보호 상태를 강조 |
| 공명핵 | 팀의 주 분배 장치 | 핵 파괴가 승리 조건이라는 문장을 유지 |
| 수리 패치 | 임시 자가 수리 자재 | HP 회복량과 적 영웅 피해 시 중단을 함께 표시 |

설정 용어를 기술 설명의 조건문 대신 쓰지 않는다. ‘과열’ 같은 말이 실제 상태 이상이 아니라면 상태 아이콘을 만들지 않는다.
한국어 원문에서 하나의 판정을 여러 동의어로 바꾸지 않으며, 영어 현지화 키는 ID로 연결한다.

## 4. 세 영웅의 미술 축

| 영웅 | 먼 거리 실루엣 | 재료와 움직임 | 표현할 전투 판단 |
|---|---|---|---|
| C01 바스 | 낮고 넓은 몸, 큰 압착 장갑 | 도자기 외피와 구리 경첩, 무게를 싣는 짧은 동작 | 언제 앞으로 나가고 언제 아군 병력을 기다릴지 |
| C02 리오 | 가는 몸, 길게 늘어진 천 끝, 원반 | 목재·얇은 구리, 몸과 원반의 분리된 궤적 | 나가는 방향과 돌아오는 경로를 어떻게 맞출지 |
| C03 네마 | 중간 높이 배낭과 두 개의 접이식 핀 | 세라믹 연결 핀, 명확한 설치·접기 동작 | 장치의 위치와 연결이 어느 공간을 바꾸는지 |

머리 장식이나 무기의 크기만으로 팀을 구분하지 않는다. 팀은 별도의 윤곽·기호로 표시한다.
영웅의 몸색은 능력의 위험도나 팀 구분을 대신하지 않는다.
바스의 큰 모델도 지면 충돌 반경은 다른 영웅과 같은 0.45m다.
리오의 긴 천과 네마의 연결선은 몸의 피격 판정처럼 오해되지 않도록 발밑 기준점을 유지한다.
초기 세 영웅의 세부 과거와 관계는 짧은 소개문 범위로 두고, 플레이에 필요한 역할과 성격부터 제작한다.
기술 이름·효과·구체 수치는 [개별 영웅 문서](../characters/README.md)를 따른다.

## 5. 수로 공방의 지역별 미술

| 지역 | 배경 제안 | 전투 바닥의 기준 |
|---|---|---|
| 북쪽 N | 열린 온실 선반, 낮은 수로 덮개, 밝은 석재 | 가로 진행 방향을 읽을 수 있는 넓은 줄눈 |
| 중앙 C | 조립 작업대 주변의 넓은 운반 통로 | 가장 단순한 바닥, 화면 중앙 교전의 대비 확보 |
| 남쪽 S | 건조대, 천막 가장자리, 구리 배수관 | 북쪽과 다른 장식 묶음, 같은 전투 대비 |
| 라인 연결로 | 낮은 정원 벽 사이의 작업 통로 | 양 끝이 보이는 일관된 폭과 명확한 출입구 |
| 기지 | 재정비 발판과 상점 작업대 | 상점·회복 구역 경계를 지속적으로 표시 |
| 외곽 배경 | 물 저장조와 정원, 정지된 크레인 | 조작 가능 지면과 구분하고 클릭 유도를 피함 |

맵의 이동·시야 차단은 [맵 문서의 지면과 차단체](02-arena-and-objectives.md)만 결정한다.
낮은 화단, 그림자, 물 표면의 반짝임은 추가 이동 방해나 시야 가림을 만들지 않는다.
배경의 세로 부재는 캐릭터가 뒤에 있을 때 투명화하되, 실제 시야 차단 벽의 경계선은 남긴다.
높이 차이를 그려도 초기 맵에는 고지대 명중 보정이나 낙하 경로가 없다.

## 6. 화면에서 먼저 읽혀야 하는 것

1. 나와 아군·적군의 위치, 현재 조작 대상과 이동 목적지.
2. 피해가 발생할 영역, 방향, 남은 경고 시간.
3. HP·에너지, 상태 이상, 타워의 현재 공격 대상.
4. 라인 병력의 접근, 구조물 보호, 연결로의 입구.
5. 재료 질감, 장식, 세계관 소품.

색상 제안은 아군 청록, 적군 주황이지만 색상 모드별 대체 팔레트를 함께 둔다.
아군 위험 영역은 얇은 연속 테두리, 적군 위험 영역은 두꺼운 끊긴 테두리와 삼각 표식을 사용한다.
팀 표시는 색과 기호를 함께 쓰며 적록 구분만으로 판정을 전달하지 않는다.
바닥 기술은 실제 판정 경계 안에 불투명 질감을 쌓지 않고 바깥 윤곽과 진행 방향을 강조한다.
동시 경고가 겹치면 적군 경고 윤곽을 위에 표시하되 아군 기술의 위치도 가는 선으로 남긴다.
캐릭터의 발밑 원, 투사체 중심선, 구조물의 피격 외곽은 미술 크기가 바뀌어도 판정과 맞춘다.

## 7. 효과와 소리의 작성 규칙

| 단계 | 필수 정보 | 제작 금지 사항 |
|---|---|---|
| 시전 전 | 실제 선딜과 같은 길이의 경고, 범위·방향·종료 시점 | 장식 때문에 실제보다 일찍 사라지는 경고 |
| 발사/활성 | 진행 방향, 실제 폭, 남은 설치 영역 | 피격되지 않는 영역을 같은 밝기로 채우기 |
| 적중 | 보이는 대상의 짧은 반응, 피해·보호막 구분 | 안개 속 적중 음향이나 숫자로 적 위치 노출 |
| 종료 | 피해 판정 종료와 같은 시점의 윤곽 제거 | 잔광 때문에 위험이 남았다고 오해하게 만들기 |
| 제어 효과 | 기절/속박의 다른 아이콘과 짧은 상태 문구 | 둘을 같은 얼어붙은 포즈로만 표현하기 |

장식 잔광은 남길 수 있지만 채도를 낮추고 판정 외곽선과 분리한다.
리오의 원반은 나가는 단계와 돌아오는 단계를 화살표 방향으로 구분한다.
네마의 연결선은 실제 유효 연결과 끊어진 장식을 다른 선 모양으로 표시한다.
타워 공격 준비는 표적 연결선과 반복 간격으로 알려 주고, 영웅 우선 공격 전환은 짧은 경고음을 더한다.
사운드는 타격의 무게와 방향 감각을 돕되, 보이지 않는 적의 정확한 좌표를 제공하지 않는다.
핵 노출·구조물 파괴·경기 종료는 공개 경기 상태로 안내하고, 안개 속 일반 타격 알림과 분리한다.
음성 대사는 비전투 소개와 짧은 반응 위주로 두며, 교전 중 핵심 경고음을 덮지 않게 한다.
효과음 동시 재생 수가 초과하면 장식·반복 발자국을 먼저 줄이고 경고음은 보존한다.

## 8. 초기 제작 예산 제안

아래 수량은 초기 3종과 맵 1개의 제작 견적을 위한 가설이다. 성능 측정 결과를 대신하지 않는다.

| 묶음 | 초기 제작 단위 | 제안 예산 |
|---|---|---|
| 영웅 모델 | 각 1개, 무기·가방은 재사용 가능한 분리 부품 | 영웅당 LOD0 8천–1.2만 삼각형, 재질 2개 이하 |
| 영웅 텍스처 | 컬러·노멀·마스크 묶음 | 영웅당 1,024 정사각 아틀라스 1세트부터 시작 |
| 영웅 애니메이션 | 대기·이동·공격·피격·사망·부활·시전 동작 | 공통 6개와 기술별 최대 4개, 영웅당 약 10개 |
| 영웅 UI | 초상, 패시브와 Q/W/E/R, 선택 카드 | 영웅당 초상 1·능력 아이콘 5·역할 기호 1 |
| 기술 효과 | 경고·활성·적중·종료를 하나의 작성 묶음으로 관리 | 일반기 9·특수기 3·패시브 3, 공통 재질 재사용 |
| 병력 | 근접·원거리·공성 3개 기본 모델 | 모델당 1.5천–3천 삼각형, 팀별 외피 복제 금지 |
| 구조물 | 외곽탑·내곽탑·핵의 3개 기본 모델 | 종류당 5천–8천 삼각형, 팀 표식만 교체 |
| 셀/소모품 | 셀 1종, 에너지 병·수리 패치 2종 | 셀 상태 2개, 소모품 아이콘 2개 |
| 맵 모듈 | 바닥·턱·벽·수로·정원 소품 | 기능 모듈 16개 안팎, 장식 소품 12개 안팎 |
| 공통 UI | 성장 6선택, 보호·잠금·상태·핑 | 아이콘 약 24개, 재사용 버튼·패널 규격 1세트 |

맵 전체의 새 텍스처보다 타일 재질 6종과 소품 아틀라스 2세트를 우선 사용한다.
성능 스트레스 장면은 영웅 6·병력 96·방어탑 12·핵 2·셀 6·네마 장치 4개를 기본 묶음으로 제안한다.
병력 96은 생성 제한이 아니라 측정 장면의 수량이다. 실제 병력의 생존을 임의로 잘라 성능을 맞추지 않는다.
동시 장식 이펙트 48개·입자 2,400개부터 예산을 시작하고, 경고 도형·투사체·게임 판정은 감축 대상에서 제외한다.
이 숫자로 특정 PC에서 60fps가 보장된다고 적지 않는다. 실제 목표 사양과 측정 기록은 기술 문서와 M5에서 확정한다.

## 9. 문장·현지화·접근성

- 기술 설명은 행동, 범위, 자원, 재사용 대기, 예외 순서로 쓰고 실제 값을 자동으로 삽입할 수 있는 키를 둔다.
- 한국어를 기준으로 제작하되 출시 후보에는 영어 UI 길이와 줄바꿈을 검수하는 절차를 포함한다.
- 1,920×1,080 화면의 본문 18px 이상을 초기 가설로 삼고, 배율 80–140%에서 잘림을 확인한다.
- 팀 색상 변경, 카메라 흔들림 끄기, 번쩍임 줄이기, 피해 숫자 크기 조절을 제안한다.
- 음성을 꺼도 핵심 경고를 볼 수 있어야 하며, 소리를 들을 수 없어도 필수 튜토리얼을 완료할 수 있어야 한다.
- 숨겨진 키 입력 없이 현재 역할·현재 성장 선택·공성 보호 이유를 화면에서 읽을 수 있어야 한다.
- 플레이어 비난, 승패의 원인을 한 명에게 돌리는 자동 대사, 처치 수만 강조하는 승리 연출은 넣지 않는다.

## 10. 제작과 검수의 통과 기준

| 단계 | 확인할 결과 | 통과 조건 제안 |
|---|---|---|
| M1 회색 상자 | 영웅·적·위험 영역 식별 | 재질 없이도 기술 방향과 피격 외곽을 구분 |
| M2 전체 경기 | 병력과 구조물의 역할 | 외곽/내곽·잠금/병력 보호를 플레이 중 설명 가능 |
| M3 사람 6명 | 동시 교전의 가독성 | 세 영웅의 위치와 적군 위험 경계를 영상으로 판독 |
| M4 확장 후보 | 추가 영웅의 외형 차별 | 기존 3종과 실루엣·주요 효과 문법이 겹치지 않음 |
| M5 출시 후보 | 효과·번역·성능의 동시 검수 | 실제 사양 측정과 한국어/영어 UI 검수 기록 보유 |

초기 3종에 이 기준이 적용되기 전에는 장식 스킨이나 두 번째 맵 제작을 시작하지 않는다.
읽기 어려운 효과는 색을 더 강하게 만드는 방식보다 범위·단계·실루엣을 먼저 수정한다.
설정이 공통 규칙을 설명하기 어렵게 만들면 설정을 바꾼다. 경기 규칙을 숨기는 서사적 예외는 만들지 않는다.
