# 모드·온보딩·경기 화면

- 버전/작성일: v0.1 / 2026-10-21
- 상태: 화면과 상호작용의 설계 제안. UI 이미지·게임 화면·실행 코드는 아직 없다.
- 범위: 연습장, 튜토리얼, 봇 연습, 비공개 3대3, 선택부터 결과까지의 화면과 안내.
- 관련: [공통 규칙](../01-core-rules.md), [영웅 목록](../characters/README.md), [맵](02-arena-and-objectives.md), [경제](03-minions-and-economy.md), [개발 로드맵](../02-development-roadmap.md)
- 이번 설계의 기준: 빠른 3대3 전투와 즉시 지원, 경기 중 성장과 공성을 익히게 한다.
- 제안과 경계: 아래 시간·문구·화면 구성은 검증값이다. 계정 강화·랭크·배틀패스·새 대전 규칙을 추가하지 않는다.

## 1. 초기 모드 구성

| 모드 | 사용 목적 | 플레이 범위 | 우선 단계 |
|---|---|---|---|
| 연습장 | 조작과 영웅 기술을 제한 없이 확인 | 1인, 타깃·타워·짧은 병력 경로, 초기화 가능 | M1 진단 장면에서 발전 |
| 기본 튜토리얼 | 이동·지원·성장·공성의 연결을 학습 | 수로 공방의 순서형 과제, 저장되는 것은 진행 여부뿐 | M3 |
| 영웅 연습 | 바스·리오·네마의 서로 다른 판단을 학습 | 세 개의 짧은 역할 과제, 반복 가능 | M3 |
| 봇 연습 | 완전한 한 경기의 흐름을 안전하게 반복 | M01 3대3, 빈 자리를 봇으로 채움 | M2 |
| 비공개 방 | 초대받은 6명과 규칙을 공유해 테스트 | M01 3대3, 사람·봇 합계 팀당 3자리 | M2→M3 |

출시 후보는 맵 1개와 영웅 6종을 목표로 하지만, 초기 플레이 가능한 범위는 영웅 3종이다.
공개 대기열은 M4–M5의 접속 품질·동시 접속자 검증을 통과할 때 결정한다. UI에 당장 동작하지 않는 매칭 버튼을 노출하지 않는다.
랭크·경쟁 등급·계정 능력치·장비 수집을 모드의 재방문 동기로 쓰지 않는다.
튜토리얼을 건너뛸 수 있으며 영웅이나 능력치를 잠가 완료를 강요하지 않는다.

## 2. 화면별 목적과 이동

| 화면 | 주요 정보 | 주요 행동 | 실패·경계 처리 |
|---|---|---|---|
| 최초 실행 | 언어, 표시 배율, 기본 조작, 접근성 | 설정 적용, 튜토리얼 또는 홈 | 설정은 이후에도 변경 가능 |
| 홈 | 연습·봇 연습·비공개 방, 최근 튜토리얼 단계 | 바로 시작, 방 만들기/참가 | 네트워크 실패 시 로컬 연습 경로 유지 |
| 방 목록/참가 | 방 이름, 인원, 지역/지연 표시, 데이터 버전 | 코드 또는 초대로 참가 | 버전 불일치·가득 참·방 종료를 다른 문구로 안내 |
| 비공개 대기실 | 팀별 3자리, 사람/봇, 연결 상태, 현재 규칙 | 팀 변경, 봇 추가, 준비 | 모든 사람의 준비와 여섯 자리 충족 후 시작 |
| 영웅 선택 | 역할·조작 주제·패시브·일반기·특수기 개요·팀 선택 | 팀 내 중복 없는 영웅 선택 | 상대와 같은 영웅은 허용, 중복 선택은 즉시 설명 |
| 준비 | 양 팀 구성, 기본 키, 라인 출발 선택 | 성장 2포인트·상점·경로 확인 | 준비 중 접속 실패는 경기 시작 전 방으로 복귀 |
| 경기 | 전장·핵심 HUD·미니맵 | 이동·공격·성장·지원·구매 | 실패 이유는 가까운 짧은 문구로 제공 |
| 사망 대기 | 부활 시간·죽은 이유·현재 전장 | 아군 시점, 성장 투자 | 소모품 사용·상점 구매는 차단 |
| 결과 | 승리/패배/무승부/세션 중단 | 같은 방 복귀, 영웅 연습, 홈 | 중단을 패배나 승리로 기록하지 않음 |

선택 60초, 준비 15초를 첫 가설로 제안한다. 모든 사람이 준비를 마치면 선택 단계를 단축할 수 있다.
선택 제한 시간이 끝나면 같은 팀의 미선택 영웅을 정해진 순서로 배정하고 배정 사실을 알린다.
준비 15초에는 출발지 밖 이동과 적대 행동을 막고 성장·상점·경로 확인만 허용한다. 시작 신호와 함께 이동을 연다.
준비 타이머가 끝난 뒤 경기 시간 0초를 시작한다. 병력 첫 생성 20초·셀 첫 생성 30초는 이 시계를 따른다.
비공개 방장은 봇·팀 배치·시작을 관리하지만 경기 중 능력치나 승패를 임의로 바꾸지 못한다.
출시 전 개발용 진단 기능은 일반 방 옵션으로 노출하지 않는다.

## 3. 기본 튜토리얼의 순서

전체 8–12분을 초기 학습 시간 가설로 삼고, 속도 시험보다 각 행동의 이유를 설명하는 데 집중한다.
바스로 공통 조작을 익힌 뒤 리오·네마 역할 과제로 이어진다. 어느 단계든 다시 시작하거나 연습장으로 나갈 수 있다.

| 단계 | 화면 지시와 실제 행동 | 성공 확인 | 가르치는 판단 |
|---|---|---|---|
| T01 이동·표적 | 우클릭으로 두 지점 이동 후 보이는 타깃 기본 공격 | 이동과 공격 커서의 차이를 확인 | 땅을 누르는 것과 적을 누르는 것은 다른 명령 |
| T02 세 일반기 | 바스 Q/W/E의 사거리·경고를 보고 각 한 번 사용 | 피해·자원·쿨타임 변화를 확인 | 처음부터 세 기술을 쓰되 동시에 낭비하지 않기 |
| T03 최초 성장 | 체력 1·방어 1 추천을 보고 시작 포인트 2개 투자, 다른 선택도 허용 | 실제 수치와 남은 포인트 확인 | XP·포인트·크레딧을 구분 |
| T04 라인 보상 | 병력을 함께 처치하고 봇이 막타를 치는 사례 비교 | 직접 막타 없이 XP를 받고, 막타에는 추가 크레딧 확인 | 기본 보상 공유와 막타 추가 보상 |
| T05 인접 지원 | 중앙 출입점에서 북쪽의 아군에게 이동 | 기준 출입점 사이 이동 시간을 보여 줌 | 가까운 지원 뒤 원래 라인 상태를 확인 |
| T06 셀 선택 | 측면 셀을 깨고 미니맵으로 라인 병력 확인 | XP·크레딧과 45초 재생성 조건 설명 | 작은 보상을 위해 라인에서 빠지는 비용 |
| T07 R 해금 | 진단용 XP로 레벨 3에 도달하고 포인트 1개 투자 | 잠긴 R이 사용 가능해짐 | 레벨 3 도달과 R 투자라는 두 조건 |
| T08 기지와 소모품 | 기지 이동, 병 또는 패치 구매, 부족 자원에서 D 사용 | 합산 2개·공유 12초 쿨타임을 확인 | 자원이 부족할 때 남을지 귀환할지 |
| T09 공성 보호 | 병력 없이 타워 한 번 타격 후 병력과 함께 재시도 | 방패 표식과 피해 차이 확인 | 장치보다 라인 병력이 공성 보호를 해제 |
| T10 승리 경로 | 같은 라인 외곽·내곽 파괴 후 핵 공격 | 잠금 해제와 핵 파괴로 종료 | 모든 라인을 밀지 않아도 승리 경로가 열림 |

T05는 기준 위치에서의 약 3.5–3.7초를 보여 주며, 이동 경로를 배우는 동안 5초를 넘겼다고 실패시키지 않는다.
T07의 진단용 XP 지급은 튜토리얼에만 존재하며 일반 경기의 보상량을 바꾸지 않는다.
T08에서 이미 자원이 가득 찼으면 테스트 타깃이 자원을 소모시킨 뒤 안내한다. 아이템이 소모되지 않는 이유를 숨기지 않는다.
T09에서는 무적 잠금과 병력 부재 보호를 다른 상태로 보여 주고, 두 조건을 한 번에 바꾸지 않는다.
튜토리얼에서 죽으면 마지막 학습 단계로 돌아가며, 진행 실패에 계정 재화 비용을 붙이지 않는다.

## 4. 세 영웅을 구분해 가르치기

| 역할 과제 | 장면 구성 | 성공과 재시도 | 상대법도 함께 설명 |
|---|---|---|---|
| 바스: 진입과 철수 | 아군 병력 뒤에서 시작, 앞의 적과 적 타워를 함께 배치 | 적을 견제하고 타워의 영웅 공격 표식을 보면 빠져나오기 | 먼저 들어온 바스를 옆으로 피하고 후퇴 경로를 압박 |
| 리오: 나감과 돌아옴 | 직선 타깃 하나, 옆으로 움직이는 타깃 하나, 돌아오는 원반 궤적 표시 | 회수 경로를 바꾸어 두 단계의 차이를 관찰 | 원반만 따라가지 않고 리오와 귀환 방향을 함께 보기 |
| 네마: 두 장치의 공간 | 연결 핀을 놓을 두 유효 지점, 연결 범위 바깥의 이동 타깃 | 장치 배치·연결 경계·위치 변경의 결과를 확인 | 연결이 실제로 닿는 공간 밖으로 움직이거나 장치 대응 |

각 역할 과제는 60–90초를 첫 가설로 삼고, 개별 기술의 이름·타이밍·피해는 영웅 문서와 같은 데이터를 사용한다.
바스 과제는 Q로 병력을 정리한 뒤 영웅 타깃에 Q/E로 압력을 쌓고, 기본 공격으로 보호막을 얻은 다음 W로 아군을 보호하는 순서다.
리오 과제는 Q 왕복 적중, 첫 타격 뒤 옆걸음 회피, Q 출발 중 E 이동, W 회수점 지정, R 삼각형 내부 안전지대 확인을 순서대로 수행한다.
네마 과제는 Q 두 번 설치, 선 통과 보호막, W 발동, 적 시점에서 핀 두 번 공격, R의 핀 소비, 장치 없이 E로 아군 보호를 차례로 보여 준다.
R 단계는 연습장용 레벨 3·R 투자 상태를 명시하고 제공한다. 이 편의 설정은 실제 경기의 해금 조건을 바꾸지 않는다.
바스에게 ‘계속 맞아 주기’, 리오에게 ‘가만히 기본 공격’, 네마에게 ‘아군 뒤에서 관전’을 역할이라고 가르치지 않는다.
바스는 교전을 여는 시점, 리오는 기하와 이동, 네마는 설치 위치라는 서로 다른 판단을 먼저 보여 준다.
기절 타깃에서는 이동·시전이 모두 막히고 속박 타깃에서는 제자리 기술이 가능한 차이를 직접 확인하게 한다.
연속 제어는 최근 3초에 최대 1.5초라는 공통 한도가 있음을 짧은 게이지로 보여 주고, 무한 제어 콤보를 추천하지 않는다.
세 과제 뒤에는 ‘모든 역할을 숙련했다’ 대신 완료한 행동과 다시 연습할 기술을 표시한다.

## 5. 연습장과 봇의 범위

연습장은 영웅 변경, 레벨 1–12, 성장 초기화, 쿨타임 초기화, 타깃 HP·방어 0/10/20 설정을 제공한다.
타깃은 정지·좌우 이동·기본 공격 세 유형을 제안하고, 실제 기술 경계와 피해 기록을 확인할 수 있게 한다.
일반 연습 모드와 개발용 진단 정보는 구분하며, 보통 플레이어에게 서버 틱이나 내부 객체 ID를 필수 설명으로 노출하지 않는다.
연습장 설정은 실제 3대3으로 이어지지 않는다. 방 입장 시 모든 경기 자원이 표준 시작값으로 초기화된다.
봇 연습은 사람 1–6명과 봇을 섞을 수 있지만, 양 팀 모두 사람·봇 합계 3자리로 시작한다.
봇도 동일한 시야·쿨타임·성장·상점·피해 규칙을 지키고, 안개 속 상대 좌표를 읽지 않는다.
쉬운 봇의 반응 지연 650ms, 일반 봇 350ms를 첫 가설로 삼고 인간에게 없는 조준 정확도를 주지 않는다.
봇의 우선 행동은 핵 방어, 가까운 아군 지원, 자기 라인 병력 유지, 안전한 공성, 여유 있는 셀 순서로 제안한다.
HP 30% 이하이고 즉시 핵 방어가 필요하지 않으면 후퇴·기지 회복을 우선하는 시작 규칙을 둔다.
성장 추천과 R 해금은 영웅별 기본 계획을 사용하되 인간과 같은 포인트를 소비한다. 소모품은 기지에서만 산다.
봇의 목적은 학습과 빈자리 유지다. 봇전 승률이 인간 대전의 재미나 공정성을 검증했다고 보지 않는다.

## 6. 경기 HUD

| 위치 | 표시 내용 | 상호작용과 제한 |
|---|---|---|
| 화면 위 | 경기 시간, 양 팀 핵 상태, 구조물 파괴 알림 | 핵 잠금/노출은 공개 상태, 강제 종료 타이머 없음 |
| 영웅 근처 | HP·보호막·짧은 상태 표시·이동 목적지 | 적 정보는 시야 규칙을 따르고 발밑 판정을 가리지 않음 |
| 화면 아래 | HP·에너지, 패시브, Q/W/E/R, 실제 쿨타임 | R 잠금 이유와 에너지 부족을 서로 다른 표시로 안내 |
| 소모품 영역 | 두 개 보유칸, 현재 선택, 공유 쿨타임, 크레딧 | D는 선택한 것 한 개 사용, 슬롯 클릭/선택 키로 전환 |
| 성장 영역 | 레벨·XP·미사용 포인트·추천 이유 | 전투 중에도 닫을 수 있는 작은 패널, 자동 투자 기본 꺼짐 |
| 미니맵 | N/C/S, 타워·핵·관측한 유닛, 팀 핑 | 보이지 않는 적을 유지 추적하지 않음 |
| 팀 상태 | 아군 HP·레벨·부활·연결 상태 | 아군 영웅 선택 시 화면 이동, 적의 숨은 기술 정보는 없음 |

상대 구조물의 파괴·핵 노출은 공개하지만, 보이지 않는 적 체력이나 셀 상태의 변화를 실시간으로 흘려주지 않는다.
적 구조물 HP는 관측한 마지막 값임을 표시하고, 아군 구조물 HP는 팀 상태로 공유한다.
타워의 잠금은 자물쇠, 병력 부재 보호는 방패로 표시하며 ‘아군 병력 12m 안 필요’라는 짧은 설명을 제공한다.
받은 피해의 원인·상태 이상·부활 시간은 사망 패널에 남기되 안개 속 적의 현재 위치를 추가로 보여 주지 않는다.
성장 패널은 상한에 도달한 선택을 비활성화하고, 포인트 소비 전후의 실제 변화량을 보여 준다.
구매 실패는 금액 부족·보유 2개·구역 밖·사망 상태를 구분한다. 작은 버튼 색 변화만으로 이유를 전달하지 않는다.

## 7. 입력·알림·접근성

우클릭 이동/기본 공격, Q/W/E 일반기, R 특수기, D 소모품은 공통 규칙을 따른다.
추가 키 제안은 G 팀 핑, B 상점, V 소모품 선택 순환, U 성장 패널, T 겹친 표적 순환, Tab 팀 현황이며 모든 키를 다시 지정할 수 있다.
표적에는 사전 선택 윤곽을 제공하고 겹친 적의 우선순위는 [공통 클릭 규칙](../characters/README.md)을 따른다. T로 핀 등 뒤에 겹친 표적을 고를 수 있다.
B는 기지 안에서 상점을 여는 키다. 맵 어디서든 기지로 이동하는 귀환이나 순간이동을 뜻하지 않는다.
기본 시전은 키 입력 후 지점 지정이며 빠른 시전은 옵션이다. 사거리 밖 클릭 시 이동 시전 대신 실패 이유를 표시한다.
핑은 ‘지원 요청·공격·후퇴’ 세 종류로 시작하고 지면 또는 미니맵에 둘 수 있다.
한 플레이어의 일반 핑은 0.5초 간격·5초당 4회로 제한하는 가설을 두되 시스템의 핵 노출 알림을 막지 않는다.

| 안내 상황 | 문구 제안 | 우선순위 |
|---|---|---|
| 인접 지원 요청 | ‘북쪽 지원 요청’과 출입구 방향 | 일반 핑, 반복 축약 |
| 레벨·포인트 | ‘성장 포인트 +1’ | 전투를 가리지 않는 짧은 강조 |
| R 사용 실패 | ‘레벨 3 및 성장 포인트 1개로 해금’ | 해당 슬롯 근처 |
| 내곽 잠금 | ‘이 라인의 외곽탑을 먼저 파괴하세요’ | 표적 구조물 근처 |
| 병력 부재 | ‘라인 병력 없이 구조물 피해 30%’ | 방패 아이콘과 함께 |
| 핵 노출 | ‘상대 핵의 잠금이 해제되었습니다’ | 팀 전체 공개 알림 |
| 연결 불안정 | ‘연결 복구 중 · 5초 후 봇 제어’ | 화면 고정 영역 |

경고의 중요도는 색만이 아니라 기호·위치·문장으로 전달한다. 화면 흔들림과 장식 번쩍임을 줄일 수 있게 한다.
한국어/영어, 배율 80–140%, 색상 대체 모드에서 HP·에너지·성장 패널이 겹치지 않도록 검사한다.
팀 음성 채팅을 초기 필수 제작 범위로 잡지 않는다. 필수 협동 안내는 핑과 맵 상태만으로 이해할 수 있게 한다.

## 8. 재접속·종료·결과

연결 상실 5초 후 봇이 현재 영웅을 이어받는다. 잃어버린 접속 시점부터 60초 내 복귀하면 같은 현재 상태로 돌아온다.
플레이어에게 남은 복귀 시간과 봇 제어 여부를 표시하며, 복귀 때문에 체력·위치·쿨타임을 초기화하지 않는다.
60초 이후에는 그 플레이어의 복귀 자리를 닫고 봇이 끝까지 진행한다. 새 외부 플레이어를 경기 중 채워 넣지 않는다.
초기 비공개 테스트에서 호스트가 사라지면 ‘호스트 연결 종료로 세션 중단’으로 끝내며 승패를 만들어 내지 않는다.
종료 메뉴는 본인 이탈과 봇 전환을 설명한다. 초기 버전에는 팀 항복 투표나 개인 이탈에 의한 즉시 승리 처리가 없다.
결과 화면은 승패와 핵 파괴 시간을 먼저, 구조물 피해·영웅 피해·도움 횟수·획득 XP를 다음에 보여 준다.
도움 횟수는 공통 규칙의 최근 6초 기여 판정을 그대로 쓰며 보이지 않는 점수식으로 특정 플레이어를 최우수라고 단정하지 않는다.
보상 상자·계정 경험치·잠긴 능력치 해금 대신 같은 방 재경기와 관련 영웅 연습을 다음 행동으로 제안한다.

## 9. 사람 대상 검증

M3 신규 사용자에게 XP/포인트/크레딧, R 해금, 인접 지원, 두 보호 상태를 자기 말로 설명해 달라고 요청한다.
첫 경기에서 성장 포인트를 끝까지 안 쓰는지, D가 다른 소모품을 쓰는 줄 아는지, 타워 피해 감소 이유를 놓치는지 기록한다.
세 영웅 과제를 마친 뒤 각각 ‘진입 시점·회수 경로·설치 위치’ 중 무엇을 결정하는지 구별할 수 있어야 한다.
목표는 외운 키 개수가 아니라 상황에 맞는 행동을 한 번 수행하는 것이다. 시간·오입력·도움 요청을 함께 기록한다.
완료율과 소요 시간은 실제 참가자 수와 함께 [플레이테스트 문서](../04-playtest-and-balance.md)에 남긴다. 이 설계 문서는 UI나 학습 효과를 구현·검증했다는 주장이 아니다.
