## 1. 로스터 목표

세 명만으로 짧은 재사용 대기시간의 교전, 옆 라인 지원, 성장 선택, 미니언을 동반한 공성을 검증한다. 역할은 전투에서 잘하는 행동을 설명하며 고정 라인·정글 담당을 뜻하지 않는다.

| ID / 작업명 | 핵심 손맛 | 직접 만드는 기회 | 명확한 약점 | 상세 문서 |
|---|---|---|---|---|
| C01 바스 / Bas | 짧게 진입하고 넓은 장갑으로 압박 | 좁은 전선에서 아군이 공격할 공간 확보 | 진입 뒤 이탈 수단 부족, 원거리 견제 | [바스](01-bas.md) |
| C02 리오 / Rio | 나가는 원반과 돌아오는 원반의 경로 설계 | 이동·회수점을 이용한 두 번째 적중 | 낮은 체력, 좁은 경로가 막히면 효율 감소 | [리오](02-rio.md) |
| C03 네마 / Nema | 두 개의 핀을 놓고 연결선을 유지 | 예고된 선형 제압과 아군 보호막 | 준비 시간, 파괴 가능한 핀, 이동기 부재 | [네마](03-nema.md) |

이름·외형·기술명은 모두 작업명이다. 기존 게임 캐릭터를 일대일로 대응시키지 않으며, 상표 조사나 전 세계적 신규성 검증을 완료했다는 뜻이 아니다.

## 2. 공통 입력과 수치 표현

- 각 캐릭터는 패시브 1개, Q/W/E 일반 기술 3개, R 특수기 1개를 가진다. 일반 기술은 시작부터 사용 가능하다.
- R은 레벨 3 이상에서 성장점 1점을 써야 열린다. 레벨만 올랐다고 자동으로 열리지 않는다.
- 수치는 m·초 단위다. 표의 `기본값 + 계수 × 위력`은 방어 적용 전 피해다.
- 시작 위력 100, 방어력 0, 에너지 100, 자연 회복 8/초를 사용한다. 레벨·성장 증가는 정본에 따른다.
- 시트의 위력 100 합산 예시는 공식 검산용이다. 실전 R은 레벨 3부터 열리므로 성장 선택이 없어도 자동 증가 후 위력 106 이상에서 사용한다.
- 유효한 액티브 명령이 서버에서 승인되는 순간 에너지를 지불하고 재사용 대기시간을 시작한다. 투사체 귀환·장치 소멸까지 기다리지 않는다.
- 잠긴 R, 에너지 부족, 기절 중 입력, 불법 지형·대상, 필요한 장치 부재는 승인 전 실패다. 에너지와 재사용 대기시간을 소비하지 않는다.
- 승인 후 기절·넉백·사망으로 선딜이 취소되면 이미 지불한 에너지와 재사용 대기시간은 돌려주지 않는다. 속박은 정지형 기술의 시전을 막지 않는다.
- 선딜은 승인부터 효과 생성까지, 후딜은 효과 생성 뒤 다른 공격·기술을 실행할 수 없는 시간이다. 별도 기재가 없으면 선후딜 동안 이동도 멈춘다.
- 고정 선후딜 중 새 공격·기술은 실행하지 않는다. 행동 예약 1개만 보관하며 최신 명령이 이전 예약을 대체한다. 후딜이 끝나면 사거리·시야·자원·상태를 재검사하고 유효할 때만 승인한다.
- 조준점 사거리는 중심 간 거리다. 사거리 밖 조준은 자동 이동·최대 거리 보정 없이 실패하며, 방향만 쓰는 기술은 표에 적힌 최대 길이를 사용한다.
- 액티브와 기본공격은 승인 시 위력을 스냅샷한다. 패시브 보호막은 발동 사건 시 위력을 기록하며, 이미 생성된 피해·보호막을 이후 성장으로 재계산하지 않는다.
- 이동기 E는 별도 이동 구간을 가진다. 속박 중 사용할 수 없고, 이동 중 속박·기절·넉백을 받으면 현재 합법 위치에서 멈춘다.
- 지형 차단은 이동 불가 벽을 뜻한다. 투사체·선형 효과의 세부 차단과 구조물 관통 여부는 각 기술 표에 기록한다.
- 지면 조준은 시야 밖에도 가능하다. 피해 숫자·적중음·표식·자원 환급 등으로 숨은 적의 존재를 알리지 않는다.
- 캐릭터 중심은 동일한 반지름 0.45의 지상 캡슐을 쓴다. 원·부채·선의 판정은 캡슐과 실제 영역의 겹침으로 결정하고 장식 VFX는 판정을 넓히지 않는다.
- 원형·부채는 원점에서 대상 중심까지, 선·띠는 중심선의 최근접점에서 대상 중심까지 벽 차단을 검사한다. 벽에 막히면 범위가 겹쳐도 효과가 없으며 경고도 같은 지형 경계에서 잘라 표시한다.
- 동일 시전은 적중 단계별로 같은 대상을 1회만 맞힌다. 리오 Q만 명시적으로 출발·귀환 두 단계가 있으며 각각 1회다.
- 같은 이름의 보호막을 다시 받으면 기존 잔량과 새 보호막 중 큰 값으로 갱신하고 지속시간을 새로 시작한다. 잔량을 합산하지 않는다.
- 서로 다른 기술의 보호막은 함께 유지한다. 피해는 만료가 빠른 보호막부터 차감하고, 같은 만료 시각이면 먼저 생성된 것부터 차감한다.
- 보호막도 방어 적용 후 피해를 흡수한다. 시트의 보호막 적중 인정은 실제 흡수 또는 체력 피해가 발생한 경우를 뜻한다.

## 3. 기본공격과 구조물

| 항목 | 바스 | 리오 | 네마 |
|---|---:|---:|---:|
| 시작 최대 체력 | 1,100 | 950 | 1,000 |
| 이동속도 | 5.8 | 6.2 | 6.0 |
| 기본공격 사거리 | 2.0 | 6.5 | 5.5 |
| 기본공격 피해 / 간격 | 60 + 0.3 × 위력 / 1.0초 | 동일 | 동일 |
| 에너지 소비 | 0 | 0 | 0 |

- 기본공격은 선택 가능한 적 영웅·미니언·경험 셀·노출된 구조물·적 네마 핀을 대상으로 한다. 최초 대상 지정에는 공유 시야가 필요하다.
- 겹친 대상 우클릭은 보이는 적 영웅 → 적 미니언 → 공격 가능한 구조물 → 셀 → 적 핀 순으로 선택한다. 아군 영웅·핀 클릭은 공격으로 바꾸지 않고 지면 이동으로 처리한다. 선택 윤곽을 클릭 전에 표시하고, 작은 핀 표적은 전용 대상 선택 키로 직접 순환할 수 있게 한다.
- 기본공격 선딜은 바스 0.18초, 리오 0.16초, 네마 0.18초다. 원거리 공격 탄속은 20m/초이며 지형에 닿으면 소멸한다.
- 1.0초 간격은 공격 명령 승인 시점부터 센다. 선딜 중 이동·기절·넉백으로 취소해도 이 간격을 초기화하지 않는다. 공격이 성립한 뒤 남은 간격에는 이동할 수 있다.
- 바스는 선딜 종료 시 사거리·대상 유효성을 재확인한다. 원거리 공격은 발사 뒤 대상이 사라지거나 죽으면 소멸하며, 시야만 잃으면 서버가 추적하되 시야 밖 추적 구간·숨은 적중 피드백은 표시하지 않는다.
- 액티브 기술은 기본공격 간격을 초기화하지 않는다. 리오 E의 강화 공격도 다음 정상 공격 1회에 적용한다.
- 이미 발사한 기본공격 투사체는 공격자의 사망만으로 없어지지 않는다. 리오 Q의 사망 시 제거는 해당 기술의 명시적 예외다.
- 구조물 피해는 먼저 0.5배, 공격 팀의 라인 미니언이 구조물 중심 12m 안에 없으면 다시 0.3배다. 병력의 출발 라인은 따지지 않는다. 두 조건이 겹치면 원피해의 0.15배다.
- 잠긴 내부 타워·핵에는 피해와 적중 보상이 모두 없다. 보호막·속박·둔화·넉백은 구조물에 적용되지 않는다.
- 네마 핀과 리오 회수점은 공성 보호를 해제하는 라인 미니언으로 인정하지 않는다.

## 4. 조합과 대응 관계

| 공격하는 쪽 | 유효한 행동 | 상대가 보유한 대응 | 확인할 편향 |
|---|---|---|---|
| 바스 → 리오 | 귀환점을 보고 E로 짧게 접근 | 리오가 E를 진입 이후까지 보존 | 바스 E만으로 원거리전을 항상 끝내지 않는가 |
| 리오 → 바스 | Q 두 경로를 벌려 보호막 밖에서 압박 | 바스가 첫 경로만 맞고 귀환선을 이탈 | 기본공격 사거리 차이로 근접 진입이 불가능하지 않은가 |
| 바스 → 네마 | 핀을 직접 치거나 선 옆으로 접근 | 네마가 E로 보호하고 핀 뒤 아군에게 후퇴 | 핀 2개 배치가 E 한 번에 항상 무력화되지 않는가 |
| 네마 → 바스 | 진입 예상 위치에 W/R 경고선 형성 | 바스가 W로 버티고 선을 가로질러 빠르게 통과 | 둔화와 속박이 공통 CC 상한을 우회하지 않는가 |
| 리오 → 네마 | Q로 핀과 영웅을 함께 노림 | 네마가 핀을 한 선상에 모으지 않음 | 관통 원반이 장치를 비용 없이 전부 지우지 않는가 |
| 네마 → 리오 | 원반 회수점 주변을 선으로 통제 | 리오가 핀을 먼저 파괴하거나 E로 측면 이동 | 회수 기하를 항상 봉쇄하는 배치가 생기지 않는가 |

바스·네마의 보호막은 서로 다른 출처라 함께 존재할 수 있으나, 무적이나 피해 면역은 없다. 리오에게 보호막을 몰아주는 조합의 생존 시간은 독립된 관측 항목으로 둔다.

같은 팀의 중복 선택은 초기 테스트에서 금지하고 양 팀의 미러 선택은 허용한다. 초기 3명 기간에는 팀마다 세 명 모두 등장하므로 영웅별 승률만으로 밸런스를 판단하지 않는다. 6명 후보가 생긴 M4에서 중복 정책을 다시 검토한다.

## 5. 튜토리얼과 시각 구분

1. 바스: 경고 부채를 옆으로 피한 뒤, 짧은 진입·기본공격·엄호를 배운다.
2. 리오: 고정 표적에 Q 두 번을 맞히고, 회수점과 이동으로 귀환 경로를 바꾼다.
3. 네마: 핀 2개와 W를 연결한 뒤 상대 핀을 파괴해 같은 효과를 끊는다.

아군·적군 색 외에도 바스는 굵은 부채/사각 띠, 리오는 얇은 원반/삼각 테두리, 네마는 두 끝점이 보이는 선을 사용한다. 경고 바닥과 실제 타격 범위, 적중 시점은 일치해야 한다.

## 6. 제작·확장 게이트

- M1 진단 캐릭터는 바스다. 일반 공격, 이동 충돌, 지연 타격, 보호막, 짧은 넉백을 먼저 검증한다.
- M2에는 초기 3명을 모두 넣고 3대3·세 라인·성장·공성 루프를 연결한다. 상세 시트는 구현 완료의 증거가 아니다.
- M3에서 6인 테스트로 경고 인지, 이웃 라인 지원, 에너지 고갈, 대응 가능성을 관측한 뒤 확장안을 고른다.
- 추가 3명은 [확장 로스터](04-roster-expansion.md)의 개념만 승인 후보로 둔다. 상세 수치·완성 에셋·구현 착수는 해당 게이트를 통과한 뒤다.
- 영웅 선택률·라인 경험 손실·킬 관여·구조물 피해·핀 파괴 시간·경고 회피율을 함께 본다. 작은 표본의 승률 하나를 통과 조건으로 쓰지 않는다.
- 테스트 기록에는 빌드 버전, 영웅/성장 선택, RTT, 참가자 숙련도, 실패한 기술 입력 이유를 포함한다.
