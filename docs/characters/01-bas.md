## 1. 플레이 약속

바스는 구리 경첩을 단 넓은 도자기 압착 장갑으로 전선을 여는 길드 기술자다. 짧은 진입 뒤 상대의 이동 공간을 줄이고, 아군에게 잠깐의 보호막을 제공한다. 긴 추격이나 자유로운 퇴로는 주지 않는다.

손맛의 핵심은 E의 도착 위치와 Q/R의 방향 선택이다. 공격을 명중시켜 패시브를 준비한 뒤 기본공격까지 연결하면 짧게 버틸 수 있지만, 먼 적에게 보호막만 반복 생성할 수는 없다.

| 기본 정보 | 제안값 |
|---|---|
| 역할 / 조작 난도 | 근접 돌파·엄호 / 낮음~중간 |
| 체력 / 이동속도 / 방어력 | 1,100 / 5.8m/초 / 0 |
| 위력 / 에너지 / 회복 | 100 / 100 / 8/초 |
| 기본공격 | 사거리 2.0m, 60 + 0.3 × 위력, 간격 1.0초 |
| 유리한 상황 | 짧은 연결로의 입구, 아군 미니언이 도착한 타워 앞, 아군과 함께하는 재진입 |
| 불리한 상황 | 개방된 장거리 추격, E를 쓴 직후의 측면 견제, 에너지 없는 단독 공성 |

## 2. 패시브 — 압력 이음

Q/E/R 중 하나가 보이는 적 영웅에게 실제 피해 또는 보호막 피해를 주면 압력 1개를 얻는다. 같은 시전으로 여러 명을 맞혀도 1개이며 최대 2개다. 마지막 획득으로 6초 타이머를 갱신하고 만료 시 전부 사라진다.

압력 2개일 때 적 영웅에게 다음 기본공격을 적중시키면 전부 소비하고 자신에게 `80 + 0.25 × 위력` 보호막을 2초간 준다. 시작 위력에서는 105다. 공격 피해를 처리한 뒤 보호막을 생성하므로 그 공격 이전 피해를 소급해서 막지 않는다.

- 보호막 획득은 적을 처치한 정상 적중에도 성립한다. 공격이 빗나가거나 대상이 무적·사망 상태면 압력을 소비하지 않는다.
- 미니언·경험 셀·구조물·적 네마 핀에 대한 공격은 압력을 얻거나 소비하지 않는다. W는 압력을 만들지 않는다.
- 압력 획득과 소비 시 모두 대상이 팀 공유 시야에 있어야 한다. 숨은 적중은 압력 HUD를 바꾸지 않는다.
- 압력 1/2는 장갑의 두 개 기계판으로 표시한다. 추가 경직·치명타·피해 증가는 없다.
- 압력은 사망 시 제거되고 부활 시 0개다. 보호막 갱신·중첩은 캐릭터 공통 규칙을 따른다.

## 3. Q — 벼림 부채

| 항목 | 제안 사양 |
|---|---|
| 조준 / 범위 | 방향 조준, 전방 80도 부채, 반경 3.2m. 시전 승인 시 방향 고정 |
| 선딜 / 경고 / 후딜 | 0.20 / 승인부터 부채 경고 0.20 / 0.18초 |
| 피해 / 부가 효과 | 80 + 0.55 × 위력, 이동속도 20% 감소 0.7초 |
| 비용 / 재사용 | 에너지 16 / 3.0초, 승인 시 시작 |
| 대상 / 상한 | 적 영웅·미니언·셀·핀·노출 구조물, 같은 시전당 1회 |
| 지형 / 구조물 | 바스 중심과 대상 사이 벽이 있으면 피해 없음. 구조물 피해 0.5배, 둔화 없음 |

선딜 중 이동·재조준·다른 공격은 불가능하다. 기절·넉백·사망으로 타격 전에 취소되면 피해와 압력을 만들지 않고 비용은 유지한다. 속박은 시전을 중단하지 않는다.

타격 순간 영역을 벗어난 적은 맞지 않는다. 상대는 바스의 옆이나 뒤로 이동하거나 부채 밖에서 반격한다. 넓은 공격의 장점과 짧은 사거리의 약점을 함께 유지한다.

## 4. W — 받침 펼치기

| 항목 | 제안 사양 |
|---|---|
| 조준 / 범위 | 지면 조준, 중심 사거리 3.0m, 반경 2.2m의 아군 보호막 파동 |
| 선딜 / 경고 / 후딜 | 0.12 / 승인부터 원형 0.12 / 0.12초 |
| 효과 / 지속 | 영역 내 자신·아군 영웅에 100 + 0.35 × 위력 보호막, 1.5초 |
| 비용 / 재사용 | 에너지 18 / 5.0초, 승인 시 시작 |
| 피해 / 구조물 | 피해 없음. 미니언·장치·타워·핵에는 보호막을 주지 않음 |
| 설치 조건 | 걸을 수 있는 지면, 중심까지 벽에 막히지 않는 직선. 범위 밖 조준은 승인 전 실패 |

파동은 효과 생성 순간의 대상만 보호하며, 지면에 남아서 나중에 들어오는 대상을 보호하지 않는다. 같은 바스 W를 다시 받으면 보호막 잔량을 더하지 않는다. 패시브 보호막과는 별도로 유지한다.

기절·넉백·사망이 선딜을 끊으면 파동이 없다. 생성된 아군 보호막은 바스가 죽어도 정해진 만료까지 유지한다. W는 상태이상을 해제하거나 지속시간을 줄이지 않는다.

상대는 1.5초를 기다리거나 보호받지 않은 대상을 노릴 수 있다. 바스는 W를 피해 직전에 써야 이득이며, 압박 전에 미리 쓰면 효율이 떨어진다.

## 5. E — 엇박 발판

| 항목 | 제안 사양 |
|---|---|
| 조준 / 이동 | 방향 조준, 최대 4.2m를 14m/초로 지상 이동, 최대 이동 시간 0.30초 |
| 선딜 / 경고 / 후딜 | 0.12 / 승인부터 경로 폭 0.9m 경고 / 이동 종료 뒤 0.16초 |
| 충돌 / 피해 | 첫 적 영웅과 접촉하면 정지, 해당 1명에게 45 + 0.40 × 위력 |
| 부가 효과 | 진행 방향으로 최대 0.8m 밀기, 이동 시간 최대 0.12초가 하드 CC에 포함 |
| 비용 / 재사용 | 에너지 20 / 5.0초, 승인 시 시작 |
| 지형 / 구조물 | 벽·구조물에 닿기 전 합법 위치에서 정지. 벽을 넘지 않으며 구조물에는 피해 없음 |

바스의 이동 캡슐과 적 영웅 캡슐이 처음 접촉한 위치를 사용한다. 접촉 뒤 바스의 캡슐이 겹치지 않도록 정지하고, 같은 E로 두 명을 밀지 않는다. 아군 영웅에 막혀도 정지하며 피해·넉백은 없다. 미니언·셀·핀에는 접촉 피해·넉백을 주지 않는다.

넉백은 벽·구조물 직전에 멈추고 충돌 추가 피해가 없다. 하드 CC 예산이 0.06초만 남았다면 최대 0.4m만 밀고, 0이면 피해만 준다. 벽 충돌이나 CC 상한 때문에 밀리지 않아도 정상 피해는 압력을 만든다.

속박 중 시전은 거부한다. 이동 중 속박·기절·넉백·사망을 받으면 즉시 멈추며 아직 접촉하지 않은 대상에게 피해를 예약하지 않는다. 이동 중 피해 면역·투사체 회피·충돌 무시는 없다.

상대는 경로 옆으로 이동하거나 E 이후에 이동기를 써서 거리를 벌린다. 진입에 E를 사용하면 재사용 전까지 바스에게 별도의 탈출 이동기는 없다.

## 6. R — 세로 파열

| 항목 | 제안 사양 |
|---|---|
| 해금 / 조준 | 레벨 3 이상 + 성장점 1, 방향 조준 |
| 형상 / 범위 | 바스 중심에서 조준 방향으로 7.0m, 폭 2.8m의 직사각형 띠 |
| 선딜 / 경고 / 후딜 | 0.65 / 승인부터 전체 띠 경고 0.65 / 0.25초 |
| 피해 / 제어 | 150 + 0.85 × 위력, 속박 0.65초, 같은 대상 1회 |
| 비용 / 재사용 | 에너지 32 / 16.0초, 승인 시 시작 |
| 구조물 / 차단 | 구조물 피해 0.5배·속박 없음. 폭 2.8m 전방 스윕의 첫 벽 접촉 거리까지 띠 전체 길이를 줄임 |

경고 동안 바스는 움직이지 못하고 방향을 바꾸지 못한다. 타격 전 기절·넉백·사망은 전체를 취소하며 속박은 취소하지 않는다. 바스가 후딜 중 죽어도 이미 처리된 피해와 속박은 되돌리지 않는다.

속박은 이동·이동기를 막지만 기본공격과 정지형 기술을 막지 않는다. 공통 3초 창의 하드 CC 1.5초 상한에 따라 남은 시간만 적용한다. 표적이 없는 지면에도 사용 가능하다.

상대는 0.65초 동안 띠의 측면으로 빠지거나 바스의 시전을 끊을 수 있다. E 넉백의 최대 정지 시간이 0.12초이므로 E가 맞았다는 이유만으로 R 전체가 보장되지는 않는다.

## 7. 성장 선택과 교전 예시

| 선택 | 13점 완성 예시 | 노리는 상황 |
|---|---|---|
| 전선 유지 | 체력 5, 방어 4, 에너지 회복 2, 위력 1, R 1 | 타워 앞 엄호와 반복 진입 |
| 빠른 압박 | 위력 4, 체력 4, 방어 2, 이동속도 2, R 1 | 연결로 지원과 짧은 교전 |

두 예시는 모든 항목 상한을 지킨다. 시작 2점은 체력 1·방어 1을 튜토리얼 추천으로 쓰되 강제하지 않는다. 레벨 3까지 R용 1점을 확보할지, 생존 수치를 먼저 살지 선택한다.

위력 100·상대 방어 0 기준 E 85 + Q 135 + R 235 + 기본공격 90 = 545 피해다. 네 액티브를 모두 쓰는 비용은 86이며, 패시브가 준비되어 기본공격까지 맞으면 보호막 105를 받는다. 이동·경고 회피·방어·보호막은 이 이론값을 낮춘다.

Q만 타워에 맞히면 라인 미니언 동반 시 67.5, 없으면 20.25 피해다. E는 타워 피해를 주지 않고, 구조물 공격으로 패시브를 충전할 수 없다.

## 8. 에셋·튜토리얼·완료 판정

- 외형: 낮고 넓은 상체, 비대칭 도자기 장갑, 구리 경첩 2개. 몸색에 의존하지 않고 실루엣으로 식별한다.
- 애니메이션: 대기·달리기·기본공격·Q 횡압착·W 펼침·E 준비/이동/정지·R 축적/내리찍기·피격·사망 각 1세트.
- VFX/SFX: 압력 0/1/2, 부채 경고, 보호막 잔량/만료, 돌파 궤적, 파열 경고/발동, 취소음. 모든 장식은 실제 판정 안쪽에 묶는다.
- UI: 압력 2칸과 만료, E 진행 경로, R 잠금 사유, 에너지 부족, CC 상한으로 줄어든 실제 속박 시간의 개발용 로그.
- 튜토리얼: Q로 미니언 정리 → Q/E로 압력 2개 → 영웅 기본공격으로 보호막 → W로 아군 보호 → R 경고를 적 역할로 회피한다.
- 합격 B01: Q 경계 안/밖, 벽 앞/뒤의 표적을 각각 1회/0회 맞히며 선딜 취소 후 피해가 발생하지 않는다.
- 합격 B02: 동일 Q가 적 3명을 맞혀도 압력은 1개, 구조물·핀 적중은 0개, 숨은 적중 HUD 변화도 0개다.
- 합격 B03: E가 벽·두 영웅·속박과 만나는 경우 관통·겹침·중복 피해가 없고 넉백 길이가 남은 CC 시간에 비례한다.
- 합격 B04: R 속박 중 대상은 Q/W 같은 정지 기술을 쓸 수 있으며, 3초 안 누적 하드 CC는 1.5초를 넘지 않는다.
- 합격 B05: 패시브와 W는 별도 보호막으로 계산되고, W를 갱신해도 같은 출처 잔량은 더하지 않는다.
- 합격 B06: 50/100/150ms RTT에서 경고 종료와 서버 타격 시점을 비교하고, 반복되는 경고 후 지연 적중이 있으면 M1 통과를 보류한다.
- 조정 순서: E 도착 거리 → R 경고 시간 → Q 폭·사거리 → 보호막량 → 피해. 높은 처치율만 보고 경고를 지우지 않는다.

## 9. M1 진단 봇의 행동 기준

| 상황 | 첫 구현 행동 |
|---|---|
| 체력 35% 미만 | W가 가능하면 자신을 보호하고 기지 방향으로 이동. E는 적과 충돌하지 않는 안전한 경로에만 사용 |
| 보이는 적 영웅 접근 | Q 사거리면 Q, 압력 2개면 기본공격 우선. E는 도착 지점이 적 타워 범위 밖이고 아군이 지원 가능한 경우만 사용 |
| R 판단 | 현재 보이는 적 2명 이상이 경고 띠 안에 있고 에너지가 남을 때 사용. 시야 밖 위치나 미래 입력을 읽지 않음 |
| 미니언 처리 | Q로 둘 이상을 맞힐 수 있으면 사용하고 이후 기본공격. 영웅 없는 웨이브에 E/R을 모두 소비하지 않음 |
