# V5 캐릭터·운하 전장 복구와 검증

작성일: 2026-11-05. 기준 커밋: `1aabd7d` (V4). 사용자 요청: 중단된 구현·기획·시안 작업을 이어서 완료한다.

## 범위

- 중단 직전 보존된 프로젝트 작업본에서 V5 모델, 텍스처, 운하 환경, 화면 연결 코드를 복구한다.
- 이미 구현된 3라인 전투, 기본 공격, 패시브, QWER, 봇과 승패 규칙을 보존한다.
- `doc/design`에서 현재 구현과 계획을 구분하고 V5 자산·아트 가이드를 추가한다.
- 새 작업 트리에서 Godot 회귀 검사와 실제 렌더링을 실행한다. 기존 로그는 이번 검증 결과로 재사용하지 않는다.

## 작업 순서와 완료 조건

1. **복구**: 보존 작업본과 최신 Git을 비교해 변경·추가 파일만 적용한다. `.godot` 캐시는 제외한다.
2. **독립 검토**: 프레젠테이션과 리소스 경로, 기존 테스트 변경, 게임 규칙 불변 여부를 확인한다.
3. **검증 보강**: 실제 GLB 모델·텍스처와 연출실을 확인하는 의미 있는 V5 검사를 추가한다.
4. **문서**: V5 설명과 최신 상태, 남은 개발, 확인 방법을 실제 소스 기준으로 정리한다.
5. **실행 확인**: 전체 회귀 검사, 캐릭터 선택·세 영웅·전장·스킬의 실제 화면을 확인한다.
6. **전달**: 검증한 소스와 자산을 GitHub에 저장하고, 가능하면 같은 소스로 Windows 미리보기 패키지를 만든다.

## 검증의 한계

자동 검사와 Linux Compatibility 렌더링은 Windows 사용자 플레이나 온라인 대전 검증을 대신하지 않는다. Steam 연동·상용 미술 완성·대인 밸런스는 완료로 표시하지 않는다. 보존된 실행 파일을 재사용할 경우 원본 출처·해시와 새 PCK의 소스 해시를 별도로 기록한다.

## 완료 기록

복구·독립 정적 검토·V5 자산/관절 검사·문서·실제 렌더·Windows 미리보기 패키지 생성까지 수행했다. 25묶음 합계 4,586 checks, 실패 0이며 현재 런타임과 배포 snapshot의 코드·자산도 일치한다. 결과와 검증 한계는 [V5 검증 기록](../../../doc/design/verification/2026-11-05-v5-verification.md)에 모았다. GitHub 저장·워크플로 결과는 최종 전달 기록으로 연결한다.
