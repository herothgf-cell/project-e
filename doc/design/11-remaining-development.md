# 남은 개발 — 통합 V2 이후

갱신: **2026-11-03**. 최신 정본은 [통합 V2](19-integrated-v2.md). 사용자가 선택한 방식은 **먼저 전부 연결한 실행판을 만든 후 하나씩 수정**이다. 캐릭터 한 명의 승인 때문에 다른 요소 연결을 중단하지 않는다.

## 확인한 범위

Godot4.7.2 전체 **22묶음·4,522개 실패0**, 실제 Linux 렌더 정지40장+동작282프레임. 연출실은 원래 경기 상태를 보존한다. 관측 사망은 시야 상실 시 폐기한다. 검토맵 XP 셀 누락은 실패 재현 후 수정했다. 소리·완성 아트·사용자 PC 수동 플레이는 완료 처리하지 않는다.

## 다음 수정 순서

실제 검토판을 기준으로 사용자가 지목한 항목부터 바꾼다. 캐릭터 체형/장비, 스킬 동작/효과, 맵 구조/고저차, 카메라, 타격/음향을 각각 분리해 비교 가능하게 유지한다. 숫자 밸런스와 미술을 한 번에 바꾸지 않는다.

자동 경기 기록을 사람 재미나 목표 경기시간 충족으로 해석하지 않는다. 키/화면/음량 설정, 튜토리얼, 온라인2클라이언트→6인방, 재접속, 최종자산·대상PC 성능, Steam 출시 준비는 이후 제품 단계다.
