# C06 무아 · 물결의 화가

2026-11-09 V8 로컬 프로토타입 설계. 이 시트의 신규 전투 수치와 실제 효과는 V8 실험 설계다. 수치는 아래 구현 및 행동 검사와 대응한다.

붓과 물감으로 두 원형 물결 구역을 배치하는 지원가다. 활성 원에는 선명한 물결, 비활성 원에는 옅은 고리를 사용해 다음 지원 위치를 알린다.

## 플레이와 초기값

Q로 두 물결을 배치하고 W로 다음 이동할 아군이 있는 구역을 활성화한다. 가까운 아군에게 E를 주되 활성 구역과 겹치면 보호가 커진다. R로 활성 구역을 소모해 교전을 마무리하고 남은 구역으로 돌아간다.

|---|---|
| 체력 / 이동속도 / 방어력 | 980 / 6.0m/초 / 0 |
| 기본 공격 | 사거리 5.5m, 선딜 0.18초, 간격 1초, 60 + 0.30P 피해 |
| 위력 P / 마나 / 마나 회복 | 100 / 100 / 초당 8 |
| 초기 레벨 / 성장점 / R | 일반 경기 1 / 2 / 잠금 |
| 기술 체험 | 양 팀 레벨 3, 위력 106, 체력 +80, 성장점 3, R 해금 |

| 선택 시 동쪽 팀 북 / 중앙 / 남 | 바스 / 테르 / 루메 |

기본 공격 피해와 각 기술 예시값은 위력 100·방어 0·보호막 없음 기준이다. 경기 인원은 양 팀 3명씩이며 플레이어는 중앙 라인을 맡는다.

## 패시브 · 잔물결

잔물결은 활성 구역 안에 새로 들어온 아군 영웅에게 35 + 0.15P 보호막을 1.2초 제공한다. 위력 100에서는 50이다. 같은 무아와 같은 대상 조합마다 4초 재발동 간격을 둔다. 구역 설치·실제 전환·R 뒤 남은 구역 활성화는 새 진입 판정을 만들지만 재발동 시각은 초기화하지 않는다. 같은 원에 계속 서 있거나 하나뿐인 구역에 W를 써도 반복 발동하지 않는다.

### Q · 물감 웅덩이

| 항목 | V8 구현 |
|---|---|
| 조준과 형상 | 지면, 시전 거리 6m·설치 피해 반경 2m |
| 수치 | 55 + 0.30P = 85 설치 피해 |

시전자는 최대 2개 물결을 소유한다. 수명 8초, 최신 구역이 활성이다. 세 번째 정상 설치는 가장 오래된 구역을 제거한다. 구역 자체에는 체력·공격·시야·보상이 없다.

설치 예고를 피하고 지원 구역 밖으로 전투를 옮긴다.

### W · 흐름 바꾸기

| 항목 | V8 구현 |
|---|---|
| 조준과 형상 | 소유 구역 명령, 선택 구역 중심까지 8m·직선 시야 |
| 수치 | 활성화할 반경 2m 구역 아군 보행 속도 +25%, 2초 |

구역 2개면 비활성 구역으로 전환하고 1개면 그대로 사용한다. 승인 시 선택한 구역 ID를 고정한다. 발동 순간 그 구역 안의 아군 영웅에게 가속을 준다. 이후 진입자는 이 가속을 받지 않는다.

활성 전환 후 다른 구역에서 교전을 열거나 가속이 끝날 때 진입한다.

### E · 물결 덧칠

| 항목 | V8 구현 |
|---|---|
| 조준과 형상 | 자신 중심 반경 4m·직선 시야 안 아군 영웅 |
| 수치 | 80 + 0.30P = 110 보호막, 1.8초 |

받는 아군이 현재 활성 구역 안에도 있으면 40 + 0.15P = 55를 더해 총 165다. 구역과 아군 사이에도 직선 시야가 필요하다. 자기 자신도 조건에 맞으면 받는다.

물결 바깥의 아군을 압박하거나 두 보호 범위의 겹침을 깨뜨린다.

### R · 만조의 화폭

| 항목 | V8 구현 |
|---|---|
| 조준과 형상 | 활성 구역 명령, 중심까지 8m·직선 시야, 반경 3.5m |
| 수치 | 130 + 0.60P = 190 피해, 0.6초 속박 |

승인 시 활성 구역 ID와 중심을 고정한다. 0.65초 뒤 확대 범위에 타격하고 그 구역만 소비한다. 남은 구역은 활성화한다. 참여 구역이 만료되면 취소된다.

확대 원을 벗어나거나 수명이 다하는 구역에 R을 쓰도록 유도한다.

## 상태와 예외

구역은 actor.zones의 독립 상태다. 다른 무아의 구역·활성·진입 기록·재발동 시각에 접근하지 않는다. 각 소유자의 보호막 출처는 달라 함께 존재할 수 있다. 구역 안 포함은 영웅 충돌 반경을 더해 판정한다. 가장 오래된 원이 먼저 만료되며 활성 원이 사라지고 다른 원이 있으면 남은 최신 원을 활성화한다.

Q/W/E/R 키로 기술을 선택한 뒤 좌클릭 지점으로 시전한다. 방향 기술은 자기 위치와 다른 지점을 지정해야 한다. 자기 보호·가속은 자기 위치 클릭도 허용한다. R은 레벨 3과 성장점 1로 해금하며 기술 체험에서는 처음부터 열린다.

비용과 재사용은 시전 승인 때 시작한다. 선딜 중 기절·넉백·사망으로 취소되면 비용을 환급하지 않는다. 속박은 보행과 이동기를 막고 정지형 기술은 허용한다. 테르·세라 E와 기존 바스·리오 E는 명시적 이동기 판정을 공유한다. 시전된 기술의 중심·방향·위력은 승인 시 고정하며 별도 설명한 현재 상태 조건은 발동 때 검사한다.

오린 E, 테르 W, 무아 W/E, 세라 W, 루메 E는 지원기로서 부활 보호를 유지한다. 공격기와 이동기 사용은 부활 보호를 해제한다. 일반 기본 공격은 부활 보호를 해제한다.

피해는 공통 판정을 사용한다. 방어 감소는 100 / (100 + 방어력), 영웅의 구조물 피해는 0.5배다. 아군 라인 병력이 구조물 12m 안에 없으면 다시 0.3배가 된다. 잠긴 구조물과 보호 중인 표적은 피해를 받지 않는다. 둔화·속박은 영웅과 미니언에만 적용한다. 강제 제어는 1회 최대 1초와 최근 3초 합계 1.5초 규칙을 따른다.

영역 타격은 형상과 대상 충돌 반경의 교차 및 공통 직선 시야를 검사한다. 선형 공격은 벽에서 잘리고 원형·부채는 범위 안이라도 벽 뒤 적을 맞히지 않는다. 지면 지정은 거리·걸을 수 있는 지면·시전자와 목표 사이 직선 시야를 검사한다. 방향형 영역은 팀 시야 밖에도 타격할 수 있으며 표식 부여·소비는 각 영웅의 가시성 조건을 추가로 따른다.

보호막은 아군 영웅에만 제공한다. 같은 소유자·기술 출처는 높은 잔량을 유지하고 지속시간을 갱신하며 다른 출처는 함께 유지된다. 시간제 보행 가속은 가장 높은 비율 하나를 적용하고 둔화와 곱한다. 보호·가속이 아군에게 이미 부여되었다면 시전자 사망 뒤에도 대상에서 정해진 수명까지 유지된다. 자기 준비·표식·구역·가속·예약타격은 소유자 사망과 경기 초기화에 정리된다.

## 검증과 조정

자동 행동 검사는 실제 명령과 30Hz 시뮬레이션으로 피해·보호막·이동·시간 만료·중복 적중·사망 정리·제어·벽·시야·다중 소유를 확인한다. 실행 결과와 전체 회귀는 V8 검증 기록을 따른다. 봇은 공통 시전 명령으로 신규 기술을 사용하며, 실제 플레이의 체감 난도와 상성 수치는 후속 수동 검토 대상이다.

우선 조정 대상은 예고의 읽힘, 기본 공격과 기술의 연결 시간, 제어 후 회피 여유, 팀 보호 기여도다. 한 번의 기술 체험으로 최종 밸런스를 확정하지 않는다.
