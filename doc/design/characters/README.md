# 8명 영웅 설계와 전투 판정

V8의 선택 풀은 바스·리오·네마·오린·테르·무아·세라·루메다. 3등신 세미카툰 판타지 표현을 공유하며 무기, 실루엣, 전투 행동과 대응법으로 역할을 구분한다. 사람 1명과 봇 5명이 팀당 3명으로 경기에 참가한다. 기준 날짜는 2026-11-09다.

## 공통 판정

- 각 영웅은 패시브 1개, 일반 기술 QWE와 궁극기 R을 가진다.
- 일반 경기의 R은 레벨 3부터 성장점 1개로 해금한다.
- 기술 표의 피해·보호막은 `기본값 + 계수 × 위력`이며 시전 승인 시 위력을 기록한다.
- 승인 시 마나와 재사용 대기시간을 소비한다. 승인 뒤 선딜 취소는 이미 소비한 자원을 유지한다.
- 이동기는 속박 중 승인되지 않으며 이동 중 제어 상태와 지형을 검사한다.
- 경고와 피해는 동일한 원·부채·선 형상과 벽 경계를 사용한다.
- 숨은 적의 체력·표식·적중 피드백은 관측 가능한 조건에서 표시한다.
- 다회 타격은 각 단계를 따로 기록해 단계별 대상 1회 적중을 처리한다.
- 바스·테르·세라는 근접 기본공격이며 다른 영웅은 원거리 투사체 기본공격이다.
- 보호막은 출처별 잔량과 만료를 관리하며 공통 방어·상태·구조물 규칙을 따른다.

상세 승인·취소·피해·제어 규칙과 예외는 전투 기획에 기록했다. 각 영웅 시트는 기술의 수치, 형태, 유효 대상, 만료와 대응을 함께 적는다. [전투와 상태](../content/03-combat-and-status.md)

## 편성과 체험

선택한 영웅은 아군 중앙 라인에서 시작한다. 바스·리오·네마 선택 시 양 팀은 세 영웅을 한 명씩 사용한다. 신규 영웅 선택 시 아군은 선택 영웅·바스·네마로 구성하고 상대는 선택 영웅의 대응을 시험할 고정 3인 조합을 사용한다. 양 팀의 실제 편성과 후속 조합 실험표는 로스터 기획에 있다. [로스터와 편성](../content/07-roster-and-drafting.md)

기술 체험은 레벨 3과 R 해금 상태로 시작한다. F7 연출실은 8명 모두의 대기·이동·기본공격·QWER·피격·사망·부활을 실행하며, 구역·표식·정령목이 필요한 기술의 사전 조건을 실제 명령으로 만든다. [UI와 카메라](../content/08-ui-and-camera.md)

## 검증과 다음 관찰

전투 자동 검사는 실제 상태 변화, 시야·벽·제어·구조물, 사망 정리와 재시작을 확인한다. 화면 검사는 실제 카드 선택, 기술명·아이콘, 모델과 시전 효과를 확인한다. 사람 플레이에서는 영웅별 핵심 과제의 성공과 상대 대응, 마나 부족 시간, 지원 비용과 공성 기여를 기록한다. [V8 검증](../verification/2026-11-09-v8-verification.md) · [플레이테스트](../content/10-playtest-and-balance.md)

오린·테르·무아의 초기 역할 후보는 이전 설계 이력에서 볼 수 있다. V8은 사용자의 8명 확장 요청에 따라 각 역할을 현재 판타지 콘셉트와 실제 기술로 구체화했다. [초기 확장안](../../../docs/characters/04-roster-expansion.md) · [게임허브](../README.md)
