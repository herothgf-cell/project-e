## 1. 플레이 약속

리오는 얇은 구리 테두리를 두른 목재 원반으로 수로 설비의 정렬을 맞추는 길드 기술자다. 긴 천 끝과 가벼운 옆걸음으로 바스와 다른 실루엣을 만든다.

Q가 돌아오기 시작할 때의 회수 위치를 바꾸어 두 번째 경로를 만든다. 원반은 자동으로 적을 추적하지 않는다. 상대는 첫 번째 적중 뒤에도 귀환선을 피할 수 있다.

## 2. 패시브 — 되감은 힘

같은 Q의 출발 단계와 귀환 단계가 동일한 적 영웅에게 모두 피해 또는 보호막 피해를 주면 에너지 8을 즉시 회복한다. 시전당 최대 1회이며 여러 영웅에게 두 번 맞혀도 추가로 회복하지 않는다.

- 두 단계의 해당 적중 순간마다 대상이 팀 공유 시야에 있어야 한다. 숨은 적중을 이용해 에너지 HUD로 적을 탐색하지 못한다.
- 미니언·셀·구조물·장치에 두 번 적중해도 발동하지 않는다. R과 기본공격은 출발/귀환 단계로 취급하지 않는다.
- 에너지 최대 100을 넘는 회복은 버린다. 에너지 환급은 Q의 비용을 사전에 낮추지 않으므로 최초 시전에 20이 필요하다.
- 출발 적중 대상이 죽거나 귀환 전에 Q가 지형·사망으로 사라지면 발동하지 않는다. 처치된 다른 대상으로 적중 기록을 이전하지 않는다.
- 원반 중앙의 두 칸 표식과 짧은 기계음으로 성공을 알린다. 별도 위력·속도 버프나 하드 CC는 없다.

## 3. Q — 왕복 절삭

| 항목 | 제안 사양 |
|---|---|
| 조준 / 출발 | 방향 조준, 최대 8.0m, 원반 반지름 0.35m, 탄속 12m/초 |
| 선딜 / 경고 / 후딜 | 0.14 / 발사 방향 경고 0.14 + 이동 원반 / 발사 뒤 0.12초 |
| 출발 피해 | 70 + 0.45 × 위력, 같은 대상 1회 |
| 귀환 피해 | 50 + 0.35 × 위력, 같은 대상 1회, 탄속 16m/초 |
| 단계 전환 | 출발 종료 뒤 0.20초 회전 대기, 이 구간은 피해 없음. 대기가 끝날 때 귀환 목적지 확정 |
| 비용 / 재사용 | 에너지 20 / 4.0초, 승인 시 시작 |
| 수명 / 개수 | 발사 뒤 최대 2.2초, 리오당 1개. 귀환점 도착 또는 수명 종료 시 소멸 |
| 구조물 | 각 단계 피해에 0.5배. 구조물은 원반을 막지 않고 단계별 1회씩만 맞음 |

최대 거리 또는 벽에 도달하면 출발 단계를 끝내고 0.20초 회전 대기를 거쳐 귀환한다. 벽 충돌 지점에서는 벽 바로 앞의 마지막 합법 위치를 사용한다. 영웅·미니언·셀·핀은 관통하고 이동 방향을 바꾸지 않는다.

귀환 시작 순간 활성 W 회수점이 있으면 그 지점을 사용하고 회수점을 소비한다. 없으면 그 순간 리오의 위치를 목적지로 기록한다. 귀환 중 리오가 움직여도 목적지는 바뀌지 않으며 도착 즉시 소멸한다.

회수점은 귀환 시작 위치에서 13m 이내여야 한다. 초과하면 소비하지 않고 리오 위치를 사용한다. 리오 위치도 13m를 넘는 특수 상황에서는 해당 방향 13m 지점을 목적지로 제한한다.

귀환 경로는 목적지까지 직선이다. 귀환 도중 벽에 닿으면 즉시 소멸하며 벽 너머로 돌아가지 않는다. 목적지를 향하는 얇은 선은 귀환 시작 시 표시하고 시야 밖 구간은 그리지 않는다.

출발·회전 대기·귀환을 별도 단계 ID로 기록한다. 회전 대기 중 접촉 피해는 없고, 귀환이 시작될 때 다시 겹친 표적은 귀환 피해 1회만 받는다. 전환점에서 두 피해가 같은 순간 터지지 않도록 0.20초 대기를 보장한다.

발사 전 기절·넉백·사망은 전체 취소다. 발사 뒤 기절·속박은 원반을 취소하지 않지만 리오 사망은 즉시 원반을 제거한다. 이는 일반 투사체 사망 후 지속의 명시적 예외다. 출발·귀환 모두 Q 승인 시의 위력을 사용하며 숨은 적중에는 숫자·적중음·패시브 환급을 제공하지 않는다.

상대는 출발 원반의 옆으로 이동하거나, 첫 적중 뒤 귀환 목적지를 확인해 다시 선을 벗어난다. 벽 모서리를 이용하면 귀환 자체를 끊을 수 있다.

## 4. W — 회수 매듭

| 항목 | 제안 사양 |
|---|---|
| 조준 / 범위 | 지면 조준, 사거리 5.0m, 설치 파동 반경 1.2m |
| 선딜 / 경고 / 후딜 | 0.20 / 원형 경고 0.20 / 0.12초 |
| 설치 파동 | 40 + 0.25 × 위력, 20% 둔화 0.6초, 같은 대상 1회 |
| 회수점 | 파동 발생 후 2.0초 유지, 최대 1개, 다음 Q 귀환 시작에 소비 |
| 비용 / 재사용 | 에너지 14 / 4.0초, 승인 시 시작 |
| 구조물 / 지형 | 파동은 구조물에 0.5배 피해. 걸을 수 있고 리오와 벽으로 차단되지 않은 지면에 설치 |

회수점은 유닛이 아닌 바닥 표식이다. 공격·이동 방해·시야 제공·타워 어그로·공성 보호 해제 능력이 없다. 파동은 설치 시 1회이며 이후 접촉한 적은 피해를 받지 않는다.

Q 출발·회전 대기 중 W 효과가 생성되어 귀환 시작 시 회수점이 활성이라면 그 Q에 사용한다. W 후딜 종료까지 기다리지 않는다. 이미 귀환 중인 Q에는 영향을 주지 않는다. 같은 틱이면 서버 이벤트 순서로 생성 여부를 확정한다.

선딜 중 기절·넉백·사망은 설치와 파동을 모두 취소한다. 리오 사망 시 남은 회수점도 제거한다. 같은 위치를 다시 조준해도 이미 귀환한 Q를 재유도하지 않는다.

상대는 바닥 매듭을 보고 귀환 경로를 예상한다. 리오가 안전한 회수점만 놓으면 공격 각도가 줄고, 공격적인 회수점은 상대에게 추격 방향을 알려준다.

## 5. E — 가로디딤

| 항목 | 제안 사양 |
|---|---|
| 조준 / 이동 | 방향 조준, 최대 3.2m, 속도 16m/초, 최대 이동 시간 0.20초 |
| 선딜 / 경고 / 후딜 | 0.06 / 짧은 발디딤 방향 0.06 / 이동 종료 뒤 0.14초 |
| 강화 공격 | 이동을 정상 종료하면 1.5초 안의 다음 기본공격에 40 + 0.25 × 위력 추가 피해 |
| 비용 / 재사용 | 에너지 18 / 5.5초, 승인 시 시작 |
| 구조물 | 이동 중 피해 없음. 강화 기본공격의 기본·추가 피해 모두 구조물 0.5배 적용 |
| 충돌 | 영웅·벽·구조물 앞에서 정지. 무적·충돌 무시·은신·투사체 제거 없음 |

속박 중 시전은 거부한다. 이동 중 속박·기절·넉백·사망으로 끊기면 강화 공격을 얻지 않는다. 지형 때문에 짧게 정상 종료한 경우에는 강화가 생기지만 이동 거리가 추가되지는 않는다.

강화는 사거리·기본공격 간격을 바꾸지 않는다. 선딜 취소는 강화 사용으로 치지 않으며 유지 시간 1.5초는 계속 흐른다. 만료 전 다음 기본공격을 정상 발사하면 그 투사체 1개에 강화를 배정하고 HUD의 미사용 강화를 제거한다.

강화 추가 피해는 E 승인 시 위력, 기본 피해는 해당 기본공격 승인 시 위력을 사용한다. 영웅·미니언·셀·핀·노출 구조물에 적용되며, 기본공격 투사체가 소멸하면 배정된 강화도 사라진다. 리오 사망은 미사용 강화만 제거하고 이미 발사된 강화 공격은 유지한다.

E를 Q 출발·회전 대기 중 쓰면 이후 기록될 귀환 위치를 바꿀 수 있다. Q 귀환이 시작된 뒤에는 E로 자신만 이동하며 이미 확정된 귀환선을 꺾지 않는다. 상대는 E를 확인한 뒤 접근한다.

## 6. R — 삼각 봉합

| 항목 | 제안 사양 |
|---|---|
| 해금 / 조준 | 레벨 3 이상 + 성장점 1, 지면 조준, 조준점 거리 2.0~7.0m |
| 형상 | 고정 삼각형의 각 변을 중심으로 반지름 0.4m의 캡슐 띠, 전체 폭 0.8m. 내부 전체 공격 아님 |
| 선딜 / 경고 / 후딜 | 0.60 / 세 변 경고 0.60 / 0.20초 |
| 피해 / 둔화 | 140 + 0.80 × 위력, 30% 둔화 1.0초, 전체 R에서 같은 대상 1회 |
| 비용 / 재사용 | 에너지 32 / 15.0초, 승인 시 시작 |
| 구조물 | 세 변에 닿은 노출 구조물은 0.5배 피해, 꼭짓점에 겹쳐도 1회 |

꼭짓점 A는 승인 시 리오 위치, B는 조준점이다. C는 A와 B의 중점에서 A→B 방향의 왼쪽 수직 방향으로 3.0m 떨어진 점이다. 미리보기는 세 점·세 변·폭을 정확히 표시한다.

2m보다 가깝거나 7m보다 먼 조준은 불법으로 표시해 거부한다. B/C가 이동 불가 지면이거나 세 변 중 하나가 벽을 통과하면 전체 시전을 거부한다. 구조물은 벽으로 취급하지 않는다.

삼각형은 승인 후 고정되며 한 번에 타격한다. 교차하는 두 변에 닿아도 중복 피해가 없고, 삼각형 안쪽에서 테두리와 겹치지 않는 적은 안전하다. R은 Q의 회수점을 만들거나 소비하지 않는다.

선딜 중 이동은 불가능하다. 기절·넉백·사망은 전체를 취소하고 속박은 취소하지 않는다. 상대는 테두리 밖 또는 충분히 넓은 내부로 이동하거나 선딜을 끊을 수 있다. 하드 CC는 없다.

## 7. 성장 선택과 수치 기준

| 선택 | 13점 완성 예시 | 의도 |
|---|---|---|
| 경로 압박 | 위력 5, 체력 3, 에너지 회복 2, 이동속도 2, R 1 | Q 반복과 옆 라인 이동 |
| 추격 생존 | 위력 3, 체력 4, 방어 3, 에너지 회복 1, 이동속도 1, R 1 | 바스 진입·다수 견제 대응 |

시작 2점은 위력 1·체력 1을 교육 예시로 사용한다. 에너지 회복을 선택하면 원반을 빗맞힌 손실이 줄지만 위력·생존 성장에 쓸 점수가 줄어든다.

위력 100·방어 0 기준 Q는 출발 115 + 귀환 85 = 200, W는 65, 강화 기본공격은 90 + 65 = 155, R은 220이다. 전부 적중하는 총 640은 위치·타이밍이 모두 맞아야 하는 이론값이며 즉발 콤보가 아니다.

Q/W/E/R 전체 비용은 84, 패시브 성공 시 순비용은 76이다. 기본 자연 회복만으로 모든 기술을 재사용마다 계속 쓸 수 없도록 회복 선택과 빗맞힘을 관측한다.

Q 두 단계가 타워에 맞으면 라인 미니언 동반 시 총 100, 없으면 30 피해다. 타워 적중으로 패시브 에너지 환급을 얻지 않는다.

- 애니메이션: 대기·달리기·기본공격·Q 투척·W 매듭 놓기·E 옆디딤·R 세 점 지정·피격·사망 각 1세트.
- VFX/SFX: 출발/회전 대기/귀환을 구분하는 원반 홈 방향과 정지 표시, 회수점 수명, 귀환선, 강화 1회, 삼각 경고/타격, 지형 충돌/소멸음.
- UI: Q 단계·패시브 성공, W 남은 시간, E 강화 남은 시간, R 불법 꼭짓점/벽 차단 이유를 표시한다.
- 튜토리얼: 정지 표적 왕복 적중 → 첫 적중 뒤 옆걸음으로 회피 → Q 출발 중 E → W 회수점 → R 내부 안전지대 찾기 순서다.
- 검증 기준 R01: 같은 대상이 한 Q 출발에 1회·귀환에 1회만 맞고, 두 명을 왕복 적중해도 에너지 환급은 8이다.
- 검증 기준 R02: 귀환 시작 전 W 생성/만료, 귀환 시작 뒤 W 생성, E 전후 이동에서 목적지가 명세대로 한 번만 확정된다.
- 검증 기준 R03: 귀환 중 벽에 막히거나 소유자가 죽으면 원반이 사라지고 지연 피해·에너지 환급이 발생하지 않는다.
- 검증 기준 R04: E는 속박을 무시하지 않으며 강화 공격으로 공격 간격이나 사거리가 늘지 않는다.
- 검증 기준 R05: R의 세 변·꼭짓점 중복은 1회 피해, 내부는 0회 피해, 벽 통과 삼각형은 승인 전 무소모 실패다.
- 검증 기준 R06: 50/100/150ms RTT에서 목적지 확정 이벤트·표시 선·서버 충돌 결과가 같은 투사체 ID/단계 ID를 가리킨다.
- 조정 순서: 귀환선 인지성 → Q 속도·폭 → E 재사용 → R 폭·경고 → 피해. 초심자 명중률을 올리기 위해 자동 추적을 추가하지 않는다.

위력 100 기준 예시는 공식 비교용이다. 일반 경기는 레벨 1·2포인트·R 잠금으로 시작하고, 기술 체험은 여섯 영웅 모두 레벨 3·위력 106·R 해금·잔여 3포인트로 시작한다. 양 팀 성장 조건을 다르게 만들어 체험 난도를 낮추는 모드는 아니다.

위의 성장 배분·튜토리얼·봇 목표 행동은 플레이 선택과 후속 제작 기준이다. 현재 봇이 모든 상황에서 그 전술을 수행한다고 해석하지 않는다. 패시브 전용 HUD, 최종 모델·애니메이션·소리, RTT별 재현과 사람 간 대응 가능성 검증은 각각 [UI](../06-ui-and-controls.md), [아트](../07-art-direction.md), [로드맵](../08-roadmap.md)의 상태를 따른다. 구현과 설계의 차이는 [차이 기록](../10-differences.md)에 남긴다.
