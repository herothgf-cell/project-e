## 1. 플레이 약속

네마는 배낭에서 펼친 두 개의 세라믹 핀으로 수로 설비의 임시 회로를 잇는 길드 기술자다. 중간 높이의 몸과 접이식 장치를 사용해 무거운 바스·가벼운 리오와 구분한다.

준비한 연결선 주변에서 아군을 보호하고, 선형 공격을 예고해 상대의 길을 바꾼다. 적은 핀을 파괴하거나 선의 옆으로 돌아가 효과를 끊을 수 있다. 핀 자체가 자동으로 적을 공격하지 않는다.

| 기본 정보 | 제안값 |
|---|---|
| 역할 / 조작 난도 | 장치 기반 지원·짧은 구역 제어 / 중간 |
| 체력 / 이동속도 / 방어력 | 1,000 / 6.0m/초 / 0 |
| 위력 / 에너지 / 회복 | 100 / 100 / 8/초 |
| 기본공격 | 사거리 5.5m, 60 + 0.3 × 위력, 간격 1.0초 |
| 유리한 상황 | 짧은 연결로, 미리 준비한 타워 앞, 아군이 핀의 측면을 지키는 교전 |
| 불리한 상황 | 이동하면서 계속 싸우는 추격전, 핀이 파괴된 직후, 두 방향에서 동시에 접근하는 적 |

## 2. 소유 장치 — 연결 핀

- 네마 1명당 최대 2개다. Q로 세 번째를 정상 생성하면 기존 핀 중 생성 시각이 가장 이른 것을 제거한다. 동률은 장치 ID 순서로 정한다.
- 핀은 체력 160·방어력 0, 생성 뒤 수명 8초다. 레벨·위력·체력 성장으로 핀 체력이 증가하지 않는다.
- 적 영웅의 기본공격과 피해 기술은 핀을 공격할 수 있다. 미니언·타워의 자동 표적에는 포함하지 않으며 핀에 처치 경험치·크레딧은 없다.
- 적 핀 직접 클릭은 보이는 경우에만 공격 명령이 된다. 아군 핀 클릭은 이동 명령이며 공격·수선 대상 지정으로 바꾸지 않는다. E는 부채 범위로 자기 핀을 수선하고, 겹친 표적 선택은 [공통 클릭 우선순위](README.md#3-기본공격과-구조물)를 따른다.
- 핀의 피격 반지름은 0.35m다. 이동·투사체를 물리적으로 막지 않으며, 관통 기술은 핀을 맞힌 뒤 계속 이동한다.
- 핀은 시야·은신 탐지·미니언 어그로·타워 어그로 분산·공성 보호 해제를 제공하지 않는다. 핀의 피해는 항상 소유자 네마에게 귀속한다.
- 적의 핀 표시는 팀 공유 시야에 들어왔을 때만 나타난다. 자신의 핀 위치·수명은 항상 HUD에서 볼 수 있으나 주변 적 정보를 주지 않는다.
- 두 핀 사이 거리가 1.0~8.0m이고 직선이 벽을 통과하지 않으면 연결된다. 구조물은 연결선을 차단하지 않는다.
- 핀 하나가 사망·만료·교체되면 연결은 즉시 사라진다. 네마 사망 시 핀 2개와 해당 핀을 기다리는 모든 기술을 제거한다.
- 장치 체력·소유자·생성/만료 시각·연결 대상은 서버 상태다. 표시용 선만 클라이언트에서 생성하고 피해를 계산하지 않는다.
- W/R은 소유 장치 명령이므로 핀의 현재 공유 시야를 요구하지 않는다. 네마와 핀 사이 벽은 명령을 막지 않지만 핀 사이 벽은 연결을 끊으며, 피해·보호막은 [공통 영역 벽 판정](README.md#2-공통-입력과-수치-표현)을 따른다.

## 3. 패시브 — 이어받는 막

두 핀 중심을 양 끝으로 하는 전체 폭 0.5m 직사각형 영역에 자신 또는 아군 영웅이 들어오면 `60 + 0.20 × 위력` 보호막을 1.2초간 받는다. 시작 위력에서는 80이다. 같은 네마는 동일 영웅에게 4초에 한 번만 이 효과를 줄 수 있다.

- 새 연결선이 생겼을 때 이미 영역에 있는 아군도 1회 진입으로 취급한다. 4초 내부 재사용은 핀 교체·재연결·아군 이탈로 초기화되지 않는다.
- 선 안에 계속 서 있는 동안 반복 발동하지 않는다. 내부 재사용이 끝난 뒤 선 밖에서 다시 들어와야 새 보호막을 받는다.
- 영역을 벗어나거나 핀이 파괴되어도 이미 얻은 보호막은 정해진 만료까지 남는다. 적·미니언·셀·핀·구조물은 효과를 받지 않는다.
- 피해·둔화·속박·에너지 회복은 없다. 핀과 연결선이 공격자의 시야 밖에 있더라도 적중 정보를 수집하지 않는다.
- 네마 사망 시 연결선은 없어지고 대상별 내부 재사용 기록은 부활까지 유지한다. 같은 출처 보호막을 잔량 합산하지 않는다.

## 4. Q — 짝핀 놓기

| 항목 | 제안 사양 |
|---|---|
| 조준 / 범위 | 지면 조준, 중심 사거리 6.0m, 생성 파동 반경 1.25m |
| 선딜 / 경고 / 후딜 | 0.25 / 원형 경고 0.25 / 0.12초 |
| 파동 피해 | 65 + 0.35 × 위력, 같은 대상 1회, 제어 효과 없음 |
| 생성 / 비용 | 파동과 동시에 체력 160 핀 생성 / 에너지 14 |
| 재사용 | 2.5초, 승인 시 시작. 충전형 기술이 아님 |
| 구조물 | 생성 파동은 노출 구조물에 0.5배 피해, 핀은 공격하지 않음 |

걸을 수 있고 네마와 벽으로 차단되지 않는 지면에만 설치한다. 구조물 내부나 자신의 다른 핀 중심에서 1m 미만인 지점은 불법이다. 적 핀의 숨은 위치로 설치 성공 여부가 달라지지 않는다. 범위 밖 조준은 승인 전 실패한다.

선딜 중 기절·넉백·사망은 파동과 생성을 모두 취소한다. 세 번째 핀의 선딜이 취소된 경우 기존 두 핀을 제거하지 않는다. 생성 시점에 지점이 불법이 되면 생성·파동을 취소하고 이미 지불한 비용은 유지한다.

핀은 생성 직후부터 파괴 가능하다. 생성 파동에 적이 없더라도 정상적으로 핀이 생긴다. 파동이 적 영웅을 맞히면 일반 소유자 피해·타워 반응 규칙을 따른다.

상대는 파동을 피하고 생성된 핀을 공격할 수 있다. 위력 100의 기본공격 90으로 중간 수선 없이 핀을 두 번 맞히면 파괴된다. 핀 설치가 한 번의 공짜 자동 공격을 계속 만드는 구조는 아니다.

## 5. W — 직조 박동

| 항목 | 제안 사양 |
|---|---|
| 조준 / 사용 조건 | 방향 없는 장치 명령. 살아 있는 핀 1개 또는 정상 연결 1쌍 필요 |
| 명령 사거리 | 단일 핀 또는 연결선의 최근접점까지 8.0m 이내. 범위 밖이면 승인 전 실패 |
| 형상 | 핀 1개면 그 핀 중심 반경 1.5m, 정상 연결이면 두 핀 중심을 양 끝으로 하는 폭 1.4m 직사각형 |
| 선딜 / 경고 / 후딜 | 0.35 / 사용 형상 전체 경고 0.35 / 0.12초 |
| 피해 / 제어 | 75 + 0.45 × 위력, 25% 둔화 0.9초, 같은 대상 1회 |
| 비용 / 재사용 | 에너지 18 / 3.5초, 승인 시 시작 |
| 구조물 | 0.5배 피해, 둔화 없음. 미니언·셀·적 핀에도 정상 피해 |

핀 2개가 있지만 거리·벽 때문에 연결되지 않았으면 W는 실패한다. 임의로 하나를 고르거나 원형 두 개를 발사하지 않는다. HUD에는 두 핀 사이의 끊긴 선과 실패 이유를 표시한다.

승인 순간 참여 핀 ID와 경고 형상을 고정한다. 선딜 중 하나라도 파괴·만료·교체되면 전체를 취소한다. 남은 핀 주변 원형으로 뒤늦게 바꾸지 않는다. 이 취소도 이미 지불한 비용을 돌려주지 않는다.

네마의 기절·넉백·사망 역시 선딜을 취소한다. 속박은 시전을 막지 않는다. 타격 시점의 범위 안 대상만 맞으며, 피해 판정 뒤 핀이 없어져도 이미 처리한 피해는 유지한다. W/R은 핀 생성 시점이 아닌 각 명령 승인 시의 위력을 사용한다.

상대는 0.35초 경고 동안 선에 수직으로 이동하거나 핀 하나를 마무리한다. 선 끝에 서 있으면 더 빨리 벗어날 수 있지만 아군과 동선이 겹칠 수 있다.

## 6. E — 수선 부채

| 항목 | 제안 사양 |
|---|---|
| 조준 / 범위 | 방향 조준, 전방 70도·반경 6.0m 부채. 네마 자신도 항상 포함 |
| 선딜 / 경고 / 후딜 | 0.16 / 아군용 부채 경고 0.16 / 0.14초 |
| 영웅 효과 | 자신·영역 내 아군 영웅에 100 + 0.40 × 위력 보호막, 1.8초 |
| 핀 효과 | 부채 안 자신의 핀 체력을 50 회복, 최대 160. 수명은 연장하지 않음 |
| 비용 / 재사용 | 에너지 18 / 5.0초, 승인 시 시작 |
| 피해 / 구조물 | 피해·회복 없음. 타워·핵·미니언·다른 소유자 장치에는 효과 없음 |

부채는 벽 너머 아군·핀에 닿지 않는다. 핀 없는 상태에도 자기·아군 보호 목적으로 사용할 수 있으며, 현재 체력을 회복하거나 상태이상을 해제하지 않는다.

선딜 중 기절·넉백·사망은 전체를 취소한다. 속박은 취소하지 않는다. 생성된 보호막은 네마가 죽거나 핀이 없어져도 만료까지 유지한다. 패시브 보호막과는 별도 출처다.

상대는 1.8초를 기다리거나 부채 밖의 목표를 노린다. E로 핀을 수선하는 동안 네마는 이동하지 못하므로 배치 유지를 위해 노출을 감수한다.

## 7. R — 결박 봉합

| 항목 | 제안 사양 |
|---|---|
| 해금 / 조건 | 레벨 3 이상 + 성장점 1, 정상 연결된 핀 2개 필요 |
| 조준 / 사거리 | 방향 없는 장치 명령, 연결선 최근접점까지 8.0m 이내 |
| 형상 | 두 핀 중심을 양 끝으로 하는 폭 2.2m 직사각형. 양 끝은 평평하며 끝점 바깥으로 연장하지 않음 |
| 선딜 / 경고 / 후딜 | 0.60 / 전체 선 경고 0.60 / 0.20초 |
| 피해 / 제어 | 120 + 0.65 × 위력, 속박 0.60초, 같은 대상 1회 |
| 비용 / 재사용 | 에너지 30 / 18.0초, 승인 시 시작 |
| 소모 / 구조물 | 정상 타격 이벤트 직후 핀 2개 제거. 구조물 피해 0.5배, 속박 없음 |

승인 시 참여 핀 ID·위치·폭을 고정한다. 타격 전 하나라도 파괴·만료·교체되면 전체가 취소되며 남은 핀은 정상 수명대로 남는다. 적을 맞히지 못해도 정상 발동했다면 핀 2개를 소비한다.

선딜 중 네마의 기절·넉백·사망은 취소하고 속박은 취소하지 않는다. 취소 비용은 환급하지 않는다. 정상 발동한 속박은 공통 CC 상한을 지키며 대상의 정지형 기술 사용은 막지 않는다.

상대는 선의 옆으로 이동하거나 낮은 체력 핀을 파괴할 수 있다. 네마는 R 직후 연결선·패시브를 잃으므로 큰 효과를 쓰고 다시 준비할 시간을 감수한다.

## 8. 성장 선택과 수치 기준

| 선택 | 13점 완성 예시 | 의도 |
|---|---|---|
| 반복 지원 | 체력 4, 방어 3, 에너지 회복 3, 위력 2, R 1 | 핀 재배치와 아군 보호 |
| 구역 압박 | 위력 5, 체력 3, 방어 1, 에너지 회복 2, 이동속도 1, R 1 | W/R 피해와 라인 전환 |

시작 2점은 체력 1·에너지 회복 1을 교육 예시로 쓴다. 성장으로 핀을 단단하게 만들 수 없으므로 장치 배치와 아군 엄호가 끝까지 중요하다.

위력 100·방어 0에서 Q는 100, W는 120, R은 185다. 두 번의 Q + W + R은 505 피해와 에너지 76을 요구하며, Q 재사용 때문에 준비에 최소 2.5초가 걸린다. E까지 사용하면 총비용 94다.

패시브 80 + E 140 보호막은 서로 다른 출처로 함께 유지할 수 있다. E는 핀 1개당 최대 50만 복구하고 수명은 늘리지 않으므로 영구 방어선을 만들지 않는다.

## 9. 에셋·튜토리얼·완료 판정

- 에셋: 중간 키의 작업복, 접이식 배낭, 핀 모델 1종과 정상/피해/파괴 상태, 핀 체력·수명 HUD. 장치 파괴는 작은 잔해로 짧게 정리한다.
- 애니메이션: 대기·달리기·기본공격·Q 설치·W 명령·E 수선·R 연결 닫기·피격·사망 각 1세트.
- VFX/SFX: 연결 유효/거리 초과/벽 차단, 패시브 보호막, W/R 폭별 경고, 핀 수명 마지막 1초 경고, 파괴·취소음.
- 튜토리얼: Q 두 번 → 선 통과 보호막 → W → 적 입장에서 핀 두 번 공격 → R로 핀 소비 → E로 장치 없이 아군 보호 순서다.
- 검증 기준 N01: 세 번째 Q가 성공한 순간에만 가장 오래된 핀을 교체하며, 사망·만료 시 유령 선·지연 피해가 남지 않는다.
- 검증 기준 N02: 핀은 기본공격 두 번에 파괴되고 미니언·타워 표적·시야·공성 보호 해제·처치 보상을 발생시키지 않는다.
- 검증 기준 N03: 연결선을 생성·파괴·재생성해도 같은 영웅의 패시브 4초 제한이 초기화되지 않고, 선 안 정지로 반복 발동하지 않는다.
- 검증 기준 N04: W/R 선딜 중 핀 파괴·교체·만료 시 전체 취소, R 정상 발동은 빗맞혀도 두 핀 소모, 예고 후 원형으로 변경 없음.
- 검증 기준 N05: E는 핀 최대 체력·수명을 넘기지 않으며, 벽 뒤 대상을 보호하지 않고 현재 영웅 체력을 회복하지 않는다.
- 검증 기준 N06: 50/100/150ms RTT에서 핀 ID·연결 상태·경고 취소·피해 이벤트 순서를 확인한다. 숨은 적에게 피해가 들어가도 적중 피드백은 없다.
- 조정 순서: 핀 파괴·수명 가독성 → 설치 간격 → W/R 경고 폭 → 명령 사거리 → 보호막·피해. 핀을 무적으로 바꾸어 실패를 숨기지 않는다.

위력 100 기준 예시는 공식 비교용이다. 일반 경기는 레벨 1·2포인트·R 잠금으로 시작하고, 기술 체험은 여섯 영웅 모두 레벨 3·위력 106·R 해금·잔여 3포인트로 시작한다. 양 팀 성장 조건을 다르게 만들어 체험 난도를 낮추는 모드는 아니다.

위의 성장 배분·튜토리얼·봇 목표 행동은 플레이 선택과 후속 제작 기준이다. 현재 봇이 모든 상황에서 그 전술을 수행한다고 해석하지 않는다. 패시브 전용 HUD, 최종 모델·애니메이션·소리, RTT별 재현과 사람 간 대응 가능성 검증은 각각 [UI](../06-ui-and-controls.md), [아트](../07-art-direction.md), [로드맵](../08-roadmap.md)의 상태를 따른다. 구현과 설계의 차이는 [차이 기록](../10-differences.md)에 남긴다.
