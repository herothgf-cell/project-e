# C07 세라 · 월영 쌍검사

2026-11-09 V8 로컬 프로토타입 설계. 이 시트의 신규 전투 수치와 실제 효과는 V8 실험 설계다. 수치는 아래 구현 및 행동 검사와 대응한다.

짧은 돌진과 쌍검으로 보이는 적에게 월영 표식을 쌓는 근접 암살자다. 얇은 초승달 모양 칼날과 보라색 표식 두 조각으로 공격 리듬을 드러낸다.

## 플레이와 초기값

Q와 E로 표식을 두 개 쌓고 기본 공격으로 소비한다. 상대가 기본 공격 거리를 벌리면 R의 좁은 부채로 표식을 마무리할 수 있다. W는 진입 직후의 반격을 잠깐 흡수한다.

|---|---|
| 체력 / 이동속도 / 방어력 | 900 / 6.5m/초 / 0 |
| 기본 공격 | 사거리 1.8m, 선딜 0.13초, 간격 1초, 60 + 0.30P 피해 |
| 위력 P / 마나 / 마나 회복 | 100 / 100 / 초당 8 |

| 선택 시 동쪽 팀 북 / 중앙 / 남 | 바스 / 오린 / 테르 |

기본 공격 피해와 각 기술 예시값은 위력 100·방어 0·보호막 없음 기준이다. 경기 인원은 양 팀 3명씩이며 플레이어는 중앙 라인을 맡는다.

## 패시브 · 달의 낙인

달의 낙인은 보이는 적 영웅에게 자기 표식 2중첩이 있을 때 정상 기본 공격에 55 + 0.30P 추가 피해를 합쳐 적용하고 두 중첩을 소비한다. 위력 100 기본 공격은 90, 추가는 85, 합계 175다. 발사 전에 대상이 사거리·직선 시야·팀 공유 시야를 벗어나거나 보호 중이면 표식을 소비하지 않는다. 다른 세라의 표식은 소비하지 않는다.

### Q · 초승 베기

| 항목 | V8 구현 |
|---|---|
| 조준과 형상 | 방향, 반경 2.8m·60도 전방 부채 |
| 수치 | 65 + 0.40P = 105 피해 |

실제 피해가 발생한 보이는 적 영웅에게 자기 표식 1중첩을 부여한다. 대상별 최대 2중첩, 새 적중마다 만료를 5초로 갱신한다.

짧은 부채 측면으로 이동해 표식 첫 단계를 끊는다.

### W · 달그림자

| 항목 | V8 구현 |
|---|---|
| 조준과 형상 | 자신, 표시 반경 0.45m |
| 수치 | 90 + 0.30P = 120 보호막, 1.5초 |

자기 자신에게만 보호막을 준다. 같은 출처 재사용은 높은 잔량과 갱신된 지속시간을 사용한다.

보호막이 끝날 때 반격하거나 세라의 다른 진입 경로를 막는다.

### E · 월영 쇄도

| 항목 | V8 구현 |
|---|---|
| 조준과 형상 | 방향, 최대 4m 이동, 속도 17m/초 |
| 수치 | 적 영웅 접촉 시 50 + 0.30P = 80 피해 |

벽과 첫 아군·적 영웅 앞에서 정지한다. 아군 접촉은 피해 없이 막힌다. 적에게 실제 피해가 발생하고 보이면 표식 1중첩을 부여한다.

동료와 경로를 막거나 이동 중 속박·기절로 멈춘다.

### R · 그믐의 심판

| 항목 | V8 구현 |
|---|---|
| 조준과 형상 | 방향, 반경 3.5m·55도 전방 부채 |
| 수치 | 100 + 0.50P = 150 기본 피해 |

보이는 적 영웅에게 자기 표식 1중첩당 35 + 0.15P = 50을 추가한다. 위력 100에서 0/1/2중첩 피해는 150/200/250이다. 실제 피해가 발생한 뒤 사용한 표식을 모두 소모한다.

좁은 부채 옆으로 이탈하거나 5초 동안 교전을 끊어 표식을 만료시킨다.

## 상태와 예외

표식에는 대상 ID·스택·만료만 저장한다. 숨은 적의 위치를 저장하거나 드러내지 않는다. Q/E는 보이는 적 영웅에게만 표식을 주며 숨은 대상은 R 추가 피해와 패시브 소비 조건을 만족하지 않는다. 대상 사망·소유자 사망·만료·경기 리셋에 표식을 제거한다.

Q/W/E/R 키로 기술을 선택한 뒤 좌클릭 지점으로 시전한다. 방향 기술은 자기 위치와 다른 지점을 지정해야 한다. 자기 보호·가속은 자기 위치 클릭도 허용한다. R은 레벨 3과 성장점 1로 해금하며 기술 체험에서는 처음부터 열린다.

비용과 재사용은 시전 승인 때 시작한다. 선딜 중 기절·넉백·사망으로 취소되면 비용을 환급하지 않는다. 속박은 보행과 이동기를 막고 정지형 기술은 허용한다. 테르·세라 E와 기존 바스·리오 E는 명시적 이동기 판정을 공유한다. 시전된 기술의 중심·방향·위력은 승인 시 고정하며 별도 설명한 현재 상태 조건은 발동 때 검사한다.

오린 E, 테르 W, 무아 W/E, 세라 W, 루메 E는 지원기로서 부활 보호를 유지한다. 공격기와 이동기 사용은 부활 보호를 해제한다. 일반 기본 공격은 부활 보호를 해제한다.

피해는 공통 판정을 사용한다. 방어 감소는 100 / (100 + 방어력), 영웅의 구조물 피해는 0.5배다. 아군 라인 병력이 구조물 12m 안에 없으면 다시 0.3배가 된다. 잠긴 구조물과 보호 중인 표적은 피해를 받지 않는다. 둔화·속박은 영웅과 미니언에만 적용한다. 강제 제어는 1회 최대 1초와 최근 3초 합계 1.5초 규칙을 따른다.

영역 타격은 형상과 대상 충돌 반경의 교차 및 공통 직선 시야를 검사한다. 선형 공격은 벽에서 잘리고 원형·부채는 범위 안이라도 벽 뒤 적을 맞히지 않는다. 지면 지정은 거리·걸을 수 있는 지면·시전자와 목표 사이 직선 시야를 검사한다. 방향형 영역은 팀 시야 밖에도 타격할 수 있으며 표식 부여·소비는 각 영웅의 가시성 조건을 추가로 따른다.

보호막은 아군 영웅에만 제공한다. 같은 소유자·기술 출처는 높은 잔량을 유지하고 지속시간을 갱신하며 다른 출처는 함께 유지된다. 시간제 보행 가속은 가장 높은 비율 하나를 적용하고 둔화와 곱한다. 보호·가속이 아군에게 이미 부여되었다면 시전자 사망 뒤에도 대상에서 정해진 수명까지 유지된다. 자기 준비·표식·구역·가속·예약타격은 소유자 사망과 경기 초기화에 정리된다.

## 검증과 조정

자동 행동 검사는 실제 명령과 30Hz 시뮬레이션으로 피해·보호막·이동·시간 만료·중복 적중·사망 정리·제어·벽·시야·다중 소유를 확인한다. 실행 결과와 전체 회귀는 V8 검증 기록을 따른다. 봇은 공통 시전 명령으로 신규 기술을 사용하며, 실제 플레이의 체감 난도와 상성 수치는 후속 수동 검토 대상이다.

우선 조정 대상은 예고의 읽힘, 기본 공격과 기술의 연결 시간, 제어 후 회피 여유, 팀 보호 기여도다. 한 번의 기술 체험으로 최종 밸런스를 확정하지 않는다.
