# 첫 고저차 전투 구역 구현·검증

- 기준일: **2026-10-28, Asia/Seoul**.
- 범위: R28의 첫 시험 구역. 북서40XP 셀 `(-18,24)`과 남동40XP 셀 `(18,-24)`을 기존 진입로 위에 올린다.
- 높이: 고지 상단 **2.4m**, 각 라인에서 고지로 이어지는 기존3m 폭 접근로의 첫4m를 경사로로 사용한다.
- 게임 수치: XP20/30/40, 셀HP180, 첫 생성30초/재생성45초, 포탑8.5m, 영웅 능력치와 소모품 수치는 변경하지 않았다.
- 실제 엔진 검증: GitHub Actions [Godot regression #1](https://github.com/herothgf-cell/project-e/actions/runs/40649521194), Godot **4.7.2.stable.official.ed1daf0bf**.

## 1. 구현 규칙

### 보행과 높이

기존 2D 통행 가능 영역과 AStar 경로를 그대로 권한으로 사용한다. 새 `ground_height(point)`는 같은 시뮬레이션 좌표에 표현·시야용 높이를 제공한다.

- 낮은 라인 지면:0m.
- 40XP 진입 경사:0→2.4m 선형 보간.
- 40XP 셀 발판:2.4m.
- 절벽을 자유롭게 오르는 새 통행은 없다. 기존 셀 접근로가 유일한 경사 연결이다.

유닛 모델, 클릭 지점, 체력/에너지 바, 시야원 표식, 스킬/공격 경고는 같은 높이 함수를 사용한다. 화면 좌표→지면 변환은 고정 `Y=0` 평면 대신 카메라 레이와 높이 필드를 반복 교차해 고지/경사를 선택한다.

### 시야

고저차 시야와 물리선은 분리했다.

- 영웅·병력: 낮은 곳에서는 고지 상단을 팀 시야로 밝히지 못한다.
- 고지 위 영웅·병력: 아래쪽을 볼 수 있다.
- 포탑·핵: 방어 구역에 고지 사각이 생겨 일방 공성이 되지 않도록 기존12m 시야 안에서는 고지를 감시한다.
- 벽은 기존과 동일하게 모든 시야원의 LOS를 차단한다.
- 공격/스킬의 물리선 자체는 높이를 가짜 벽으로 취급하지 않는다. 실제 대상 공격 가능 여부는 팀 시야와 기술별 기존 규칙을 함께 사용한다.

전장 음영과 미니맵은 권한 시야를 계속 사용한다. 시야원 마우스오버 윤곽도 벽+고저차 규칙을 반영한다. 고지는 고정 지형이므로 미니맵에 이중 산형 표식으로 위치를 표시하지만, 그곳의 적·셀 생존/HP는 시야 밖에서 공개하지 않는다.

## 3. 아직 완료하지 않은 것

이 검증은 전체 맵 고저차 완성이 아니다.

- 다른 라인/연결로의 언덕·절벽.
- 고지 공격 시 일시 노출 같은 추가 상대 대응 규칙.
- 고지에서 리오/네마/바스의 사람 조작감과 상대법.
- XP 셀을 실제로 목표 삼는 봇 판단.
- 고지와 타워/XP/지원로의 최종 위치 조정.
- 실제 Windows PC 프레임·DPI·Alt-Tab.
- 사람1명+봇5명 및 사람6인 경기.
- Windows 배포 ZIP 재생성.

다음 공간 작업은 현재 수치를 유지한 채 **고지40XP 경합→인접 라인 지원→외곽 포탑 진입/퇴각**의 선택을 만드는 R30 배치 실험이다. 사람 관찰 전에는 고지 높이·XP 보상·포탑 공격력 등을 동시에 바꾸지 않는다.
