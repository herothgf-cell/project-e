# 원작 병력·공성·아이템

병력은 전선을 만들고 영웅의 성장과 마무리 공격을 유도한다. 측면 경험치 목표는 라인 밖의 성장 경로를 제공한다. 공성 대상은 전방에서 후방으로 이어지며, 포션과 카드는 이 과정에 사용할 자원과 행동을 바꾼다. [S01, 2·4–6쪽](06-evidence-and-open-questions.md#s01)

## 병력과 보상 목록

| 원작 표기 | 확인한 획득 가스 | 출처에서 확인한 범위 | 추가 데이터 |
|---|---:|---|---|

| 저격수 | 25 | 라인몹 보상표 | 생성 조건·사거리·공격·XP |
| 특공대 | 50 | 라인몹 보상표 | 생성 조건·HP·공격·XP |
| 분대장 | 75 | 라인몹 보상표 | 생성 조건·전투 행동·XP |
| 경험치 캡슐 | 15 | 측면 성장 목표와 가스 보상 | 수량·HP·재생성·XP |
| 경험치 탱크 | 100 | 경험치통 보상표 | 트럭 표기와의 관계·HP·재생성·XP |

근거는 PDF 2·4–5쪽이다. 획득량 열은 자료의 가스 표기를 사용한다. 경험치 분배와 구매 자원의 관계는 [성장과 경제](03-growth-and-economy.md)에서 다룬다. [S01](06-evidence-and-open-questions.md#s01)

## 일반 병력의 마무리 공격 제한

| 자료에 나타난 규칙 | 확인한 설명 | 정밀 재현에 필요한 값 |
|---|---|---|
| 공격 중단 | 상대가 낮은 HP에 도달하면 일반 병력이 공격을 멈춤 | 고정 HP·최대 HP 비율의 적용 방식 |
| 잔여 HP의 예시 | 적 영웅과 방어타워에도 약 30 HP를 남기는 설명 | 대상별 임계값 |
| 이후 이동 | 낮은 HP의 대상을 남기고 전진 | 새 대상 탐색과 이동의 우선순위 |
| 병력 간 처치 예외 | 공격 속도 차이로 서로 처치하는 경우 서술 | 선딜·이미 발사한 공격·동시 타격 처리 |
| 예외 공격 주체 | 소대장·중대장·대대장·가오수로봇·최후 건물·포트리스 방어타워가 예외 목록 | 각 개체의 처치·목표 선택 규칙 |

이 규칙은 PDF 4쪽에서 확인했다. 보상표의 분대장과 예외 목록의 소대장은 출처 표기가 다르므로 개체 ID를 확인할 때까지 이름을 각각 유지한다. [S01](06-evidence-and-open-questions.md#s01)

### 병력 AI의 복원 상태

다음 표는 자료의 행동을 상태로 풀어 쓴 역설계 모델이다. 원본 데이터가 확보되면 조건과 실행 순서를 채운다.

| 현재 상태 | 관찰할 조건 | 동작 | 다음 상태 |
|---|---|---|---|
| 라인 전진 | 공격 가능한 적이 범위에 들어옴 | 적을 대상으로 선택 | 접근 또는 공격 |
| 대상 접근 | 사거리 안에 도달 | 공격 시도 | 공격 대기 |
| 공격 대기 | 대상 HP가 중단 기준보다 높음 | 피해를 주는 공격 실행 | 재사용 대기 또는 대상 재평가 |
| 대상 재평가 | 대상 HP가 중단 기준에 도달 | 일반 병력의 추가 공격 중단 | 다른 대상 탐색 또는 전진 |
| 공격 진행 중 | 다른 공격으로 대상이 기준 아래에 도달 | 이미 진행된 공격의 처리 관찰 | 피해·취소·처치 중 실제 결과 기록 |
| 예외 개체의 공격 | 예외 개체가 같은 대상을 공격 | 마무리 가능한지 확인 | 대상 처치 또는 공격 지속 |

병력의 마무리 제한은 영웅에게 전선에 머무를 이유를 준다. 약화된 적을 처리하는 동안 적 영웅과의 거리, 광역 공격, 다음 웨이브의 접근을 함께 판단하게 된다. 이는 자료의 규칙으로부터 도출한 플레이 해석이다.

### Project E의 1 HP 적용

Project E V6는 일반 근접·원거리 병력이 적에게 1 HP를 남기도록 구현했고, 이 조건의 표적을 재평가하도록 정했다. 해당 문서는 1 HP를 현재 게임의 체력·피해 체계에서 선택한 값으로 기록한다. 원작의 약 30 HP 설명과 비율 설명을 정확히 재현하려면 원본 데이터가 더 필요하다. [V6 적용 기록](../26-cot-reference-v6.md)

| 검토 항목 | 원작의 확인 상태 | Project E에서 확인할 항목 |
|---|---|---|
| 낮은 HP의 적 유지 | 자료로 확인 | 실제 적용 피해와 보상 발생 시점 |
| 영웅의 마무리 | 규칙의 플레이 결과 | 영웅 공격으로 정상 처치 가능한가 |
| 재탐색과 전진 | 전진 서술 확인 | 같은 대상에게 계속 공격하는가 |
| 보호막 | 병력 제한과의 조합은 미확인 | 잔여 HP에서 보호막 처리 |
| 공성 병력·포탑 | 원작 예외 목록 존재 | 현재 예외 주체가 마무리 가능한가 |

## 경험치 캡슐과 대형 목표

| 구분 | 자료 확인 | 플레이 의미 | 확인할 상태 |
|---|---|---|---|
| 위치 | 각 라인 옆 구역 | 라인 이탈 거리와 성장 기회를 연결 | 정확한 좌표와 접근 경로 |
| 획득 방식 | 파괴 시 경험치 획득 | 공격 행동과 시간이 필요 | 공격 가능한 상태와 HP |
| 재생성 | 일정하게 다시 등장 | 반복되는 이동 선택 제공 | 최초 생성·재생성 시점 |

PDF 4쪽의 트럭과 5쪽의 탱크가 같은 개체인지 확인이 필요하다. 주변의 살아 있는 영웅에게 보상이 공유되는지, 파괴 주체에게만 지급되는지, 소환물의 처치가 어떻게 귀속되는지도 원본 관찰 항목이다. [S01, 4–5쪽](06-evidence-and-open-questions.md#s01)

## 아이템과 카드

PDF는 조합이 없는 단순한 구매 경로를 설명하고, 상세 아이템·카드 목록은 제작자의 별도 문서로 연결한다. 현재 확보한 원본에서는 포션의 기능과 구매 선택의 영향을 확인할 수 있다. [S01, 4·8쪽](06-evidence-and-open-questions.md#s01) · [제작자 자료의 접근 상태](06-evidence-and-open-questions.md#s06)

| 품목 또는 범주 | 확인된 기능 | 확인된 수치 | 상품 명세에 필요한 값 |
|---|---|---|---|
| 마나포션 | 일시적으로 마나 재생을 크게 증가 | 3초 | 가격, 회복량, 사용 제한, 중첩 |
| 체력포션 | 일정 시간에 걸친 HP 회복 | 약 10초, HP 2,000 | 가격, 회복 간격, 피격 중단, 보유 한도 |
| 체력포션 중첩 | 여러 개의 회복이 동시에 적용 | 5개 중첩 사례 | 최대 중첩과 개별 지속시간 |
| 체력 투자 보너스 | 체력포션 회복량 증가 | 투자 1회당 +50 | 투자 전 보유분과 사용 중 효과 갱신 |
| 카드 | 당시 공략에 구매·사용 사례 존재 | 범용 수치는 미확인 | 품목별 효과와 지속시간 |
| 장비 조합 | 조합이 없다고 서술 | 조합식 수 0이라는 설명 | 버전별 변경 여부 |

카드의 구체적인 구매 사례는 근거 등록부에 짧게 남긴다. 제작자 원문을 확보하면 품목별 비용과 효과를 우선 추가한다. [S01, 4·6·8쪽](06-evidence-and-open-questions.md#s01) · [S03](06-evidence-and-open-questions.md#s03) · [S04](06-evidence-and-open-questions.md#s04)

## 체력포션의 시간과 중첩

| 상황 | 확인한 규칙으로 설명되는 효과 | 검토할 위험과 비용 |
|---|---|---|
| 낮은 레벨의 회복 | 초기 HP에 비해 큰 총회복량 | 회복이 지급될 때까지 생존해야 함 |
| 집중 피해를 받는 교전 | 시간에 따라 HP가 회복 | 짧은 시간의 피해가 먼저 적용될 수 있음 |
| 여러 포션 사용 | 회복 효과가 중첩 | 보유량과 구매 비용 소비 |
| 체력 투자 증가 | 포션 1회의 회복량 증가 | 동일 광물의 다른 투자 기회 |

기본 회복을 약 10초 동안 균일하게 받는다는 가정에서는 HP 2,000이 평균 초당 200에 해당한다. 이는 자료의 총량을 시간으로 나눈 참고 계산이다. 실제 회복 틱은 추가로 확인한다. 중첩에 대한 원문 사례도 회복량의 합산 효과를 설명한다. [S01, 4쪽](06-evidence-and-open-questions.md#s01)

## Project E의 아이템 적용

Project E는 별샘 영약과 숲빛 치유약을 현재 상점에서 구매·사용한다. 사용 조건, 골드 가격, 보유 수량, 회복 중단과 UI는 해당 콘텐츠 규격에서 관리한다. 원작 비교에서는 마나 공급이 반복 시전을 바꾸는지, 회복이 다음 교전까지의 시간을 바꾸는지, 구매가 이후 선택에 비용을 남기는지를 검토한다. [골드와 아이템](../content/06-gold-and-items.md)

원작 병력·목표·아이템은 각각 고유한 이름과 버전을 가진 조사 대상이다. Project E의 병력과 판타지 아이템은 현재 게임의 명칭과 수치로 설계하며 원작에서 도출한 플레이 관계를 적용 근거로 남긴다.
