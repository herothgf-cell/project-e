# 시티 오브 템페스트 역설계

이 문서는 사용자가 제공한 시티 오브 템페스트 자료에서 경기 규칙과 플레이 선택을 복원하고, Project E의 설계 판단에 연결한다. 작성 기준일은 2026-11-09다. 원작 자료의 대표 시점은 PDF에 표시된 문서 수정일 2026-08-26이며, 당시 플레이 사례에는 각각의 작성 연도를 붙인다.

원작의 핵심 흐름은 세 라인에서 성장 기회를 확보하고, 짧은 재사용 시간의 기술과 마나를 운용하며, 측면 경험치 목표와 인접 라인 지원을 선택한 뒤, 전방 방어시설에서 최후 건물까지 공성을 진행하는 것이다. 광물 투자는 능력치와 특수 기술을 선택하게 하고, 구매한 포션은 짧은 교전의 자원 공급을 바꾼다. [S01, 1–6쪽](06-evidence-and-open-questions.md#s01)

## 읽기 기준

| 표시 | 뜻 | 문서에 포함하는 내용 |
|---|---|---|
| 자료 확인 | 지정한 출처에 직접 적힌 정보 | 수치, 대상, 조건, 원문이 제시한 예외 |
| 역설계 해석 | 확인한 규칙들을 연결해 설명한 플레이 구조 | 선택의 비용, 지원 타이밍, 성장 우위가 확산되는 과정 |
| 확인 과제 | 구현을 재현하려면 추가로 필요한 정보 | 정확한 범위, 시간, 귀속, 버전별 수치 |
| Project E 적용 | 현재 게임에서 채택하거나 검토하는 설계 | 판타지 영웅, 골드 표기, 현재 전투 판정, V8 역할 구성 |

수치에는 출처 페이지와 조건을 붙인다. 자료가 대략적인 경향으로 설명한 쿨타임과 교전 시간에는 그 성격을 유지한다. 자료에 값이 없는 필드는 확인 과제로 남기고, Project E에서 필요한 값은 해당 콘텐츠 문서에 실험값으로 기록한다.

## 규칙의 연결

| 플레이 상황 | 플레이어가 가진 선택 | 다음 상황에 미치는 영향 |
|---|---|---|
| 첫 라인 대치 | 광물 투자, 일반기 사용, 병력과의 거리 선택 | 마나 여유와 라인 정리 속도 형성 |
| 상대가 병력 가까이 접근 | 광역 견제, 병력 마무리, 안전 거리 유지 | 적 HP와 성장 기회를 동시에 압박 |
| 상대가 라인을 비움 | 라인 전진, 측면 경험치 목표, 인접 지원 | 자신의 성장과 팀 교전의 우선순위 결정 |
| 마나포션 사용 가능 | 짧은 집중 공격, 상대의 공격을 회피, 다음 구매를 위해 보존 | 자원을 써서 만드는 처치 기회와 구매 지연 발생 |
| 처치 또는 강제 후퇴 성공 | 남은 자원으로 병력 정리, 측면 목표, 구조물 압박 | 레벨과 공성 우위 확대 |
| 다른 라인이 밀림 | 중앙·인접 라인의 개입, 자기 라인 유지 | 열세 지역의 접근권과 자기 라인 손실 교환 |
| 전방 방어시설 파괴 | 후방 목표 공격, 라인 정리, 복귀와 재보급 | 최후 건물까지 진입할 다음 전투 준비 |

이 표는 자료의 행동을 연결한 역설계 해석이다. 각 선택의 수익은 경험치 지급 방식, 이동 거리, 아이템 가격과 상대의 대응에 따라 달라진다. [S01, 2·4–6쪽](06-evidence-and-open-questions.md#s01)

| 짧은 기술 반복이 입력과 피격으로 읽히는가 | [전투와 상태](../content/03-combat-and-status.md), [UI와 카메라](../content/08-ui-and-camera.md) |

Project E의 이름, 표현, 영웅과 수치는 현재 게임의 콘텐츠 문서가 관리한다. 원작 표기의 광물과 가스는 이 역설계 자료에서 그 출처를 유지한다. Project E의 골드는 현재 상점 구매를 설명하는 표시명이며, 원작 가스의 용도와 환산 관계는 근거 등록부의 확인 과제에 기록한다.

## 검토 순서

1. 경기와 전장에서 라인·성장 목표·지원의 관계를 읽는다.
2. 전투에서 짧은 재사용 시간과 마나포션이 만드는 교전 구간을 확인한다.
3. 성장과 경제에서 자동 성장, 광물 투자, 구매를 이어서 검토한다.
4. 병력과 공성에서 실제로 처치와 목표 진전을 만드는 주체를 확인한다.
5. 영웅과 플레이 패턴을 통해 같은 규칙의 다른 활용법을 비교한다.
6. 수치를 구현에 반영할 때 근거 등록부의 버전과 확인 과제를 함께 갱신한다.
