# 근거와 확인 과제

확인 기준일은 2026-11-10이다. 이 등록부는 원작 규칙을 설명하는 문서, 당시 플레이 사례, 시각 자료와 Project E의 적용 기록을 연결한다. 원작 맵의 실행 데이터와 연속 플레이 기록이 확보되면 수치·조건·예외를 같은 항목에서 갱신한다.

S01·S02·S05는 위키 계열의 설명 자료다. 같은 내용이 여러 곳에 남은 경우 출처의 독립성을 확인해야 한다. S03·S04는 당시 작성자가 기록한 플레이 사례이며 특정 영웅·시점·플레이 환경의 범위를 가진다.

## S01

사용자가 제공한 파일의 제목은 시티 오브 템페스트 - 나무위키다. 총 9쪽이며 페이지 하단에 1/9부터 9/9까지 표시되어 있다. 표지의 문서 수정 시각은 2026-08-26 16시 44분 50초, 인쇄 머리말은 2026-11-06 오후 3시 35분이다. 이 역설계에서 페이지는 해당 인쇄 페이지를 뜻한다.

| 페이지 | 검토한 내용 | 사용하는 문서 |
|---:|---|---|
| 1 | 팀당 3명, 관전, 세 라인, 최후 건물 | 경기와 전장 |
| 2 | 라인 병력과 공성의 진행 순서 | 경기와 전장, 병력·공성·아이템 |
| 3 | 맵 양도와 복수 변형의 이력 | 자료의 버전 해석 |
| 4 | 마무리 공격 제한, 짧은 재사용, 포션, 측면 성장, 지원, 초기 기술 | 경기·전투·경제·플레이 패턴 |
| 5 | 획득 가스, 광역 견제, 네 지표, 광물 지급 | 성장과 경제, 병력과 보상 |
| 6 | 투자 효과·상한, 기술 해금, 영웅 지표 | 성장·전투·영웅 |
| 7 | 영웅 지표 | 대표 성향 비교 |
| 8 | 후대 영웅 이름, 아이템·카드 원문 링크 | 로스터 범위, 아이템 조사 |
| 9 | 문서·이용 관련 안내 | 출처의 성격 확인 |

PDF 5–6쪽은 페이지 이미지로도 확인했다. 5쪽 보상 제목은 획득 가스이고, 6쪽 방어 투자 한도는 10이다. 각주 번호 15–18은 표시되지만 상세 숫자 본문은 인쇄되어 있지 않아 S02를 사용했다. 제공된 첨부파일이 이 등록 항목의 원본이다.

## S02

## S03

미블이 2011-09-20에 작성한 동팽 공략.을 확인했다. 0레벨부터 마나에 투자하고 3레벨에 공격력과 궁극기에 투자하는 사례가 있다. 700 이상을 모아 귀환한 뒤 포션과 카드를 구매하는 행동도 기록한다. 700은 그 글의 복귀 자금 기준이며 개별 상품 가격은 추가 확인 대상이다. [PlayXP 원문](https://www.playxp.com/sc2/citydefence/view.php?article_id=3403900&page=432)

직접 페이지를 여는 과정에서 접근 오류가 발생하여 검색 서비스에 색인된 본문으로 확인했다. 이 사례는 한 영웅의 당시 투자·구매 운용을 보여 준다. 공통 궁극기 해금 레벨과 전체 영웅의 투자 비용은 각 영웅 자료로 확인한다.

## S04

김세미가 2011-04-27에 작성한 공방 메카트론 공략을 확인했다. 중앙 감시탑, 사거리 투자, 장거리 견제와 공성 중 포션·카드 사용이 등장한다. 본문은 메카트론의 생명력을 5칸으로 설명하지만 S01의 표는 4칸을 기록한다. 당시 기술과 수치를 사용할 때는 이 시점을 유지한다. [PlayXP 원문](https://www.playxp.com/sc2/citydefence/view.php?article_id=2779114)

이 자료도 검색 서비스에 색인된 본문으로 확인했다. 첨부 리플레이는 별도 실행·검증이 필요하다.

## S05

보존 문서는 마지막 수정 시각을 2017-02-01로 표시한다. 방어 투자 1회 +2, 상한 25회, 투자에 의한 피해 감소 50%를 기록한다. S01은 같은 1회 증가량에 상한 10회와 감소 20%를 기록한다. 차이는 버전 비교표에 보존하고 실제 패치 시점을 추가 조사한다. [보존 문서](https://tcatmon.com/wiki/%EC%8B%9C%ED%8B%B0_%EC%98%A4%EB%B8%8C_%ED%85%9C%ED%8E%98%EC%8A%A4%ED%8A%B8)

## S06

S01의 8쪽 아이템·카드 항목은 제작자 Maxstorm의 정리 문서로 연결된다. 확인 시점에 해당 주소의 본문을 확보하지 못했다. 링크와 확인 과제를 유지하고 정확한 가격·효과·구매 자원은 실제 원문 또는 게임 화면으로 채운다. [제작자 아이템·카드 정리](https://cafe.naver.com/citydef/37561)

## S07

사용자가 지정한 영상은 랑죠 채널의 윤완진 플레이 영상이며 길이는 23분 37초다. 공개 스토리보드에서 약 10초 간격의 143개 실제 프레임을 확보해 검토했다. 각 표본은 160×90이다. 영상 CDN이 영상 대신 `Site Unavailable` HTML을 반환해 고해상도 연속 재생과 원본 프레임 추출은 완료하지 못했다. [지정 영상](https://www.youtube.com/watch?v=B0V1yRqhIc8)

초반의 세로 도로, 중간의 지형 옆길과 교차부, 말미 거점 주변 교전을 관찰했다. 개체 이름·HP·공성 단계별 정확한 파괴 시각과 평균 경기 길이는 이 자료의 확인 범위에 포함되지 않는다. [장면별 기록](../29-cot-map-minion-siege-review.md#원작-영상과-맵에서-관찰한-것) · [보존 표본](../assets/cot-audit-20261110/README.md)

## S08

Sina의 배포 페이지는 City of Tempest v1.3을 영어판 0~6인 맵으로 소개한다. 첨부된 640×400 실제 게임 스크린샷의 미니맵에서 상단 보라색 진영, 하단 청록색 진영, 세로 주 통로와 가로 연결부를 확인했다. 지정 한국어 영상과 다른 시기·버전의 보조 자료로 사용한다. 배포 맵 파일은 HTTP 503으로 확보하지 못했다. [배포 페이지](https://games.sina.com.cn/d/m/pc/133247.shtml) · [게임 스크린샷](https://i1.sinaimg.cn/gm/cr/2011/0622/2531619812.jpg)

## 충돌과 해석 주의점

| 항목 | 자료에 있는 차이 | 현재 문서의 결정 | 해소할 자료 |
|---|---|---|---|
| 방어 상한 | S01 10회, S05 25회 | 사용자 PDF의 10회를 기본 표에 사용 | 패치 이력 또는 해당 버전 맵 |
| 초기 레벨 | S01은 1레벨 능력치 설명, S03은 0레벨 투자 기록 | 자동 성장 계산은 실제 레벨업 횟수 사용 | 초기 HUD와 첫 레벨업 |
| 광물 경계 | 25레벨 이전·이후 표현 | 총 광물 계산을 확정하는 경계 조건을 확인 과제로 등록 | 24→25와 25→26 기록 |
