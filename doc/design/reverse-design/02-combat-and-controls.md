# 원작 전투와 조작

원작 전투는 짧은 재사용 시간의 기술, 제한된 마나, 포션에 의한 일시적인 자원 공급, 광역 공격과 이동을 함께 다룬다. 기술의 사용 빈도가 높아 한 번의 조준 이후에도 다음 시전·회피·추격을 계속 판단하게 된다. [S01, 4–6쪽](06-evidence-and-open-questions.md#s01)

## 전투에서 확인한 수치와 범위

| 항목 | 자료 확인 | 값의 성격 | 적용 범위 |
|---|---|---|---|
| 일반 기술 재사용 | 통상 1–3초 | 대표 범위 | 개별 기술 예외 있음 |
| 궁극기 재사용 | 15초를 넘는 경우가 드묾 | 경향 | 전체 궁극기의 공통 상한은 추가 확인 |
| 제어 기술 재사용 | 10초를 넘는 경우가 드묾 | 경향 | 각 제어 효과와 지속시간 확인 필요 |
| 마나포션 | 3초 동안 재생 크게 증가 | 효과 지속시간 | 정확한 초당 회복량 확인 필요 |
| 체력포션 | 약 10초에 걸쳐 HP 2,000 회복 | 근사 총량과 시간 | 투자 보너스·중첩과 함께 해석 |
| 초반 처치 | 2–3초 안에 처치되는 양상 서술 | 플레이 경험의 설명 | 통계적 평균 자료는 추가 확인 |
| 기술 보유 | 대부분의 일반 기술을 시작부터 보유 | 접근 조건 | 궁극기·일부 특수 기술은 광물 투자 |

이 표는 PDF 4쪽의 표현을 유지한다. 수치가 경향인 항목은 개별 영웅의 기술 데이터와 구분해 검토한다. [S01](06-evidence-and-open-questions.md#s01)

## 기본 공격과 광역 견제

자료는 근접·원거리 영웅을 포함해 다수의 기본 공격에 스플래시가 있으며, 적 영웅과 병력을 함께 광역 기술로 공격할 수 있다고 설명한다. 같은 공격이 전투와 성장 기회에 동시에 영향을 주므로, 병력 근처의 자리 선정이 중요해진다. [S01, 5쪽](06-evidence-and-open-questions.md#s01)

| 상황 | 공격자의 판단 | 방어자의 판단 | 역설계에서 확인할 판정 |
|---|---|---|---|
| 병력과 영웅이 겹침 | 넓은 공격으로 여러 대상을 견제 | 병력에서 떨어지거나 공격 방향 변경 | 스플래시 중심·반경·감쇠 |
| 약화된 병력에 접근 | 마무리와 적 견제를 함께 노림 | 성장 접근을 포기할지 교환할지 선택 | 기본 공격 선딜과 범위 |
| 상대가 이동하며 병력을 흔듦 | 공격 대상과 이동 경로 재선택 | 광역 효율을 낮추고 시간 확보 | 유닛 충돌과 공격 추적 |
| 구조물 압박 중 적이 복귀 | 구조물 공격과 영웅 대응 선택 | 공격자의 자원과 위치를 이용 | 기술의 구조물 적용 여부 |

공격 대상, 발사체, 범위와 피해 판정은 영웅별 데이터를 필요로 한다. 기본 공격의 공격속도·치명타·원거리 탄속을 공통 숫자로 정할 근거는 현재 자료에 없다.

## 반복 시전의 전투 과정

아래 과정은 재사용 시간과 마나의 관계를 설명하는 역설계 모델이다.

| 상태 | 진입 조건 | 플레이어 행동 | 상태를 바꾸는 사건 |
|---|---|---|---|
| 견제 준비 | 상대와 교전 가능한 거리 | 일반기와 기본 공격의 방향 선택 | 시전, 상대 이탈, 자원 부족 |
| 첫 시전 | 기술 사용 조건 충족 | 적 영웅·병력·이동 경로를 공격 | 적중, 회피, 제어 적용 |
| 재사용 대기 | 기술 사용 이후 | 다른 기술, 기본 공격, 이동 | 재사용 종료 또는 마나 부족 |
| 재시전 판단 | 기술이 다시 사용 가능 | 같은 상대 추격 또는 공격 대상 변경 | 처치, 퇴각, 포션 사용 |
| 자원 압박 | 후속 기술 사용 여유 감소 | 포션, 기술 절약, 안전 확보 | 회복, 재보급, 사망 |
| 우위 전환 | 적 처치 또는 후퇴 | 병력 정리, 측면 목표, 공성 | 다음 적 접근 또는 자원 고갈 |

실제 반복 횟수는 재사용 시간, 기술 비용, 최대 마나, 재생, 포션의 효과와 교전 지속시간을 함께 확인해 평가한다. [S01, 4·6쪽](06-evidence-and-open-questions.md#s01)

## 마나포션과 집중 교전

| 단계 | 자료가 설명한 행동 | 전술적 해석 | 상대에게 생기는 대응 질문 |
|---|---|---|---|
| 사용 준비 | 초반부터 마나포션이 중요한 구매 대상 | 구매한 자원 공급을 교전 기회로 보유 | 상대가 포션을 보유·사용했는지 읽을 수 있는가 |
| 효과 진행 | 3초 동안 마나 재생 증가 | 후속 시전을 짧은 시간에 집중 | 효과 시간 동안 거리와 지형을 활용할 수 있는가 |
| 처치 시도 | 기술을 연속 사용해 영웅 압박 | 상대의 대응 시간을 줄이고 전선에서 밀어냄 | 제어를 피하거나 지원받을 경로가 있는가 |
| 성공 후 | 남은 마나로 병력 정리 | 교전 우위를 성장으로 전환 | 빠른 복귀나 다른 라인의 개입이 가능한가 |
| 성과 부족 | 구매한 포션이 소비됨 | 다음 구매 시점을 늦추는 비용 발생 | 공격자가 자원 공백에 들어가는가 |

PDF는 포션을 잘못 사용하면 이후 필수 아이템 마련에 영향을 준다고 서술한다. 이는 포션의 실제 가격·보유 한도·사용 쿨타임을 확보한 뒤 정량화할 수 있다. [S01, 4쪽](06-evidence-and-open-questions.md#s01)

자료의 초반 포션 교전 빈도 서술은 당시 플레이 경험이다. 역설계 검토에서는 경기별 사용 시점, 사용 전후 시전 수, 처치 또는 강제 후퇴, 이후 구매 지연을 따로 기록한다.

## 피해 감소와 보호막

| 규칙 | 자료 확인 | 계산상 의미 | 확인할 예외 |
|---|---|---|---|
| 방어력 1 | 받는 피해 1% 감소 | 방어력 수치가 감소율에 직접 대응 | 음수 방어, 상한, 피해 종류 |
| 방어력 50 | 피해가 절반 | 원피해의 0.5배라는 예시 | 다른 감소 효과와 합산 방식 |
| 방어 투자 1회 | 방어력 +2 | 감소율 +2%p | 기본 방어력과 버프 합산 |
| 방어 투자 상한 | 10회 | 투자로 감소율 20%p 획득 | 과거 자료의 다른 상한 |
| 보호막 | 방어 효과 적용 | 보호막이 받는 피해에도 감소 적용 | 보호막 차감 순서·중복·갱신 |

근거는 PDF 6쪽이다. 단독 방어 항만 표현하면 적용 피해는 원피해에 1에서 방어력의 백분율을 뺀 비율을 곱한 값이다. 다른 효과를 포함하는 최종 계산 순서는 추가 확인이 필요하다. [S01](06-evidence-and-open-questions.md#s01)

## 전투 성장의 반영

| 성장 원천 | 자료 확인 | 실제 전투에서 볼 변화 |
|---|---|---|
| 전투력 지표 | 무투자 상태의 기본 공격과 기술 피해에 영향 | 첫 교전의 공격 성향 |
| 레벨 성장 | 레벨 상승에 따른 기술 피해 증가가 우위 확대와 연결 | 같은 기술이 주는 피해의 변화 |
| 공격력 투자 | 기본 공격·기술 피해, 일부 부가 효과 증가 | 마무리 시간과 제어·생존 효과 변화 |
| 체력 투자 | 생명력 등급별 HP 증가, 체력포션 회복량 증가 | 집중 공격을 견디는 시간과 회복 가치 |
| 마나 투자 | 최대 마나와 재생 증가 | 포션 사용 전후 후속 시전 여유 |
| 이동속도 투자 | 이동속도 증가 | 공격 접근, 회피, 지원과 추격 |

레벨 증가와 공격력 투자가 각각 어떤 계수로 기술에 적용되는지는 영웅별 데이터가 필요하다. 현재 문서에서는 영향 관계를 기록하고, 성장 수치표에서 확인한 항목을 연결한다. [S01, 4–6쪽](06-evidence-and-open-questions.md#s01) · [성장과 경제](03-growth-and-economy.md)

## 조작과 행동 예약

| 항목 | 확인한 동작 | 확인 범위 |
|---|---|---|
| Shift 예약 | 재사용 시간이 없는 일부 기술의 예약 연속 사용 | PDF 4쪽의 특정 기술 사례 |
| 다수 일반기 | 시작부터 기술을 활용 가능 | 기술별 슬롯·키 배치 확인 필요 |
| 궁극기 습득 | 광물 투자 후 사용 | 영웅별 해금 비용·레벨 확인 필요 |
| 구매 후 사용 | 포션과 카드가 전술에 사용됨 | 원작의 선택·구매·사용 키 확인 필요 |

원작의 모든 영웅에 공통인 키 배치, 클릭 시전과 빠른 시전, 예약 개수, 취소 입력은 원본 UI나 플레이 장면으로 확인한다. Project E의 Q/W/E/R과 소모품·성장·상점 조작은 현재 UI 규격에 기록한다. [S01, 4·6쪽](06-evidence-and-open-questions.md#s01) · [현재 UI와 조작](../06-ui-and-controls.md)

## Project E 적용과 검토

| 원작에서 가져갈 관계 | 현재 게임의 확인 위치 | 검토 질문 |
|---|---|---|
| 반복 시전과 이동 | 공통 전투, 영웅별 시트 | 재사용보다 입력·선후딜이 전투의 병목이 되는가 |
| 마나와 구매한 회복 | 성장·경제, 소모품 규격 | 포션이 전투 선택에 의미 있는 변화를 만드는가 |
| 광역 견제와 병력 정리 | 기본 공격·기술 범위 | 영웅과 병력을 함께 노리는 자리가 생기는가 |
| 제어와 대응 | 상태 이상 규칙 | 상대가 예고를 읽고 회피할 수 있는가 |
| 성장과 피해 | 성장 코드와 영웅별 계수 | 같은 레벨과 레벨 차이 조건을 모두 확인했는가 |

정확한 Project E 수치는 현행 문서를 따른다. V8 영웅은 동일한 공통 판정 안에서 각자의 사거리·준비 시간·영역·표식으로 다른 전투 선택을 만든다. [현재 전투](../03-combat.md) · [현재 성장과 경제](../05-growth-and-economy.md) · [영웅 목차](../characters/README.md)
