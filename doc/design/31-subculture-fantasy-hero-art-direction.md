## 1. 목적과 디자인 원칙

### 1.1 D 혼합형 해석

- **고급 판타지 의상**: 자수·가죽·천·세공 금속·룬·신화적 장신구가 풍부하지만 현대 총기·SF·스트리트웨어 없이 읽히는 세계.
- **귀여운 SD 인게임**: **3.0~3.5등신**을 기준으로 큰 머리, 표정 있는 눈, 과장된 장비 및 짧은 동작을 활용. 단순한 아동용 장난감처럼 표현하지 않는다.
- **미형 캐릭터 표현**: 영웅 선택·상세 소개·키아트에서는 **6~7등신 애니메이션풍 일러스트**를 별도 제작. 해당 그림을 단순 축소하여 게임 모델의 비율로 취급하지 않는다.
- **진지한 전투**: 공격 예고, 타격 정점, 회복 동작에 명확한 리듬을 부여하고 캐릭터별 기술 모티프를 유지한다.
- **애착의 원천**: 특정 영웅을 기억하게 만드는 헤어스타일·무기·직업·표정·포즈·짧은 인물 서사를 함께 설계한다. 선정성이나 과도한 노출에 의존하지 않는다.

참고 감성은 그랑블루 판타지(고급 판타지 복식), 프린세스 커넥트(귀여운 전투 비율), 에픽세븐(미형 캐릭터의 개성과 전투 연출)이나 **비율·미술 원칙만 해석**한다. 기존 작품의 인물, 복식, 문양, 고유 명칭, 이펙트, 포즈, 아이콘을 직접 복제하지 않는다.

### 1.2 변경하면 안 되는 기존 게임 계약

- 영웅 ID·기본 역할·패시브 및 Q/W/E/R 이름과 판정은 현재 문서와 코드를 정본으로 한다.
- 현재 **아군 하단 / 적군 상단 / 세로 3라인**, 3v3, 시야/고지/벽/안개, 실제 스킬 예고와 충돌 범위를 유지한다.
- 인게임 의상·이펙트·초상 개선은 스킬 사거리, 피해, CC, 이동, 타워/미니언 규칙을 바꾸지 않는다.
- 새 캐릭터나 8개 직업을 창작해 로스터를 대체하지 않는다. 8명은 **이미 구현된 고유 영웅 8명**이다.
- 실제 게임의 신규 모델·텍스처·모션 적용은 이 문서만으로 완료되지 않는다. 본 문서는 미술 제작 계약이다.

## 2. 공통 비주얼 시스템

### 2.1 2D 일러스트와 3D 모델의 이중 표현

| 구분 | 2D 선택/상세/키아트 | 3D 경기/F7 |
|---|---|---|
| 비율 | 6~7등신 미형 | 3.0~3.5등신 SD |
| 표정 | 눈매·속눈썹·미소·감정 표현까지 정교화 | 눈동자, 눈썹, 입의 단순한 큰 형태 |
| 디테일 | 자수·보석·메탈 장식, 의복 층 | 머리·주무기·망토 외곽·특징 문양 우선 |
| 색 | 재질별 부드러운 명암, 영웅별 서브컬처 키아트 | 큰 색면 3~4개, 값 대비, 판정/팀 표식 우선 |
| 공통성 | 같은 색·문양·장비·헤어 구성, 대표 포즈 | 같은 디자인 DNA를 위에서 보는 실루엣에 최적화 |
| 검증 | 4×2 로스터 카드, 확대 프로필 | 교전 카메라·축소 카메라·팀전 혼잡도 |

- 선택 일러스트에는 전신 그림뿐 아니라 눈/입/표정 시트, 정면·측면·후면 턴어라운드 및 장비 확대도를 함께 제작한다.
- 인게임용 장비는 손보다 확실히 커야 하는 경우가 많지만 판정 반경을 장비 크기에 맞춰 수정하지 않는다. 공격은 기존 로직의 실제 판정 위치에 동기화한다.
- 3D 비주얼 관절에 영향을 주는 장비를 교체할 때는 리깅 바인드 포즈, 공격·QWER·피격·사망·부활 클립을 동시에 검수한다.

### 2.2 셀풍 재질·조명 제안

- 피부: 선명한 기초색 + 부드러운 2단 명암, 눈·볼·광택은 얼굴 중심에서만 강조.
- 머리: 큰 헤어 뭉치와 매력적인 반짝임, 잔머리 실루엣은 소수의 굵은 가닥만 사용.
- 의상: 천·가죽·메탈·유리·나무의 재질 차이를 러프니스/명암 단계로 드러내되 작은 텍스처 노이즈는 억제.
- 외곽선: 전신을 두꺼운 검정으로 둘러싸기보다 접촉부·머리·무기 바깥윤곽 중심의 절제된 셀풍 엣지. 실기 카메라에서 선 두께 조정.
- 림라이트: 선택 화면·F7 강조 연출에는 허용, 전투에서는 팀/상태·판정·시야 대비를 침범하지 않도록 제한.
- 세계: 기존 밝은 아스트라 수로·석재·공방 환경과 조화시키되, 배경의 채도와 디테일은 영웅보다 낮게 유지.

### 2.3 영웅 고유색 vs 팀/위험 표시

**고유색은 캐릭터 정체성**, 청록/적대색 등 **팀 색은 전투 관계**를 담당한다. 적군이라고 영웅 머리·복식을 모두 붉게 염색하지 않는다. 팀 링/HP바/외곽 HUD로 구분한다.

- 위험 예고는 기존 판정 원·띠·부채 경고가 우선이며, 장식 입자는 그 밖으로 확대되어 추가 피해처럼 보이면 안 된다.
- 색각 이상과 저해상도에 대비해 **무기 외곽, 헤드기어, 모션, 문양, 경고 기하** 중 최소 둘 이상으로 구분한다.
- 디자인상 겹칠 수 있는 리오/세라의 보라, 네마/무아의 청록은 실루엣·형태·이펙트 질감으로 반드시 분리한다.
- 플레이어의 자기 캐릭터를 구분하기 위한 링/커서/체력 표식은 의상 색과 독립적으로 유지한다.

## 3. 8명 영웅별 캐릭터 바이블

다음의 외형 서사·성격·색상 코드는 **아트 제안값**이다. Q/W/E/R과 전투 형태는 현재 정본의 기술을 따른다. 성별·연령대·세부 세계관 인물 관계 등은 공식 캐릭터 설정 확정 전까지 과도하게 고정하지 않는다.

### C01. 바스 / 룬 건틀릿 전사 / bas

- **첫인상**: 거칠지만 믿음직한 열혈 전선 수호자. 작고 귀여운 체구와 거대한 건틀릿의 대비.
- **얼굴·헤어**: 기존 금발 유지. 삐죽한 앞머리, 똑바로 보는 강한 눈, 이마 위 짧은 역동적인 헤어 뭉치.
- **의상·장비**: 진홍 전투 외투·비대칭 어깨 갑옷·허리 가죽 벨트, 양손 룬 건틀릿. 오른쪽 건틀릿을 특히 크고 낮게.
- **실루엣**: **낮은 역삼각형/거대한 주먹 2개**. 어깨-장갑-발 접지로 탱커/돌진 영웅을 인식.
- **팔레트**: Crimson #B54F4D / Brass #DDB66C / Stone #615D63, 룬 발광 청록은 작은 면적만.
- **캐릭터 훅**: 싸움을 좋아하지만 동료 뒤에 숨지 않는 책임감. 대기 때 두 건틀릿을 쾅 맞대고 웃는다.
- **패시브/스킬 시각 언어**: 룬 심장은 건틀릿에 2칸 충전; Q 룬권 파쇄는 부채 모양 돌·룬 파열; W 수호 각인은 보호판; E 거석 돌진은 낮은 직선 질주·먼지; R 대지의 심판은 **7m 전방 띠**를 따른 룬 균열.
- **경쟁 화면에서의 가독성**: 폭넓은 건틀릿이 먼저 보여야 하며, 선딜 동안 바닥에 찍는 포즈를 사용. 보호 이펙트는 공격 판정으로 혼동되지 않도록 반투명 외곽 방패형.
- **금지**: 지나친 근육질 서양 야만전사, 총기·기계식 파워아머, 룬 충전 2개를 초과해 보이는 장식.

### C02. 리오 / 별빛 원반 마법사 / rio

- **첫인상**: 태연하고 천재적인 별자리 관측자. 공격 동선이 우아한 유리대포.
- **얼굴·헤어**: 기존 연보라 머리 유지. 큰 기울어진 마법사 모자 아래 이마가 보이는 짧은 보브/긴 옆머리. 느긋한 눈매.
- **의상·장비**: 자주·짙은 남청색 로브, 별지도가 새겨진 겹천, 등/양손 주변의 **쌍원반**. 종이 맵과 천체 관측 장치를 판타지 금속 세공으로.
- **실루엣**: **삼각 모자 + 좌우 원반의 둥근 궤도**, 가볍고 길게 뻗은 팔.
- **팔레트**: Indigo Violet #6750A4 / Starlight #75BEEA / Midnight #243253.
- **캐릭터 훅**: 가끔 멍하니 하늘을 보는 마도학자. 승리 포즈에서 공중 별도를 한 번 완성한다.
- **패시브/스킬 시각 언어**: 별의 순환은 1개의 맥동 궤도; Q 왕복 혜성은 **출발 및 귀환 경로를 각각 보이게**; W 별무리 닻은 작은 고정 별자물쇠; E 별빛 도약은 짧은 점멸 잔상; R 삼각 성좌는 직선 3변과 꼭짓점 발광.
- **경쟁 화면에서의 가독성**: 원반은 무기이고 바닥 궤적은 기술 예고임이 구분되도록 렌더 층을 달리. 세라와 달리 **둥글고 느린/기하학적** 마법.
- **금지**: 세라의 날카로운 검 궤적 같은 표현, SF 홀로그램 원반, 모든 스킬을 동일한 별 입자로 처리.

### C03. 네마 / 숲의 결계술사 / nema

- **첫인상**: 숲의 정령을 돌보는 신비로운 결계사. 조용하지만 교전 위치를 바꾸는 지원형 영웅.
- **얼굴·헤어**: 기존 녹색 머리 유지. 부드러운 눈, 앞머리를 감싼 후드, 작고 밝은 귀 옆 잎 장식.
- **의상·장비**: 천·목재·씨앗 주머니·룬핀 배낭, 정령목 문양의 지팡이/완드. 자연물은 얽힌 덩굴보다 **큰 잎·굵은 가지** 중심.
- **실루엣**: **둥근 후드 + 뒤로 솟은 잎/배낭 + 가느다란 지팡이**.
- **팔레트**: Forest #3A8768 / Sprout #D4C66B / Bark #6D5A48.
- **캐릭터 훅**: 사람보다 묘목과 더 오래 대화하는 수줍은 수호자. 대기 때 작은 싹을 살핀다.
- **패시브/스킬 시각 언어**: 숲의 품은 작고 둥근 잎 보호; Q 정령목 심기는 살아 있는 묘목; W 덩굴 물결은 **두 정령목 사이 연결선**으로 퍼짐; E 잎새의 가호는 잎 방패; R 고대숲의 결박은 실제 판정 경계의 굵은 뿌리.
- **경쟁 화면에서의 가독성**: 설치 가능한 정령목과 실제 맵의 배경 나무를 색상·아이콘·윤곽으로 명확히 구별.
- **금지**: 지나친 잎 입자로 실전 연결선 가리기, 무아의 물감 구역과 비슷한 원형 장식.

### C04. 오린 / 바람의 사수 / orin

- **첫인상**: 바람을 읽어 한 발을 준비하는 자유로운 방랑 사수. 발사 직전의 집중 상태가 매력.
- **얼굴·헤어**: 비대칭 짧은 머리, 바람에 튀는 한쪽 머리 가닥, 시선이 먼 곳을 향한 눈매.
- **의상·장비**: 모래색 여정 코트, 짧은 두건, 가벼운 깃털·가죽 보호대. 기존 **판타지 송풍관**을 나팔/바람 악기처럼 조형해 현대 총기로 읽히지 않게.
- **실루엣**: **수평으로 길어진 송풍관 + 바람에 휘는 스카프**, 좁은 삼각형.
- **팔레트**: Sand #BDA16F / Tailwind #7BC9B2 / Warm Brown #78644F.
- **캐릭터 훅**: 허풍스러우나 발사 전에는 침착. 대기 때 손가락으로 바람을 재는 짧은 포즈.
- **패시브/스킬 시각 언어**: 바람 장전 준비상태는 송풍관 입구의 **압축 고리**; Q 바람살은 좁고 긴 직선, 준비 시 더 짧고 넓은 파동; W 돌개 숨결은 준비 자세 변화; E 순풍 걸음은 발밑 뒤쪽 공기 흐름; R 쌍둥이 폭풍은 **시간차를 가진 두 파동**.
- **경쟁 화면에서의 가독성**: 바람이 투명하므로 충돌/예고 경계의 기하학을 먼저 보여주고 단순 흰 입자만 사용하지 않는다.
- **금지**: 총열·탄창·탄피 등 현대 총기 디테일, 기본 Q와 준비 Q를 단순 색 차이로만 구분.

### C05. 테르 / 수정 방패 수호자 / tere

- **첫인상**: 무표정하지만 동료를 지키는 서약의 기사. 거대한 방패가 캐릭터의 얼굴만큼 중요.
- **얼굴·헤어**: 잘 정돈된 짧은 헤어 또는 단정한 묶음, 절제된 눈매, 차분한 표정.
- **의상·장비**: 빙청색 판금과 은빛 천, 벨트의 작은 수정 봉인, 접이식 **세로로 긴 수정 방패**. 금속은 차갑고 둔중하게.
- **실루엣**: **높은 세로 직사각형 방패 + 짧은 망토**, 바스의 낮고 넓은 실루엣과 대비.
- **팔레트**: Slate Blue #3E6687 / Ice #A8E7EA / Silver #C5CDD6.
- **캐릭터 훅**: 무뚝뚝한 보호자. 대기 동작에서 뒤쪽 아군을 먼저 살핀다.
- **패시브/스킬 시각 언어**: 동행의 맹세는 작은 방패 매듭; Q 수정 방패격은 찌르는 수정판; W 후위의 성벽은 뒤편 보호 평면; E 수호 후퇴는 **출발점 반격 예고를 남긴 실제 후퇴 경로**; R 빙정 봉쇄는 실제 방향과 폭의 전방 결정 장벽.
- **경쟁 화면에서의 가독성**: 뒤편 아군 보호 방향을 시각적으로 설명하고 방패가 HP바/적 예고를 가리지 않게 크기 제한.
- **금지**: 바스와 동일한 돌진형 무기, 반투명 방패가 LOS를 바꾼 것처럼 보이는 표현.

### C06. 무아 / 물결의 화가 / mua

- **첫인상**: 전장을 캔버스 삼아 물결을 그리는 발랄한 예술가. 제어·지원의 리듬을 직관적으로 설명하는 영웅.
- **얼굴·헤어**: 경쾌한 눈매, 한쪽으로 묶은 머리와 물방울 모양 장신구.
- **의상·장비**: 판타지 화공용 짧은 로브, 둥근 붓통, 손보다 큰 **수평 대형 붓**, 허리 유리 물감병. 도색은 물과 유약처럼 맑게.
- **실루엣**: **가로로 길게 뻗은 붓 + 둥근 병/붓통**, 네마의 후드·지팡이 실루엣과 분리.
- **팔레트**: Sea Teal #2F9C9A / Pearl #DCE8E5 / Coral Pink #F4A8BB.
- **캐릭터 훅**: 장난스럽지만 작품을 완성할 때 몰입. 승리 시 작은 물결 그림이 하트/소용돌이 형태로 닫힌다.
- **패시브/스킬 시각 언어**: 잔물결은 붓 끝의 잔상; Q 물감 웅덩이는 바닥의 **두 구역**; W 흐름 바꾸기는 활성/비활성 구역의 테두리·밀도 전환; E 물결 덧칠은 보호성 덧칠; R 만조의 화폭은 실제 **활성 구역을 소비**하며 확장.
- **경쟁 화면에서의 가독성**: 무아의 설치물은 페인트처럼 평평한 이중 원이며 네마의 정령목/연결선과 구별. 활성 상태는 색 외에 두께·결 패턴 차이를 사용.
- **금지**: 고래/파도 투사체로 실제 타격 반경을 감추기, 잔류 구역을 피해 판정처럼 오인시키는 고채도 테두리.

### C07. 세라 / 월영 쌍검사 / sera

- **첫인상**: 차갑고 우아한 달의 검사. 작고 귀여운 외형 안에 날카로운 전투력을 대비시킨다.
- **얼굴·헤어**: 길게 날린 한쪽 머리 뭉치/높은 묶음, 선명한 눈매, 무표정에서 미소로 변하는 강한 대비.
- **의상·장비**: 어두운 보랏빛 경장, 은색 검집, 비대칭 짧은 망토와 **쌍초승달 검**. 칼날은 금속, 달빛은 극히 얇은 발광선.
- **실루엣**: **대각선 두 칼날의 X자 + 날카로운 머리/망토 끝**, 리오의 모자·원반·둥근 궤도와 정반대.
- **팔레트**: Eclipse #5C447A / Moon Silver #E1C9FF / Ink #242332.
- **캐릭터 훅**: 냉정한 밤의 검객, 진심으로 웃는 순간이 희귀한 인물. 대기 때 칼날로 달빛을 확인.
- **패시브/스킬 시각 언어**: 달의 낙인은 **대상별 최대 2중첩/만료가 읽히는 초승 표식**; Q 초승 베기는 짧고 날카로운 호; W 달그림자는 생존을 뜻하는 흐릿한 잔상; E 월영 쇄도는 짧은 실제 진입 궤적; R 그믐의 심판은 표식 소비 순간 교차되는 날카로운 선.
- **경쟁 화면에서의 가독성**: 표식은 대상 팀시야 규칙에 따라 표시하고, 기본공격/R의 표식 소비를 한 번에 인식할 수 있게 소멸 모션을 정의.
- **금지**: 리오의 별빛 마법과 같은 보라빛 원판, 숨은 적에게 표식 카운트가 보이는 연출, 영구적으로 깔리는 잔상.

### C08. 루메 / 잿불 연금술사 / lume

- **첫인상**: 겉으로는 다정하고 허술한 천재 연금술사, 실제 전투에서는 계산된 지연 폭발의 명수.
- **얼굴·헤어**: 둥근 얼굴과 살짝 헝클어진 앞머리, 호기심 많은 눈매, 반짝이는 고글.
- **의상·장비**: 둥근 연금술 모자, 가죽-황동 배낭, 다층 유리병, 단단한 작은 부츠. 유리 용기·뚜껑·마법 인장을 근대 화약기보다 판타지 도구로 표현.
- **실루엣**: **큰 둥근 모자 + 옆구리 유리병 2개 + 비대칭 가방**, 오린의 긴 송풍관과 분리.
- **팔레트**: Ember #A65B33 / Honey #F0B65E / Charcoal #454047.
- **캐릭터 훅**: 본인의 실험이 성공할 때마다 기뻐하며 기록. 폭발 직전에 가방을 꽉 잡는 짧은 포즈.
- **패시브/스킬 시각 언어**: 잔열은 **0~3 카운트와 다음 공격 강화**가 보이는 병 속 밝기; Q 잿불 병은 고정 지면 원 예고 뒤 병 파열; W 화약 고리는 원형 불씨; E 불씨 망토는 보호/가속의 얇은 후광; R 유성 가마는 **동일 원 안에서 3회에 걸친 예고/낙하**를 정확하게 반복.
- **경쟁 화면에서의 가독성**: 후속 포격의 경고는 실제 남은 시간에 맞게 갱신하고, 첫 타 이후 회피 가능한 틈을 가리지 않는다.
- **금지**: 현실 수류탄·현대 폭약 도구, 3회 포격을 한 번의 큰 폭발로 보이게 하는 연출.

## 5. 애착 유도용 캐릭터 콘텐츠 제안

- **캐릭터 선택 카드**: 얼굴 클로즈업 + 고유 무기 한 부분 + 역할 한 줄 + 패시브/기술의 고유 모양. 같은 카드 구도로 8명을 통일한다.
- **전신 키아트**: 6~7등신, 개별 대표 포즈, 역할을 보여 주는 짧은 판타지 배경. 기존 게임의 특정 캐릭터를 연상시키는 고유 장비 배열은 회피.
- **표정 4종**: 기본, 기쁨/승리, 당황/피격, 진지한 집중. 과도하게 많은 표정 대신 하나의 잊히지 않는 특징을 정한다.
- **한 줄 캐릭터 대사 톤**: 바스 직선적·리오 여유·네마 조심스러움·오린 장난기·테르 과묵·무아 명랑·세라 냉정·루메 호기심.
- **비전투 리액션**: 대기 2종(기본/희귀), 승리 1종, 패배 1종, 스킬 성공 1종. 프로토에서는 기본 대기 1종부터 시작.
- **스킨 방향**: 인물 성격과 무기 실루엣은 고정하고, 망토/자수/장신구·색 테마만 확장. 스킨으로 위험 경고를 감추거나 무기를 다른 역할처럼 보이게 하면 안 된다.

서브컬처 감성의 핵심은 모든 영웅을 같은 미형 얼굴로 만드는 것이 아니라 **매력의 종류가 서로 다른 8명**을 구축하는 것이다.

## 6. 모션·스킬 연출 제작 계약

### 6.1 모션 리듬

- 모든 캐릭터는 Idle → 이동 → 기본 공격 → Q/W/E/R → 피격 → 사망 → 부활의 기존 관절/클립 계약을 우선 보존한다.
- 실전 가독성을 위해 선딜(anticipation) → 타격/효과(hit) → 회복(recovery)을 분리한다.
- 이동기, 다회 타격, 설치기, 보호막은 보이는 애니메이션이 실제 게임 상태·시점과 어긋나지 않아야 한다.
- 주무기와 장비의 관절/본 이름 계약 및 각 기술의 유효 타격 프레임은 게임 표현 구현을 착수할 때 별도 명세로 고정한다.
- 머리카락·망토 보조 움직임은 전투·카메라 시야를 가리지 않는 범위로만 적용한다.

### 6.2 스킬 VFX 우선순위

1. **정확한 판정**: 경고 기하·시간·LOS/시야/고지 경계·팀 소속.
2. **캐릭터성**: 룬/성좌/정령목/바람/수정/물감/월영/연금.
3. **타격감**: 1회 반동, 잔상, 충격, 적중 대비.
4. **장식**: 경미한 입자·빛·재질 하이라이트.

동시에 셋 이상의 궁극기가 겹치는 3v3 화면에서 1이 2~4에 가려지면 실패다. 판정과 무관한 VFX로 적중 반경이 넓어 보이거나 시야 밖 적의 위치가 보이면 실패다.

### 6.3 기존 기능과 신규 연출의 구분

- **현재 구현**: 8명 로스터 및 QWER 판정, 8종 관절 모델, 로스터 초상과 HUD 아이콘, F7 동작 확인 환경(정확한 범위와 품질은 V8/V9 검증 기록 참조).
- **신규 요구**: 고유 얼굴·눈매, 모델별 전용 텍스처와 완성형 머리/의상, 조형이 풍부한 장비, 6~7등신 원화, 정교한 관절 리깅·애니메이션, 역할별 고급 VFX/SFX.
- **원칙**: 문서에 외형을 상세히 썼다는 이유만으로 출시급 3D 자산을 구현 완료로 표기하지 않는다.

| D — 전투 품질 | 3v3·세로 전장·고지·공성 | 960×540/1280×720/1920×1080, 맵/안개, 상대 예고 가독성 |
| E — 사용자 평가 | 8명 첫 인상과 한 경기 | 선호도·영웅 구별·조작/피격 이해도·애착 포인트 기록 |

### A 게이트 실전 체크리스트

- [ ] 바스/테르, 리오/세라, 네마/무아, 오린/루메는 무채색 실루엣으로도 쌍별 구별이 된다.
- [ ] 4×2 선택 화면에서 8명 얼굴이 클론처럼 보이지 않는다.
- [ ] 전투 거리에서 머리/무기/의상 정보가 1초 내에 읽힌다.
- [ ] 선딜·경고·적중·잔류 이펙트가 기존 전투 규칙과 일치한다.
- [ ] 모든 플레이 카메라에서 실제 구조물/병력/HP바/라인을 가리지 않는다.
- [ ] W 지원기와 R 공격기 시각 언어가 구분된다.
- [ ] 팀 색과 영웅 개성이 충돌하지 않는다.
- [ ] 기존 8명 선택과 Godot 실행 검사를 재통과한다.

## 9. 우선 결정할 미술 제작 기준

1. **아트 톤 기준점**: 바스의 묵직함, 리오의 우아함, 세라의 날카로움을 동시에 보여 주는 3인 비교 시안부터 제작.
2. **고유 색 대비**: 리오/세라 및 네마/무아가 같은 계열로 묶여 보이지 않도록 실루엣·빛 방향·문양을 다르게.
3. **얼굴 품질**: 섬세한 2D 인물성과 3D SD 모델의 핵심 표정은 재사용 텍스처 대신 각 영웅 전용 디자인.
4. **세계관 정리**: 아스트라 수로의 길드·룬·마법·자연·천체·연금술을 하나의 오리지널 판타지 세계 언어로 연결.
5. **플레이 증거**: 실제 F7/경기 화면과 독립 콘셉트 렌더를 명확히 구분해 저장.
