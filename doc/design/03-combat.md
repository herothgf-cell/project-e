# 기본 공격과 공통 전투 판정

- 정본: [초기 공통 규칙](../../docs/01-core-rules.md), [캐릭터 공통 예외](../../docs/characters/README.md).
- 적용 단위: 초·m, 위력 `P`, 대상 반경 0.45m인 영웅. 형상은 모델이 아닌 판정체와 겹침으로 검사한다.
- 이번 실행의 판정 주체는 한 프로세스의 로컬 시뮬레이션이다. 온라인 서버 권한은 후속 설계다.
- 영웅별 기하·비용·타이밍과 명시적 예외는 [바스](characters/01-bas.md), [리오](characters/02-rio.md), [네마](characters/03-nema.md)를 따른다.

## 1. 행동 승인

우클릭으로 이동 또는 보이는 적의 기본 공격을 명령한다. Q/W/E/R을 선택하고 지면을 확인하면 기술을 요청한다. 방향 기술은 영웅 문서의 고정 길이를 사용하고, 지점 기술은 중심 간 사거리를 검사한다. 범위 밖 지점을 클릭해도 자동으로 걸어가 시전하지 않는다.

살아 있는지, 종료된 경기인지, 상태 이상과 현재 행동, 쿨타임·에너지·해금·목표 지형·필요한 장치가 유효한지 검사한다. 실패하면 비용과 쿨타임은 발생하지 않는다. NaN·무한대 좌표 역시 거부한다. 승인이 완료되면 에너지 차감과 쿨타임을 즉시 시작하고 위력을 기록한다.

승인 후 기절·넉백·사망 등으로 중단된 시전은 비용을 돌려주지 않는다. 속박은 제자리 기술을 막지 않지만 바스/리오 E의 신규 사용과 진행 중 이동을 막는다. 기술의 선딜·후딜 동안 다른 공격을 실행하지 않으며, 허용되는 예약은 하나로 제한한다. 예약 시점이 아닌 실제 실행 시점에 조건을 다시 검사한다.

설계 시간은 초 단위이며 현재 시뮬레이션은 30Hz 고정 틱으로 진행한다. 0.12초 같은 설정값과 실제 효과가 처리되는 틱을 구분해 기록한다. 시각 애니메이션 프레임으로 타격 횟수나 피해를 늘리지 않는다.

## 2. 기본 능력치와 기본 공격

| 항목 | 바스 | 리오 | 네마 |
|---|---:|---:|---:|
| 시작 HP | 1,100 | 950 | 1,000 |
| 이동 m/s | 5.8 | 6.2 | 6.0 |
| 위력 / 방어 | 100 / 0 | 100 / 0 | 100 / 0 |
| 에너지 최대 / 초당 회복 | 100 / 8 | 100 / 8 | 100 / 8 |
| 기본 공격 사거리 | 2.0m | 6.5m | 5.5m |
| 기본 공격 선딜 | 0.18초 | 0.16초 | 0.18초 |
| 공격 간격 / 비용 | 1.0초 / 0 | 1.0초 / 0 | 1.0초 / 0 |
| 발사 방식 | 선딜 종료 시 접촉 검사 | 탄속 20m/s | 탄속 20m/s |

기본 공격 원피해는 모두 `60 + 0.30P`다. 위력 100이면 90이다. 사거리는 공격자 중심에서 대상의 가장 가까운 외곽까지 잰다. 대상은 적 영웅·병력·셀·적 핀·잠금이 해제된 구조물이며, 신규 지정은 공유 시야가 있어야 한다. 아군을 공격하지 않는다.

간격 1초는 공격 승인부터 센다. 선딜 중 이동·기절·넉백으로 취소해도 간격을 초기화하지 않는다. 액티브와 리오의 강화 공격도 공격 간격을 초기화하지 않는다. 바스는 선딜 종료에 사거리·대상 생존을 재검사한다. 원거리 탄은 발사 후 표적 사망·제거·벽 충돌 시 소멸하고, 시야만 잃으면 추적을 계속한다. 숨은 구간과 적중은 화면에 노출하지 않는다.

## 3. 피해와 보호막

1. 기술 원피해는 `기본값 + 계수 × 승인 시 P`다.
2. 방어 `A`를 적용한 피해는 `원피해 × 100 / (100 + A)`다.
3. 구조물에는 아래 구조물 배율과 잠금을 적용한다.
4. 보호막을 먼저 차감하고 남은 피해를 HP에 적용한다.

피해는 음수가 될 수 없고 계산 내부는 소수를 유지한다. 치명타·무작위 피해·음수 방어는 없다. 이미 발사한 기술의 피해가 이후 성장으로 바뀌지 않는다.

같은 출처 보호막은 기존 잔량과 새 보호막 중 큰 값으로 갱신하고 지속시간을 새로 시작한다. 잔량을 더하지 않는다. 서로 다른 기술 출처는 함께 존재하며 만료가 빠른 순서로 소모한다. 같은 만료 시각이면 먼저 생성한 것을 먼저 소모한다. 보호막도 방어 적용 후 피해를 흡수한다.

같은 시전의 같은 단계는 같은 대상에 한 번만 적중한다. 리오 Q는 출발·귀환을 별도 단계로 두어 각각 1회다. 리오 R의 꼭짓점 중첩과 넓은 기술의 여러 프레임 겹침도 중복 피해를 만들지 않는다.

## 4. 제어 상태

| 상태 | 막는 행동 | 허용되는 행동 |
|---|---|---|
| 기절 | 이동·기본 공격·새 기술, 중단 가능한 진행 시전 | 성장 투자 |
| 속박 | 이동·이동기, 진행 중 지상 이동 | 제자리 기본 공격과 이동 없는 기술 |
| 감속 | 이동속도 일부 | 이동과 모든 유효 행동 |
| 넉백 | 실제 이동 중 제어 | 종료 후 행동; 벽 앞 합법 지점에서 중단 |

감속은 가장 강한 것만 적용하며 기본 이동속도의 40% 아래로 내려가지 않는다. 개별 기절/속박은 최대 1초, 최근 3초 안의 이동 불가 시간 합계는 최대 1.5초다. 겹쳐 흐르는 시간은 한 번만 센다. 새 효과는 남은 예산만 적용한다. 바스 E의 밀기는 최대 0.8m/0.12초이며 남은 CC 예산에 비례해 줄인다.

세 영웅에게 은신·정화·무적 이동·대상 지정 불가·벽 통과는 없다. 부활 보호는 [경기 흐름](01-match-loop.md)의 공통 예외다.

## 5. 지형·시야·구조물

원형·부채는 원점에서 대상 중심까지, 선형 효과는 중심선의 최근접점에서 대상 중심까지 벽 차단을 검사한다. 기술별 투사체·삼각형·장치 조건은 개별 문서가 우선한다. 화면의 예고 형상과 실제 유효 영역은 같은 데이터를 사용해야 한다.

현재 원형·부채 경고는 원래 형상 전체를 표시하고 벽 뒤 부분의 외곽선을 잘라내지 않는다. 실제 피해·보호막은 벽 검사를 통과한 대상에만 적용되므로 벽 근처에서 표시와 유효 영역에 차이가 남는다. 이는 판정 규칙을 바꾼 것이 아니라 해결할 표시 한계이며, [차이 기록 L01](10-differences.md#3-현재-구현의-한계)을 따른다.

지면 기술은 시야 밖에도 사용할 수 있다. 숨은 적중은 피해 숫자·사운드·패시브 표시·에너지 환급으로 위치를 드러내지 않는다. 구조물의 파괴와 핵 잠금 해제는 공개 상태다. 숨은 적 구조물의 실시간 HP·적 유닛 위치를 UI에 흘리지 않는다.

| 구조물 대상 | 최종 배율 또는 결과 |
|---|---|
| 잠긴 내곽/핵 | 피해·적중 보상 0 |
| 영웅 공격/기술/장치 | 기본 0.5배 |
| 공격 팀 라인 병력이 중심 12m 안에 없음 | 위 결과에 추가 0.3배 |
| 라인 병력 공격 | 영웅 0.5배 적용 없음; 병력 부재 보호는 동일 |
| 구조물 제어·보호막 | 속박·감속·넉백·아군 보호막 대상 아님 |
