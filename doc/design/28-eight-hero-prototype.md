# V8 8인 프로토타입

버전은 0.8.0이며 작성일은 2026-11-09다. 사용자의 콘텐츠 상세 기획·원작 역기획·캐릭터 확장 요청을 기존 GitHub 게임허브와 Godot 실행판에 연결했다. “8개군”은 기존 바스·리오·네마를 포함한 총 8명으로 해석했다.

## 구현 범위

| 영역 | V8 구현 |
|---|---|
| 로스터 | 8명 선택, 팀당 3명 자동 편성, 사람 1명과 봇 5명 |
| 전투 | 액티브 32개와 패시브 8개, 기본공격·성장·아이템 |
| 신규 상태 | 바람 준비, 물감 구역, 달 표식, 잔열, 예약 다회 타격 |
| 선택 화면 | 4열 × 2행, 선택 영웅 설명과 QWER 요약, 일반 경기·기술 체험 |
| 영웅 표현 | 8종 관절 모델, 신규 5명 실제 모델 초상, 기술별 동작 |
| 기술 표현 | 아이콘 32개, 경고·발동·지속 상태 효과, 음향 연결 |
| 연출실 | F7의 8명 선택과 32개 액티브, 실제 명령을 통한 사전 준비 |
| 문서 | 현재 콘텐츠 10편, 원작 역기획 6편과 목차, 총 8명 시트, 게임허브 |

## 공통 규칙 연결

새 영웅의 공격은 기존 `area_damage`, `hit_stage`, 기본공격과 피해 경로를 사용한다. 벽, 시야, 강한 제어 상한, 구조물 잠금과 피해 보정이 공통으로 적용된다. 다회 공격은 시전과 단계별 적중 키를 사용한다.

이동기의 속박 판정, 지원형 기술의 승인, 근접 기본공격 구분을 로스터에 맞게 확장했다. 가속 효과는 성장으로 증가한 기본 속도와 별도 상태로 유지한다. 사망과 경기 재설정은 구역·표식·예약 타격·경고·준비 상태를 정리한다.

무아 구역은 활성 구역과 비활성 구역을 다른 밀도로 표시한다. 세라 표식은 적의 관측 조건을 따라 표시한다. 오린 준비와 루메 잔열은 HUD와 영웅 주변 신호로 확인한다. [공용 전투](../../game/project-e/scripts/battle/hero_abilities.gd) · [확장 판정](../../game/project-e/scripts/battle/expanded_abilities.gd) · [지속 표시](../../game/project-e/scripts/presentation/effects_view.gd)

## 프로토타입 편성

사람은 선택한 영웅으로 중앙 라인에 배치된다. 기존 3명 선택 시 각 팀은 바스·리오·네마를 사용한다. 신규 5명 선택 시 아군은 선택 영웅·바스·네마이며 상대는 선택 영웅별 고정 조합이다. 이 조건으로 신규 역할의 진입·지원·견제 대응을 반복해 볼 수 있다. 자유 조합 비교의 시험 조건은 로스터 기획에 정리했다. [편성표](content/07-roster-and-drafting.md)

## 자산 재현

저장소 루트에서 다음 명령으로 신규 GLB 5개와 SVG 20개를 재생성한다. 모델 생성기는 기존 메시 기록기와 관절 이름 규격을 사용한다. 신규 모델은 기존 GLB에 포함된 얼굴·의상 텍스처를 그대로 재사용하고 머리 장식, 외투, 장갑과 무기를 각 역할에 맞춰 구성한다. 원본 텍스처를 복사하는 과정은 이미지 데이터를 변형하지 않는다.

```sh
python tools/build_roster_models_v8.py
python tools/art/build_roster_icons_v8.py
python tools/check_art_assets.py
```

출력 GLB는 `game/project-e/assets/heroes`, 기술 SVG는 `game/project-e/assets/ui/skills`에 저장된다. 실제 모델 초상은 같은 GLB를 `SubViewport`에서 상반신 중심으로 렌더하고 영웅 고유색의 후광을 합성한다. 3종 기존 일러스트와 5종 모델 초상을 4열 × 2행 카드에 배치한 것은 이번 프로토타입의 표현 선택이다. [모델 생성기](../../tools/build_roster_models_v8.py) · [아이콘 생성기](../../tools/art/build_roster_icons_v8.py) · [미술 상세](content/09-art-and-audio.md)
