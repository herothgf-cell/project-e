# 경기 흐름과 승패 상세 기획

한 경기에서 라인 성장의 이익을 지원과 공성으로 전환한다. 승리 조건은 적 마법 핵 파괴다. 플레이어는 영웅 한 명을 조작하고 아군 2명과 상대 3명은 봇이 맡는다. 선택 가능한 영웅은 8명이다.

## 경기 설정

| 항목 | 실행 규칙 |
|---|---|
| 팀 규모 | 서쪽과 동쪽 각 3명 |
| 같은 팀 영웅 | 중복 없이 편성 |
| 양 팀 동일 영웅 | 허용 |
| 전장 | M01 수로 공방, 3라인 |
| 일반 경기 시작 | 레벨 1, XP 0, 성장 2포인트, 골드 100, QWE 사용 가능 |
| 기술 체험 시작 | 출전 영웅 모두 레벨 3, R 해금, 남은 성장 3포인트 |
| 기술 체험 자동 성장 | 일반 시작 대비 HP +80, 위력 +6 |
| 초기 자원 | 현재 HP와 마나를 각각 최대치로 채움 |
| 첫 병력 | 20초에 생성, 이후 18초마다 생성 |
| 첫 경험치 셀 | 30초에 생성 |
| 경기 시계 | 일시 정지 중 멈춤 |
| 결과 확정 | 한 틱의 피해 정산 뒤 핵 생존 검사 |

## 플레이 흐름

| 구간 | 핵심 행동 | 상태와 피드백 | 실패했을 때의 다음 선택 |
|---|---|---|---|
| 영웅 선택 | 역할과 기술을 보고 한 명 선택 | 선택 강조, 역할 설명, 경기 시작 버튼 | 다른 영웅으로 교체 |
| 기지 준비 | 성장 투자와 소모품 구매 | 남은 포인트, 골드, 인벤토리 | 포인트를 보관하거나 다른 아이템 구매 |
| 첫 대치 | 병력 뒤에서 견제하고 직접 마무리 | HP·마나·재사용·개인 XP 변화 | 기지 회복, 옆 라인 지원 요청을 가정한 이동 |
| 측면 선택 | 셀을 확보하거나 교전 지원 | 공개된 셀 등급, 고지·경사, 미니맵 | 적 접근 시 포기하고 라인 복귀 |
| R 선택 | 레벨 3 이후 1포인트 투자 | 해금 상태와 다음 투자 가능 수치 | 능력치 투자 후 해금 연기 |
| 공성 | 병력을 살려 구조물 근처까지 전진 | 잠금 상태, 병력 부재 보호, 포탑 어그로 | 라인 정리와 재집결 |
| 결정적 교전 | 적을 밀어낸 시간에 탑 또는 핵 공격 | 파괴된 구조물, 노출된 핵, 부활 대기 | 회복과 다음 병력 합류 |
| 경기 종료 | 결과 확인 후 재시작 또는 영웅 교체 | 승리·패배·무승부, 개인 전투 기록 | 새 경기 상태 생성 |

## 공성 진행

각 라인은 외곽탑과 내곽탑으로 구성한다. 외곽탑을 파괴하면 같은 라인의 내곽탑을 공격할 수 있다. 어느 한 라인의 외곽과 내곽을 모두 파괴하면 적 핵이 노출된다. 해제된 잠금은 해당 경기 동안 유지된다.

| 상태 | 피해 승인 조건 | 다음 상태 |
|---|---|---|
| 외곽탑 생존 | 살아 있고 적대 대상이면 공격 가능 | 외곽 파괴 후 같은 라인 내곽 잠금 해제 |
| 내곽탑 잠금 | 피해 0 | 같은 라인 외곽 파괴 시 해제 |
| 내곽탑 노출 | 정상 피해와 공성 배율 적용 | 파괴 시 해당 라인의 핵 진입 조건 달성 |
| 핵 잠금 | 피해 0 | 한 라인의 두 탑 파괴 시 해제 |
| 핵 노출 | 정상 피해와 공성 배율 적용 | HP 0이면 해당 틱 종료 판정 |

구조물 중심 12 m 안에 공격 팀의 살아 있는 라인 병력이 있어야 병력 부재 보호를 해제한다. 영웅의 구조물 피해는 0.5배이며, 병력이 없으면 여기에 0.3배를 곱해 원피해의 0.15배가 된다. 셀, 정령목, 물감 구역은 공성 병력을 대신하지 않는다. [전투 판정](03-combat-and-status.md)

## 사망과 복귀

부활 시간은 사망 당시 레벨 L에 대해 `8 + 2 × L`초다. 레벨 1은 10초, 레벨 6은 20초, 레벨 12는 32초다. 부활 시 기지에서 최대 HP와 최대 마나로 돌아온다. 사망 중에도 재사용 시간과 정기 골드 수입이 진행된다.

| 상태 | 사망 처리 |
|---|---|
| 레벨, XP, 성장 투자, 골드 | 다음 생명으로 유지 |
| 진행 중 기본 공격과 시전 | 취소 |
| 자기 보호막과 제어 상태 | 정리 |
| 소유 정령목과 별무리 닻 | 정리 |
| 신규 준비, 표식, 구역, 예약 타격 | 영웅별 시트의 사망 정리 계약 적용 |
| 다른 아군에게 이미 부여한 보호막 | 원래 만료 시각까지 유지 |
| 이미 발사한 일반 원거리 탄 | 표적·벽·수명 규칙으로 처리 |
| 리오의 왕복 혜성 | 소유자 사망 시 종료 |

부활 보호는 3초다. 적대 행동이 승인되면 효과 처리 전에 보호를 해제한다. 지원 행동과 적대 행동은 각 기술의 시전 속성으로 구분한다. 기지 회복은 마지막 피격과 적 영웅 공격 이후의 대기 조건을 적용한다. [성장과 회복](05-growth.md)

## 종료와 재시작 계약

한 팀 핵만 파괴되면 반대 팀 승리다. 같은 틱에 양 팀 핵이 파괴되면 무승부다. 결과 확정 뒤의 명령, 투사체 진행, 피해와 보상은 더 이상 경기 결과를 바꾸지 않는다.

재시작은 시계, 유닛 집합, 소유 상태, 예약 타격, 투사체, 피드백 이벤트, 봇 목표, 승패를 새로 만든다. 이전 경기의 선택 영웅은 다시 시작 버튼의 입력으로 사용할 수 있으며, 영웅 선택 화면에서 교체할 수 있다.

## 검증 기준

- 8명 각각 시작했을 때 조작 영웅이 정확하고 영웅 수는 6명이다.
- 각 팀의 3라인에 영웅이 한 명씩 배치된다.
- 체험 시작의 R과 잔여 포인트가 모든 출전 영웅에게 동일한 규칙으로 적용된다.
- 잠긴 핵, 한 라인만 열린 핵, 같은 틱 양 핵 파괴를 각각 검사한다.
- 사망 직전에 예약한 타격과 구역이 사망 정책대로 정리된다.
- 결과 뒤 계속 들어온 입력이 새 피해와 보상을 만들지 않는다.
- 재시작 뒤 이전 경기의 타격이나 화면 피드백이 재생되지 않는다.

12–18분은 사람 플레이에서 확인할 경기 길이 가설이다. 첫 교전, 첫 R, 첫 외곽 파괴, 첫 핵 노출, 경기 종료 시각을 함께 기록해 지연 원인을 구분한다. [플레이테스트](10-playtest-and-balance.md)
