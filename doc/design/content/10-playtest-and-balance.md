# 8인 프로토타입 플레이테스트와 밸런스

프로토타입은 8명 각각의 핵심 행동을 학습할 수 있는지, 상대에게 읽을 수 있는 대응이 있는지, 세 라인의 성장과 공성이 끝까지 이어지는지를 확인한다. 원작의 전투 감각과 비교할 때는 시전 간격, 자원 부족, 성장 체감과 지원 시간을 함께 기록한다.

## 시험 순서

| 단계 | 조건 | 완료 기준 |
|---|---|---|
| 기술 단독 | 기술 체험과 F7, 대상과 위치 고정 | 패시브와 QWER의 실제 효과·범위·만료 확인 |
| 1 대 1 교전 | 같은 레벨과 투자, 아이템 조건 고정 | 핵심 연계와 상대 대응을 각각 수행 |
| 라인 시험 | 병력 웨이브와 셀 활성 | 미니언 정리, 마무리, 셀 이탈 비용 관찰 |
| 3 대 3 조합 | 조합과 시작 진영 기록 | 보호·제어·피해의 중첩과 공성 기여 관찰 |
| 전체 경기 | 일반 성장과 골드 사용 | 첫 교전부터 결과와 재시작까지 완료 |
| 원작 비교 | 동일한 질문으로 원작 장면 기록 | 확인된 수치와 체감 차이를 분리해 설명 |

## 영웅별 학습 과제

| 영웅 | 조작 과제 | 상대 대응 과제 | 실패 시 우선 확인 |
|---|---|---|---|
| 바스 | 룬 두 중첩 뒤 강화 보호막 발동 | 돌진 접촉 전에 옆으로 회피 | 룬 준비와 보호막 신호 |
| 리오 | 같은 적에게 출발·귀환 명중 | 귀환 경로에서 벗어나기 | 닻과 귀환 방향 표시 |
| 네마 | 두 정령목 연결로 W·R 실행 | 정령목 파괴 후 R 차단 | 설치 범위와 연결 경고 |
| 오린 | 준비형 Q와 기본 공격 강화 연결 | 좁은 탄과 넓은 파동에 다른 회피 | 준비 상태와 사거리 차이 |
| 테르 | 뒤의 아군을 W로 보호하고 E 반격 | 뒤쫓는 대신 측면 진입 | 보호 방향과 반격 예고 |
| 무아 | 두 구역 전환 후 아군 보조 | 비활성 쪽으로 교전 이동 | 활성·비활성 표시 |
| 세라 | 표식을 쌓아 기본 공격 또는 R로 소비 | 표식 만료까지 거리 유지 | 표식 수·남은 시간·소비 피드백 |
| 루메 | 잔열 강화와 다회 포격 활용 | 포격 경고 구역을 순서대로 이탈 | 발동 시점과 남은 타격 수 |

첫 테스트에서 참가자는 도움말을 본 뒤 핵심 과제를 시도한다. 수행 성공 여부와 설명 가능한지 함께 기록한다. 수치를 조정하기 전에 입력 실패와 표시 오해를 먼저 확인한다.

## 경기 기록표

| 구분 | 기록할 값 |
|---|---|
| 환경 | 빌드 커밋, 버전, OS, GPU, 해상도, 입력 장치 |
| 참가 | 영웅, 진영, AOS 경험, 해당 영웅 경험 |
| 편성 | 양 팀 3명과 라인 |
| 경기 시간 | 첫 영웅 피해, 첫 처치, 첫 R, 첫 외곽 파괴, 핵 노출, 종료 |
| 성장 | 분별 레벨과 XP, 포인트 배분, 미사용 포인트 |
| 경제 | 분별 골드, 구매·사용 아이템, 획득량과 지출량 |
| 전투 | QWER 횟수, 마나 부족 시간, 적중, 제어, 보호막, 유효 회복 |
| 이동 | 지원 결정 시각, 합류 시각, 비운 라인 손실 |
| 목표 | 셀 획득과 포기, 탑 피해, 공성 병력 동반 여부 |
| 조작 | 잘못된 영웅 선택, 조준 실패 이유, 카메라 재중앙 횟수 |
| 표현 | 읽기 어려운 기술 조합, 화면 가림, 소리 중복 |

## 비교 실험의 통제

- 같은 조합과 투자·아이템 조건으로 양 진영을 교환한다.
- 한 번의 수정에서는 피해, 재사용, 범위, 자원 비용 중 주요 변수를 하나로 제한한다.
- 원작 비교에서는 영상의 실제 버전과 경기 시간을 기록한다.
- 플레이어 숙련 차이가 큰 경기는 원인 설명을 함께 남긴다.
- 짧은 테스트의 승률은 실제 경기 수와 함께 제시한다.
- 자동 봇 경기 결과와 사람 조작 기록은 각각의 실행 조건을 붙인다.

## 역할별 실패 기준

| 현상 | 먼저 살펴볼 항목 | 조정 방향 |
|---|---|---|
| 신규 영웅의 핵심 연계를 사용하지 않음 | 조준과 준비 신호, 비용, 사거리 | 사용 조건과 UI를 이해할 수 있게 수정 |
| 보호 조합을 뚫을 수 없음 | 출처별 보호막 합, 재사용, 체류 조건 | 보호 시간·조건·범위의 선택 비용 확대 |
| 암살 대응 시간이 없음 | 진입 거리, 선딜, 표식 공개, 피해 집중 | 피해가 발생하기 전 읽을 구간 확보 |
| 포격으로 라인 접근이 봉쇄됨 | 범위·지속·연속 시전·마나 재생 | 안전 경로와 재배치 시간 확보 |
| 구역 효과가 구별되지 않음 | 활성 표시, 팀 색, 바닥 대비 | 활성 상태를 형태와 밀도로 구분 |
| 골드만 계속 쌓임 | 회복 필요, 구매 장소, 사용 제한 | 효과량·수입·칸·복귀 비용 중 병목 검토 |
| 지원이 항상 손해임 | 실제 합류 시간, 라인 손실, 셀 보상 | 연결로·목표·지원 보상의 원인별 검토 |
| 한 번 밀린 뒤 복구 기회가 없음 | 자동 성장, 투자량, 처치·공성 보상 | 열세 팀의 정보·목표·방어 선택 관찰 |

## 원작 비교 질문

| 질문 | 원작에서 볼 장면 | 현재 게임에서 볼 장면 |
|---|---|---|
| 기술을 얼마나 자주 쓰는가 | 일반기 반복 사용과 포션 직후 | 재사용이 끝났으나 마나가 부족한 구간 |
| 성장 투자가 즉시 느껴지는가 | 같은 기술을 투자 전후 사용 | +위력·HP·방어 투자 전후 교전 |
| 포션이 공격 기회를 만드는가 | 마나포션 사용 후 연속 공격 | 별샘 영약 사용 뒤 추가 시전 |
| 라인 이탈의 선택이 있는가 | 측면 캡슐과 중앙 지원 | 셀·고지·인접 라인 이동 |
| 마무리 행동이 중요한가 | 병력의 저체력 공격 중단 | 1 HP 유보 뒤 영웅의 직접 마무리 |
| 역할 차이가 조합을 바꾸는가 | 실제 영웅별 투자와 교전 패턴 | 8명 역할표의 연계와 대응 |
