# Project E 콘텐츠 상세 기획

8명의 판타지 영웅으로 3 대 3 전투를 구성한다. 라인 병력 마무리, 측면 경험치 셀, 인접 라인 지원, 성장 투자, 병력 동반 공성이 한 경기의 선택을 만든다. 기준 버전은 V9 프로토타입이며 날짜는 2026-11-10이다. 세로 표시 좌표와 열린 라인 재배치는 V9에 적용했다.

## 원작에서 가져온 플레이 원리

| 원작에서 관찰한 요소 | Project E 적용 | 플레이어가 하는 판단 |
|---|---|---|
| 시작부터 일반 기술 활용 | QWE 즉시 사용 | 첫 라인 교전에서 자신의 기술 조합 선택 |
| 짧은 재사용과 마나 사용 | 반복 시전과 마나 회복, 별샘 영약 | 계속 싸우기와 회복·철수의 시점 |
| 광물로 능력치와 기술 습득 | 성장 포인트로 능력치 또는 R 해금 | 즉시 생존·화력과 새로운 기술 사이 투자 |
| 일반 병력의 마무리 유보 | 근접·원거리 병력의 1 HP 보존 | 직접 마무리할 위치와 타이밍 |
| 라인 옆 경험치 목표 | 20·30·40 XP 셀과 고지 | 라인 유지, 성장 목표, 옆 라인 지원 |
| 좁은 전장에서 빠른 합류 | 세 라인과 네 연결로, 두 고지의 지원 경사 | 비운 라인의 손실과 지원 이익 비교 |

원작의 확인된 수치와 시대별 자료는 별도 역기획에서 찾을 수 있다. 1 HP 보존, M01의 미터 단위, V8 신규 영웅 수치는 Project E의 설계값이다. [시티 오브 템페스트 역기획](../reverse-design/README.md)

## 구현과 실험 기록

이 폴더의 수치표는 현재 실행 경로를 설명한다. 각 문서의 후속 실험 항목은 플레이 결과로 채택 여부를 결정한다. 사람 대상 밸런스와 장시간 성능은 빌드·장비·참가자·경기 기록을 함께 남긴다.

현재 캐릭터별 기술의 정확한 수치는 영웅 시트와 공용 스킬 데이터를 연결한다. 새 원작 자료가 생기면 원작 근거 등록부와 관련 콘텐츠의 비교표를 함께 갱신한다. [영웅 시트](../characters/README.md) · [공용 스킬 데이터](../../../game/project-e/scripts/battle/hero_abilities.gd) · [게임허브](../README.md)
