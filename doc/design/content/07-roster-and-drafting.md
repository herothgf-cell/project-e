# 8인 로스터와 3인 편성 상세 기획

기존 바스·리오·네마에 오린·테르·무아·세라·루메를 더해 총 8명의 영웅으로 시험한다. 역할마다 주력 행동, 필요한 준비, 성공 보상, 상대 대응이 달라야 한다. 한 경기는 선택 풀에서 각 팀 3명을 편성한다.

## 역할과 플레이 구분

| 영웅 | 전투 역할 | 핵심 반복 행동 | 강점 | 상대의 대응 |
|---|---|---|---|---|
| 바스 | 근접 돌파 | 기술 적중으로 룬을 쌓고 기본 공격으로 보호막 획득 | 선제 진입과 근거리 교전 | 진입 방향 회피, 접촉 전 거리 유지 |
| 리오 | 궤도 견제 | 원반의 왕복과 닻 위치를 조합 | 두 번의 경로 피해와 삼각 외곽 압박 | 귀환 궤도 이탈, 삼각 중앙 활용 |
| 네마 | 설치 제어 | 정령목 두 그루의 연결을 만들고 유지 | 길목 제어와 아군 보호 | 정령목 파괴, 연결 밖 교전 |
| 오린 | 준비형 사수 | 준비 파동과 기본 공격 강화를 교대 | 중거리 반복 화력 | 준비 신호를 보고 거리와 옆 방향 조절 |
| 테르 | 후퇴 보호 | 후방 아군을 감싸고 후퇴 지점을 반격 | 보호막과 추격 차단 | 측면 압박, 긴 경고 범위 이탈 |
| 무아 | 구역 지원 | 두 구역 중 활성 위치를 전환 | 아군의 위치 선택과 이동 보조 | 비활성 구역과 전환 시점 활용 |
| 세라 | 표식 암살 | 표식을 쌓고 평타 또는 R로 회수 | 짧은 근접 교전의 집중 피해 | 표식 만료 유도, 진입 지점 통제 |
| 루메 | 지연 포격 | 잔열을 준비하고 지면 폭발을 배치 | 웨이브와 고정 지역 압박 | 경고를 보고 이동, 포격 대기 중 접근 |

네마는 파괴 가능한 정령목과 연결선을 사용한다. 무아는 공격 대상이 되는 설치물 없이 만료되는 바닥 구역을 교대한다. 이 두 영웅의 상대 대응은 각각 파괴와 위치 전환에 중심을 둔다.

## 프로토타입 자동 편성

| 선택 영웅 | 아군 출전 | 상대 출전 |
|---|---|---|
| 바스·리오·네마 중 선택 | 바스·리오·네마 | 바스·리오·네마 |
| 오린 | 오린·바스·네마 | 바스·세라·무아 |
| 테르 | 테르·바스·네마 | 바스·루메·오린 |
| 무아 | 무아·바스·네마 | 바스·테르·루메 |
| 세라 | 세라·바스·네마 | 바스·오린·테르 |
| 루메 | 루메·바스·네마 | 바스·무아·세라 |

사람이 선택한 영웅은 중앙 라인에서 시작하고 아군 두 봇은 양쪽 라인에 배치한다. 상대는 편성 순서대로 세 라인에 배치한다. 같은 편성은 반복 시험할 때 비교 조건을 고정할 수 있다. 초기 세 영웅의 경기는 기존 기준 조합으로 반복한다.

현재 자동 편성표는 신규 영웅을 즉시 조작하고 상성 장면을 보는 테스트 구성이다. 역할별 균등한 승률이나 최종 추천 조합으로 해석하려면 좌우 교환과 사람 플레이 기록이 필요하다.

## 조합 실험 설계

8명에서 중복 없이 3명을 고르는 조합 수는 56개다. 초기 테스트에서는 행동 상호작용이 큰 조합부터 선택하고, 각 조합을 양 진영에서 번갈아 사용한다.

| 조합 | 시험할 상호작용 | 과도할 때 관찰될 현상 |
|---|---|---|
| 바스·세라·리오 | 진입 이후 표식 회수와 귀환 경로 | 한 번의 진입으로 대응 없이 처치 |
| 테르·무아·네마 | 후퇴 보호, 활성 구역, 정령목 연결 | 공격 팀이 돌파하거나 목표 전환을 할 수 없음 |
| 루메·오린·리오 | 지연 폭발과 직선 견제, 귀환 궤도 | 라인 접근과 미니언 마무리 자체가 불가능 |
| 바스·무아·루메 | 구역 지원을 받은 근접 진입과 후속 포격 | 범위 경고가 겹쳐 안전 지점 판단이 어려움 |
| 테르·세라·오린 | 후위 보호와 짧은 암살 기회 | 딜러가 전후방 압박을 동시에 무시 |

이 조합들은 상세 플레이테스트 시나리오다. 현재 선택 화면의 자동 편성 범위는 위 자동 편성표를 따른다.

## 캐릭터별 완료 조건

- 기본 공격과 패시브, QWER가 실제 전투 상태를 바꾼다.
- 기술마다 조준·예고·비용·재사용·범위·적중·사망 조건을 시트에 기록한다.
- 같은 영웅의 아이콘, 툴팁, 경고와 실제 효과가 일치한다.
- 일반 경기와 기술 체험, F7에서 선택할 수 있다.
- 봇이 해당 영웅의 선행 상태를 만들고 기술을 사용한다.
- 실루엣과 손에 든 장비로 역할을 구분할 수 있다.
- 초심자가 핵심 연계 한 번과 상대 대응 한 번을 수행한다.
