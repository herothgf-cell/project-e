# UI와 카메라 상세 기획

플레이어가 영웅을 고르고 교전 중 필요한 정보를 읽는 흐름을 우선한다. 화면은 선택, 경기, 성장·상점·도움말, 결과, F7 연출실로 구성한다. 카메라는 영웅 추적으로 시작하고 명시적인 시점 조작에 반응한다.

## 영웅 선택

| 영역 | 정보와 행동 |
|---|---|
| 영웅 카드 | 4열×2행의 8명, 초상·이름·선택 강조 |
| 선택 영웅 상세 | 역할, 플레이 핵심, QWER 아이콘·이름·요약 |
| 일반 경기 | 레벨 1, 성장 2포인트 |
| 기술 체험 | 레벨 3, R 해금 |
| 경기 시작 | 선택한 영웅 이름을 포함한 명확한 버튼 |
| 도움 | 기본 조작과 F7 접근 안내 |

선택은 하나만 활성화한다. 영웅 변경 시 상세 패널과 시작 버튼을 같은 키로 갱신한다. 모드 선택도 일반·체험 중 하나만 활성화한다. 카드를 누르는 입력이 뒤 전장의 이동 명령으로 전달되지 않아야 한다.

기준 프레임은 1280×720이고 작은 창에서는 비율에 맞춰 배치한다. 960×540, 1280×720, 1366×768에서 모든 카드, 모드, 시작 버튼을 실제 포인터로 누를 수 있어야 한다.

## 전투 HUD

| 우선순위 | 정보 | 표시 방식 |
|---|---|---|
| 즉시 생존 | 현재 HP, 보호막, 마나, 피격과 회복 | 하단 자원 바와 전장 유닛 표시 |
| 기술 실행 | QWER 해금·비용·재사용·이름 | 하단 기술 슬롯과 툴팁 |
| 캐릭터 고유 상태 | 룬, 원반·닻, 정령목, 준비, 활성 구역, 표식, 잔열 | 패시브 상태와 필요한 월드 표시 |
| 성장 | 레벨, XP, 남은 포인트 | XP 바와 성장 버튼 |
| 전장 판단 | 미니맵, 셀 등급, 구조물과 핵 | 현재 관측 정보와 고정 지형 |
| 경제 | 골드, 보유 아이템, 공용 사용 재사용 | 인벤토리와 상점 버튼 |
| 경기 상태 | 시간, 승패, 조작 안내 | 상단과 결과 패널 |

사용 가능한 기술은 아이콘·명칭·비용을 읽을 수 있게 한다. 잠긴 R에는 레벨과 포인트 조건을 표시한다. 목표 조준 중에는 유효 범위와 거절 이유를 표시하며, 실제 피해 형상을 사용하는 경고가 지형과 겹치지 않게 배치한다.

## 조작표

| 입력 | 행동 |
|---|---|
| 우클릭 지면 | 이동 |
| 우클릭 보이는 적 | 지정 기본 공격 |
| A 이후 지면 좌클릭 | 공격 이동 |
| Q·W·E·R 이후 좌클릭 | 기술 선택 후 조준 확정 |
| Esc | 조준 취소 또는 열려 있는 패널 닫기·일시 정지 |
| S | 행동 정지 |
| G | 성장 화면 |
| B | 기지 복귀 이동 명령 |
| P | 기지 상점 화면 |
| D | 선택한 소모품 사용 |
| F1 | 조작과 전장 도움말 |
| Y | 영웅 추적 전환 |
| Space | 조작 영웅에게 초점 복귀 |
| 마우스 가운데 버튼 드래그 | 자유 카메라 이동 |
| 마우스 휠 | 확대·축소 |
| F6 | 전투·전술·근접 시점 순환 |
| F7 | 영웅·스킬·전장 연출실 |

B는 현재 위치에서 합법적인 지상 경로를 따라 기지로 걸어가는 이동 명령이다.

## 카메라 수치와 상태

| 항목 | 실행 규칙 |
|---|---|
| 경기 시작 | 영웅 추적 ON, 전투 시점 |
| 투영 | 원근, FOV 42도, 피치 55도 |
| 추적 보간 | 매 프레임 `1 − exp(−12 × delta)` 비율로 목표 위치 접근 |
| 시점 크기 | 전투 30, 전술 50, 근접 18 |
| 휠 범위 | 크기 16~58 |
| 자유 이동 속도 | 최대 23 m/s |
| 카메라 초점 범위 | X −55~55, 북쪽 좌표 −31~31 |
| 가장자리 진입 폭 | 720 높이 기준 32 px, 창 크기에 비례 |
| 가장자리 속도 | 안쪽에서 바깥쪽으로 연속 증가 |
| UI 위 가장자리 예외 | 최외곽 10 px 안에서 이동 허용 |

영웅 추적 중에는 마우스가 화면 내부에 들어왔다가 새로 가장자리로 진입했을 때 자유 시점으로 전환한다. 경기 시작 시 이미 마우스가 가장자리에 있는 경우 갑작스럽게 카메라가 이동하지 않는다. 네 방향은 같은 규칙을 사용하고 대각선은 속도를 정규화한다.

조준 중, 모달 패널 사용 중, 창 포커스가 없는 경우 가장자리 이동을 중단한다. 좌클릭을 누른 채 기술을 확정하는 동안 가장자리 이동으로 조준 위치가 밀리지 않게 한다. 창 포커스를 잃으면 드래그와 가장자리 진입 상태를 정리한다.

## 패널과 일시 정지

로컬 성장·도움말·상점·일시 정지 패널은 경기 상태와 입력 차단을 함께 관리한다. 정보를 알리는 토스트는 전장 클릭을 막지 않는다. 패널을 닫을 때 기존 일시 정지 상태를 정확히 복원한다.

상점은 골드, 가격, 효과, 수량, 구매 불가 이유를 보여준다. 성장 메뉴는 현재 수치와 1회 증가량, 상한을 보여준다. 중첩된 패널이나 조준 상태에서 Esc를 눌렀을 때 가장 앞의 사용자 의도부터 해제한다.

## F7 연출실

F7은 원래 경기를 보존한 별도 장면에서 대기·이동·기본 공격·QWER·피격·사망·부활·언덕 이동을 실행한다. 8명 모두 선택 가능하며 준비가 필요한 기술은 실제 기술 명령으로 사전 조건을 만든다.

| 기술 조건 | 연출실의 준비 |
|---|---|
| 네마 W·R | 실제 Q로 정령목 설치 |
| 무아 W·R | 실제 Q로 물감 구역 설치 |
| 세라 R 표식 연계 | 실제 공격 기술로 표식 부여 |
| 다회 포격 | 경고, 첫 타격, 다음 타격을 경기 시계로 진행 |

연출실을 닫으면 원래 경기의 유닛·HP·위치·시계·카메라·패널 상태를 복원한다. 연출실에서 체험한 성장과 아이템은 원래 경기에 영향을 주지 않는다.

## 검증 기준

- 가장 작은 창에서 8명 각각 실제 포인터 선택 후 시작한다.
- 선택과 시작의 영웅 키, HUD 이름과 네 기술이 일치한다.
- 가장자리 네 방향과 대각선, 내부 재진입, 포커스 상실을 검사한다.
- 성장·상점·도움말 뒤의 전장으로 클릭이 통과하지 않는다.
- 토스트와 타깃 정보, 미니맵과 카메라 안내가 겹치지 않는다.
- F7의 32개 액티브와 사전 조건을 검사한다.
- 연출실 종료 뒤 원래 경기의 상태를 비교한다.
