# 전투와 상태 상세 기획

전투의 판정은 30 Hz 로컬 시뮬레이션에서 수행한다. 사람, 봇, 기본 공격, 액티브, 설치물과 예약 타격은 같은 피해·제어·시야 규칙을 사용한다. 영웅별 기술은 명중 위치, 예고, 비용, 보상과 대응 행동에서 차이를 만든다.

## 입력 승인 순서

1. 경기 진행 여부와 영웅 생존을 확인한다.
2. 유한한 목표 좌표, 기술 슬롯과 영웅 데이터를 확인한다.
3. 현재 행동, 기절과 속박, 필요한 선행 상태를 확인한다.
4. R 해금, 재사용 시간, 마나를 확인한다.
5. 사거리, 보행 가능 지점, 벽과 필요한 설치물·구역을 확인한다.
6. 승인 시 마나를 차감하고 재사용 시간을 시작하며 현재 위력을 저장한다.
7. 경고를 표시하고 선딜이 끝나는 틱에 효과를 처리한다.
8. 후딜을 거쳐 다음 행동을 승인한다.

거절된 명령은 비용을 소비하지 않는다. 시전 승인 뒤 기절·넉백·사망으로 취소된 기술은 이미 소비한 비용을 돌려주지 않는다. 예약된 명령은 실행 순간에 유효성을 다시 검사한다. 범위 밖 지점 클릭은 자동 접근 시전으로 바꾸지 않는다.

## 기본 공격

| 항목 | 공통 규칙 |
|---|---|
| 원피해 | `60 + 0.30 × 위력` |
| 시작 위력 | 100, 기본 공격 원피해 90 |
| 공격 간격 | 승인 시점부터 1초 |
| 마나 비용 | 0 |
| 근접 영웅 | 바스, 테르, 세라 |
| 원거리 영웅 | 리오, 네마, 오린, 무아, 루메 |
| 원거리 기본 탄속 | 20 m/s |
| 사거리 기준 | 공격자 중심에서 대상 외곽까지 |
| 신규 표적 | 보이는 적 영웅·병력·셀·정령목·공격 가능한 구조물 |

근접 공격은 선딜 종료 시 생존과 사거리를 다시 확인한다. 원거리 공격은 실제 탄을 생성하며 표적 소멸과 벽 충돌에 따라 종료한다. 표적이 시야에서 사라진 뒤에도 이미 발사한 탄은 추적 규칙을 유지하고, 숨은 경로와 적중 정보는 화면에서 가린다.

이동이나 제어로 기본 공격 선딜이 취소되어도 공격 간격을 초기화하지 않는다. 패시브 강화 공격도 별도의 공격 속도 초기화를 제공하지 않는다. 강화의 부여·만료·소비 조건은 각 캐릭터 시트를 따른다. [영웅 시트](../characters/README.md)

## 피해 계산

| 단계 | 계산 또는 조건 |
|---|---|
| 승인 위력 | `P = 시전 승인 시점의 위력` |
| 기술 원피해 | `고정 피해 + 계수 × P` |
| 방어 | `원피해 × 100 / (100 + 방어)` |
| 구조물 잠금 | 잠금 중 피해 0 |
| 영웅의 구조물 피해 | 방어 적용 피해 × 0.5 |
| 공격 팀 병력 부재 | 구조물 피해에 추가로 × 0.3 |
| 보호막 | 만료가 빠른 보호막부터 차감 |
| HP | 남은 피해만 차감, 최저 0 |
| 중복 방지 | 시전 ID·적중 단계·대상 ID 조합당 1회 |

방어 20이면 피해 배율은 `100 / 120`이고 감소율은 약 16.67%다. 원작의 방어 1당 1% 감소와 수식이 다르므로 같은 숫자의 투자를 같은 효과로 해석하지 않는다. [원작 성장과 경제](../reverse-design/03-growth-and-economy.md)

피해와 보호막은 내부적으로 소수를 보존한다. 화면의 정수 표시가 실제 회복·피해 적산을 바꾸지 않는다. 사후 성장 투자는 이미 승인한 기술의 저장 위력에 소급하지 않는다.

## 보호막과 회복

같은 출처의 보호막을 다시 받으면 기존 잔량과 새 부여량 중 큰 값을 사용하고 만료를 갱신한다. 서로 다른 출처는 함께 존재한다. 보호막 소비 순서는 빠른 만료 우선이며 동률이면 먼저 생성한 순서다.

회복은 최대 HP 또는 최대 마나를 넘지 않는다. 아이템 회복은 마지막 부분 틱까지 실제 남은 시간만 지급한다. 숲빛 치유약의 중단 여부는 적 영웅 소유 피해가 유효하게 들어왔는지로 결정한다. [골드와 아이템](06-gold-and-items.md)

## 상태 이상과 이동

| 상태 | 제한 | 허용과 경계 |
|---|---|---|
| 기절 | 이동, 기본 공격, 새 시전 제한 | 성장 투자 가능 |
| 속박 | 지상 이동과 이동 기술 제한 | 제자리 공격과 이동 없는 기술 가능 |
| 감속 | 이동속도 감소 | 가장 강한 감속 적용, 기본 이동의 40% 하한 |
| 넉백 | 강제 이동 중 제어 제한 | 벽 앞 합법 지점에서 중단 |
| 시간제 가속 | 만료까지 이동 보조 | 성장으로 얻은 기본 이동속도와 별도 저장 |

기절·속박·넉백의 단일 적용 시간은 최대 1초다. 최근 3초의 제어 구간 합집합은 신규 연장량 계산의 기준이 되며 총 1.5초 예산을 사용한다. 이미 겹친 제어 시간을 단순 합산해 이중으로 소비하지 않는다. 감속은 이 강제 제어 예산과 별도로 처리한다.

이동 기술은 시전 데이터의 이동 속성으로 속박을 검사한다. 선딜 중 속박이 들어와도 이동 실행을 차단한다. 돌진은 지형과 영웅 충돌을 검사하고, 접촉 효과가 있는 기술은 실제 첫 접촉 대상에 적용한다.

## 다회 타격과 소유 상태

| 유형 | 판정 계약 | 정리 조건 |
|---|---|---|
| 왕복 혜성 | 출발과 귀환이 각각 한 번 적중 | 소유자 사망, 벽, 거리와 수명 |
| 쌍둥이 폭풍 | 두 타격의 적중 단계를 구분 | 각 단계 처리 뒤 제거, 소유자 사망 정책 적용 |
| 유성 가마 | 세 포격의 예정 시각과 단계를 구분 | 마지막 타격 또는 소유자 사망 |
| 물감 구역 | 소유자별 최대 두 개, 하나 활성 | 수명, 세 번째 설치, R 소비, 사망 |
| 월영 표식 | 소유자와 대상별 스택·만료 | 강화 적중 소비, 만료, 관련 사망 |
| 시전 경고 | 실제 예정 형상·시점과 연결 | 취소, 실행 또는 사망 |

각 타격의 경고는 같은 판정 형상을 사용한다. 여러 화면 프레임의 겹침이 추가 피해를 만들지 않는다. 이전 경기에서 예약한 타격은 새 경기에서 실행되지 않는다.

## 공격 이동

`A → 지면 좌클릭`은 최종 목적지를 보존하고 8 m 안의 보이는 적 영웅·병력·잠금 해제 구조물을 탐색한다. 유효한 표적을 유지하며 거리 동률은 ID로 정한다. 획득한 위치로부터 최대 8 m까지 추격한다. 시야를 잃으면 추격을 중단하고 목적지로 복귀한다.

셀과 정령목은 직접 지정해 공격한다. 목적지에 도착한 뒤에는 기본 사거리와 물리 시선 안의 적을 공격하며, 새 추격으로 목적지를 떠나지 않는다. 입력한 스킬은 플레이어의 명령으로 실행한다.

## 검증 기준

- 같은 시전·같은 단계의 중복 피해가 차단되고 다른 단계는 각각 적중한다.
- 보호막의 같은 출처 갱신과 다른 출처 중첩을 구분한다.
- 비용 부족, 잘못된 좌표, 해금 전 R, 벽 너머 지점을 거절한다.
- 이동기 선딜과 돌진 도중의 속박을 각각 검사한다.
- 새 영웅의 표식과 구역을 두 소유자가 동시에 사용해 상태 격리를 확인한다.
- 죽은 소유자의 예약 타격과 새 경기의 예약 타격을 검사한다.
- 안개 속의 실제 판정이 HP바·음향·표식 위치로 공개되지 않는지 검사한다.
