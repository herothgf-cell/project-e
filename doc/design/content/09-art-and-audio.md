# 미술과 소리 상세 기획

아스트라 전장은 3등신 세미카툰 판타지 영웅과 수로 공방을 사용한다. 전투 거리에서 몸의 색, 장비 실루엣, 시전 자세, 효과 형상을 함께 읽어야 한다. 8명 확장은 각 역할의 다른 행동을 실제 모델과 연출로 드러내는 프로토타입이다.

## 캐릭터 실루엣

| 영웅 | 주요 형태 | 색과 소재 | 행동에서 강조할 부분 |
|---|---|---|---|
| 바스 | 크고 낮은 건틀릿 | 붉은 의상, 금빛 룬, 거석 | 전방 돌파와 양손 내려치기 |
| 리오 | 원반과 넓은 모자 | 보라 의상, 푸른 별빛 | 원반 방출과 귀환 방향 |
| 네마 | 정령 지팡이와 잎 장식 | 녹색 천, 목재와 잎 | 심기, 연결, 보호 동작 |
| 오린 | 넓어지는 송풍관과 가벼운 두건 | 모래색 천, 금빛 바람 | 준비된 사격 자세와 발사 반동 |
| 테르 | 세로로 긴 접이식 수정 방패 | 빙청색 수정과 단단한 판 | 후방을 감싸는 자세, 후퇴 반격 |
| 무아 | 둥근 붓통과 수평 붓 | 민트 물결과 유약 | 바닥을 칠하고 활성 구역을 바꾸는 손짓 |
| 세라 | 양손 초승달 검과 짧은 망토 | 보라 월광과 어두운 천 | 짧은 진입, 교차 베기와 표식 회수 |
| 루메 | 연금 병과 둥근 모자 | 주황 불씨와 유리 | 병 투척, 예고된 포격과 잔열 |

새 영웅은 같은 관절 체계를 사용하되 머리·장비·외투·비례와 시전 자세를 개별 구성한다. 얼굴과 의상은 기존 GLB의 텍스처를 재사용하고, 두건·수정 관·베레모·묶은 머리·고글 모자와 역할별 장비를 조합한다. 초상은 기존 일러스트 또는 실제 영웅 모델의 상반신 렌더를 사용하며, 모델 렌더 초상에는 영웅 고유색의 후광을 둔다.

## 화면 읽기 우선순위

1. 실제 피해와 제어 범위, 발동 시점.
2. 적과 아군, 표적과 조작 영웅.
3. 이동 방향과 공격 준비 자세.
4. 패시브 준비와 기술 연계 상태.
5. 재질, 입자, 환경 장식.

아군은 청록 계열의 팀 표시, 적군은 따뜻한 적대 표시를 사용한다. 영웅 고유색은 팀 색과 함께 사용하되 장비 형상과 경고 형태만으로도 구별 가능하게 한다. 발판과 경사는 이동 가능한 높이를 설명해야 한다.

## 스킬 연출 계약

| 단계 | 표시 | 실제 상태와의 연결 |
|---|---|---|
| 조준 | 유효 범위와 방향 | 권한의 preview 형상 |
| 선딜 | 발동까지 남은 경고 | 시전 남은 시간 |
| 발동 | 고유 모티프와 짧은 적중 강조 | 실제 피해·보호·이동 처리 |
| 지속 | 구역·닻·표식·준비·회복 상태 | 소유 상태와 만료 시각 |
| 종료 | 소모·만료·취소에 맞춘 제거 | 상태 정리 결과 |

다회 공격은 다음 타격의 범위와 시간을 보여준다. 이동기의 궤적은 실제 이동 구간을 따르며 벽을 통과한 장식이 합법 이동으로 오해되지 않게 한다. 공격 범위 밖의 큰 장식은 피해 경고와 형태·밝기를 구분한다.

## 아이콘과 텍스트

액티브 아이콘 32개는 영웅의 장비와 해당 행동을 함께 표현한다. 파일 키, SVG 제목, HUD 표시 이름을 같은 기술 데이터와 연결한다. 색상만 다른 동일 도형을 여러 기술에 배정하지 않는다. 패시브는 이름과 현재 상태를 HUD에서 읽게 한다.

툴팁은 기본 피해와 위력 계수, 사거리·형상, 제어, 비용·재사용·준비 조건을 알려준다. 상태가 필요한 기술은 실패 이유를 함께 표시한다. 긴 설명은 선택 화면의 요약과 전투 툴팁으로 나누어 읽게 한다.

## 소리

현재 음향은 조작 영웅의 상태 전환을 관측해 재생한다. 새 5명도 기존 마법·근접·자연 계열의 음원에 연결한다.

| 관측 사건 | 현재 연결 |
|---|---|
| 바스·테르·세라의 기술 선딜 진입 또는 기본공격 시작 | 근접 계열 소리 |
| 리오·오린·루메의 기술 선딜 진입 또는 기본공격 시작 | 마법 계열 소리 |
| 네마·무아의 기술 선딜 진입 또는 기본공격 시작 | 자연 계열 소리 |
| 조작 영웅의 피격 | 피격 소리 |
| 조작 영웅의 레벨 상승 | 성장 소리 |
| 별샘 영약·숲빛 치유약 회복 시작 | 아이템 데이터에 지정된 사용 소리 |

한 상태 전환의 소리는 한 번 발생한다. 같은 관측 프레임에서는 레벨 상승, 피격, 아이템, 기술, 기본공격 순으로 우선한다. 일시 정지 중에는 재생을 멈추고 현재 상태를 추적한다.

지연 포격의 단계별 타격음, 영웅별 추가 음색, 사망·부활 신호는 후속 음향 실험 항목이다. 실험할 때는 중첩 소리 수, 경고 인지, 실제 적중 시점과의 일치, 숨은 적 정보 공개 여부를 함께 관찰한다.

## 제작과 재현

기존 3명과 신규 5명의 모델 생성기는 저장소에 포함한다. GLB는 몸통, 머리, 팔다리, 무기, 천과 팀 표식의 관절 계약을 따른다. 고유 장비를 변경할 때는 시전 포즈와 초상 렌더도 함께 확인한다.

기술 VFX는 권한 형상, 벽, 높이, 현재 시야 안에서 메시를 만든다. 같은 효과를 표시하는 최적화 경로와 정확한 경계 경로가 같은 가시성을 유지해야 한다. 3 대 3의 여러 기술이 겹친 장면에서 프레임 시간과 가독성을 함께 관찰한다.

## 검증 기준

- 8명 모델과 초상이 빈 화면 또는 다른 영웅의 장비로 표시되지 않는다.
- 기본·QWER·사망·부활 모션에서 손과 장비가 분리되지 않는다.
- 32개 아이콘의 제목과 실제 기술 이름이 일치한다.
- 기술 경고·적중·지속 상태가 실제 판정과 같은 위치에 표시된다.
- 무아 두 구역의 활성 상태와 세라 표식 수를 전투 시점에서 읽을 수 있다.
- 안개·벽·고지 경계에서 장식이 숨은 정보를 공개하지 않는다.
- 새 5명의 F7 실제 모델과 기술 화면을 배포 PCK에서 촬영한다.
