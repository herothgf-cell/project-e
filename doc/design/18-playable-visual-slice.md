## 1. 카메라

`playable_battlefield.gd`가 기존 입력/경기 컨트롤러를 상속한다. 경기 중 원근 투영, FOV 42도, 내려다보는 각도 55도를 첫 제안값으로 사용한다. 참고 영상의 실제 연속 프레임은 확보하지 못했으므로 원작의 정확한 카메라를 측정·복제했다는 주장은 하지 않는다.

| 입력/모드 | 동작 |
|---|---|
| 기본 전투 뷰 | 세로 구도 폭 30m 기준, 사선 원근 시점 |
| F6 | 전투 30 → 전술 50 → 가까이 18 순으로 전환 |
| 휠 | 16~58 범위 확대·축소 |
| Y | 내 영웅 추적 ON/OFF |
| Space | 기존 영웅 재집중 동작 유지 |
| 가운데 드래그·미니맵 | 기존 자유 시점 이동 유지 |
| 가장자리 이동 | 활성·포커스된 게임 화면에서만 동작; 메뉴/성장/상점/조준/HUD 위에서는 차단 |

고지 클릭은 고정 Y=0 평면 대신 권한 높이 필드와 카메라 레이의 첫 교차점을 사용한다. 평지·라인 경사·지원 경사·고지의 화면→좌표 복원, 메뉴 입력 차단과 재시작을 실제 장면에서 검사했다.

## 2. 실제 게임 메시와 전장 표현

세 영웅 모두 실제 `MeshInstance3D` 부품과 시각 관절을 사용한다. 컨셉 이미지를 화면에 붙인 것이 아니다.

| 영웅 | 이번 실루엣 |
|---|---|
| 바스 | 넓은 몸체, 비대칭 큰 장갑, 손가락·금속 고리, 등 압력 장치 |
| 리오 | 좁은 몸체, 양팔 원반, 가벼운 천 장식 |
| 네마 | 등 장비와 두 개의 긴 핀, 천 장식 |

세라믹·구리·짙은 작업복과 팀 청록/주황을 유지했다. 걷기, 기본 공격, 기술 준비/후딜, 돌진, 기절 자세와 천 흔들림이 실제 전투 상태를 읽는다. 판정 반경 0.45m, 스킬 시간과 피해는 변하지 않는다.

전장은 기존 바닥 위 석재 이음·타일 가장자리, 벽의 석재 층, 고지 하부 석조 지지대, 타워 지지물, 셀 받침과 정원 소품을 추가했다. 기존 보행 영역과 타워·벽 좌표는 그대로다. 새 지형 장식은 기존 시야 음영 재질을 사용하며 가짜 통행 지점을 만들지 않는다.

남은 아트: 캐릭터별 얼굴/비율 차별화, 스컬프·텍스처·스키닝 자산, 피격/사망 동작, 기술별 고유 애니메이션, 전장 전체 미술 품질, 물 표현과 조명·명암 조정. 이번 모델은 이 방향을 실제 카메라에서 판단하기 위한 1차다.

## 3. 스킬과 전투 표현

기존 권한 형태의 사거리·부채·선·장판 경고는 유지했다. 별도 `combat_accents.gd`는 관측 가능한 시전 손끝, 보호막 고리, 기절/속박, 원반과 기본 공격 투사체, 실제 발동 영역의 작은 발광선을 추가한다.

- 기본 공격 추적 투사체는 현재 시야 밖 좌표를 추가 효과로 드러내지 않는다.
- 고정 경로인 자기 리오 원반은 기존 자기 기술 관측 규칙을 유지한다.
- 적중 장식은 각 지점의 현재 시야·벽 LOS·실제 효과 형태를 함께 검사한다.
- 추가 효과는 피해·사거리·기절·자원 판정을 만들지 않는다.

이것은 최소 전투 표현이며 완성된 타격감·대량 파티클·음향까지 끝낸 상태는 아니다. 실제 바스 Q/W/E/R 명령으로 준비/발동 장면을 캡처했다.

## 4. 전술 봇 1차

`TacticalAI`는 플레이 가능한 장면에 연결된다. 원래 `BattleState` 기본 AI는 비교용 회귀에서 유지한다. 새 봇은 별도 전체 경기 검사도 수행한다.

정책:

1. 체력이 낮으면 기존 회복·소모품·퇴각을 우선한다.
2. 자기 핵이 노출되고 가까운 관측 적이 위협하면 방어한다.
3. 가까운 아군과 교전하는 현재 팀 시야의 적에게 제한된 지원을 한다.
4. 건강하고 당장 라인 압력이 낮으면 보이는 셀의 XP/경로 비용으로 목표를 고른다.
5. 같은 셀에 두 봇이 중복 예약하지 않는다.
6. 목표 소멸·시야 상실·위험·8초 제한에 도달하면 저장한 자기 라인으로 돌아간다.
7. 복귀 후 6초 재선택 대기로 왕복 진동을 줄인다.
8. 사망/부활은 이전 생명의 목표와 복귀 지점을 초기화한다.

사람이 조작하는 영웅은 제어하지 않는다. 셀/적 선택 전에 팀 시야를 검사하며 공개 구조물의 공격 범위를 통행 비용에 반영한다. 빈 라인 전역 재배치, 팀 단위 공성 지휘, 네마 핀 우선 대응, 난이도는 아직 남아 있다.

새 봇 경기: **1,333.0초(22분 13초), 동쪽 승리**, 피해 738,287.8, 셀 목표 선택 87회, 지원 12회, 핵 방어 45회, 셀 개인 XP 지급 이벤트 42건. 87회가 셀 87개 처치를 뜻하지 않으며, 42건도 공유 수령자 기준이라 셀 처치 수와 다르다. 기존 431.8초는 옛 AI 비교 결과다. 이 단일 봇 경기로 스피디함·사람 경기 시간·밸런스를 확정하지 않는다.

V-Sync 미지원(Mesa)과 GitHub action Node 버전 경고는 있었으나 게임 엔진/스크립트 오류는 없었다. 코드 리뷰는 별도 도구가 없어 작성자가 독립된 확인 단계로 직접 수행했으며, 제3자 리뷰로 표시하지 않는다.

## 7. 다음 단계와 검토 질문

먼저 이 실행판의 카메라 거리·세 영웅의 비율/장비 실루엣·밝은 수로 공방 방향을 검토한다. 확정 전에는 전체 맵 고급 자산과 모든 영웅 애니메이션을 대량 제작하지 않는다.

후속 순서: 장비/비율 아트 의견 반영 → 바스 한 명의 피격·사망·고유 기술 동작/효과·소리 → 전장 한 구역의 조명·재질·시야 경계 개선 → 나머지 두 영웅 확장 → 실제 Windows 사람 경기와 템포 조정. 입력 접수/예약/실패(R31), 전역 봇 전략, 온라인 진단은 계속 백로그에 남아 있다.

미검증: 사용자 PC의 GPU 성능/화면 배율/Alt-Tab/마우스 조작, 사람 재미·밸런스, 원작 카메라와의 장면 단위 일치, 온라인 동기화, 완성 아트 품질. 자동 실행·캡처와 혼동하지 않는다.
