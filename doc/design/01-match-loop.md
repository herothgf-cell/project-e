# 한 판의 흐름과 승리

- 설계 ID: MATCH-01 / 2026-10-26
- 범위: 로컬 영웅 선택부터 공명핵 파괴와 재시작까지.
- 관련: [전장](02-map-m01.md), [성장](05-growth-and-economy.md), [입력](06-ui-and-controls.md), [차이 기록](10-differences.md).

## 1. 플레이어가 반복하는 판단

라인 병력과 함께 전진하면서 기본 공격과 Q/W/E로 상대를 견제한다. 경험치로 얻은 포인트를 생존·위력·기동·에너지 회복 또는 R에 투자한다. 옆 라인을 도울 때는 비운 라인의 병력 손실을 감수한다. 적을 밀어냈다면 병력을 구조물까지 보존해 공성 보호를 해제한다. 외곽탑과 내곽탑을 같은 라인에서 파괴하면 핵으로 이어지는 승리 경로가 열린다.

| 단계 | 플레이어 행동 | 게임 상태 |
|---|---|---|
| 선택 | 바스·리오·네마 중 한 명, 일반 경기 또는 기술 체험 선택 | 아군의 나머지 두 영웅과 상대 세 영웅을 봇으로 구성 |
| 시작 | 라인 선택, 시작 포인트 투자 | 일반 경기 레벨 1·포인트 2·R 잠금 |
| 첫 전진 | 이동·표적 공격·일반기 | 경기 시계 20초 첫 웨이브, 30초 첫 셀 |
| 교전과 성장 | 병력 보상, 적 영웅 견제, 인접 지원 | 레벨 3 이상에서 1포인트를 써야 R 해금 |
| 공성 | 병력을 지키며 외곽→내곽 공격 | 같은 라인 외곽 파괴 시 내곽 잠금 해제 |
| 핵 노출 | 개통한 라인 또는 다른 접근 경로로 핵 공격 | 어느 한 라인의 두 탑이 파괴되면 핵 잠금 영구 해제 |
| 종료 | 승리·패배·무승부 확인, 다시 시작 | 판정 확정 후 추가 피해·보상·명령 없음 |

## 2. 경기 구성

| 항목 | 규칙 |
|---|---|
| 팀 | 서쪽 0, 동쪽 1; 각 3영웅 |
| 인간 조작 | 한 프로세스에서 영웅 한 명 |
| 중복 | 팀 안에서 중복 없음, 양 팀 같은 영웅 허용 |
| 맵 | M01 수로 공방 1개, N/C/S 3라인 |
| 정상 시작 | 레벨 1, XP 0, 성장 2포인트, Q/W/E 사용 가능 |
| 기술 체험 | 여섯 영웅 모두 레벨 3·R 해금·잔여 3포인트; 선택 화면과 HUD에서 연습 조건 표시 |
| 목표 경기 길이 | 12–18분은 향후 사람 테스트의 관측 가설; 시간 초과 강제 종료 없음 |
| 경기 간 성장 | 없음; 다시 시작하면 이전 경기의 HP·레벨·장치·쿨타임·승패를 초기화 |

이 실행판은 선택 후 바로 경기를 시작하는 흐름을 우선한다. 초기 온라인 제안의 영웅 선택 60초·준비 15초, 초대 방과 준비 동기화는 후속 범위다.

## 3. 공성 상태 전이

외곽탑은 처음부터 피해를 받을 수 있다. 내곽탑의 무적 잠금은 같은 라인의 외곽이 파괴되어야 풀린다. 핵은 어느 한 라인에서 외곽과 내곽을 모두 파괴하면 영구 노출된다. 잠금 해제는 타워 HP를 회복시키지 않는다.

구조물 중심 12m 안에 공격 팀의 살아 있는 **라인 병력**이 없으면 받는 피해는 0.3배다. 이 조건은 잠금과 독립적이다. 잠금이 풀린 핵에도 병력 부재 보호가 적용된다. 영웅·네마 핀·리오 회수점은 병력을 대신하지 못한다. 영웅의 구조물 피해는 먼저 0.5배이므로 병력 없는 공성은 원피해의 0.15배다.

## 4. 사망과 복귀

부활 대기는 사망 당시 레벨 `L`에 대해 `8 + 2L`초다. 레벨 1은 10초, 레벨 6은 20초, 레벨 12는 32초다. 기지에서 HP·에너지를 최대치로 채워 돌아온다. 레벨·XP·성장 투자는 유지하고 쿨타임도 사망 중 계속 흐른다.

사망한 영웅의 제어 상태·자기 보호막·진행 중 행동·소유 설치물을 정리한다. 네마의 핀과 리오의 회수점은 사라진다. 리오 Q는 사망 시 제거되는 명시적 예외이며, 이미 발사된 기본 공격은 소유자 사망만으로 제거하지 않는다. 다른 아군에게 이미 준 보호막은 원래 만료 시각까지 남는다.

부활 보호는 3초이며 적대 행동을 승인하면 효과를 처리하기 전에 종료한다. 기지는 상시 무적 구역이 아니다. 회복 조건은 [성장·경제](05-growth-and-economy.md)를 따른다.

## 5. 종료와 재시작

한 시뮬레이션 틱의 피해를 정산한 뒤 핵 HP를 검사한다. 한 팀 핵만 파괴되면 반대 팀 승리, 같은 틱 양 핵이 모두 파괴되면 무승부다. 결과는 한 번만 정한다. 승패 확정 뒤 계속 누적되는 투사체 피해나 XP는 없다.

재시작은 시계, 유닛 ID 집합, 투사체, 기술 경고, 장치, 포인트, 봇 목표, 종료 결과를 새 경기 상태로 만든다. 온라인 이탈·재접속·호스트 소실은 이번 로컬 종료 규칙에 포함되지 않는다.
