# 판타지 V4: 3등신 전투 아트·애니메이션·사운드 (2026-11-03)

## 배경 및 목표
2026-11-03 `main`의 판타지 V3는 영웅 3명(바스·리오·네마) 3등신 블록 메시, 판타지 맵, HUD 및 SVG 아이콘을 사용한다. 다음 단계는 **새 영웅/스킬 규칙을 만드는 것이 아니라 실제 전투 표현의 완성도**를 높이는 것이다.

## 채택 접근
- **선택**: 기존 Godot 3D `HeroRig` / `SkillVFX` / `playable_battlefield`에 소규모 표현 계층을 덧붙인다. 모델링 원본·스킬 판정은 그대로 둔다.
- 비교 1: 전면 2D 스프라이트 교체는 전방향 리깅·시야 작업량과 기존 3D 지형 충돌 위험이 커서 보류.
- 비교 2: 전체 영웅 FBX 리깅 재제작은 1인 개발 및 현재 리소스 규모에서 초기 비용이 커서 후순위.

## 이번 패치 (V4)
1. **영웅 실루엣** — 바스 전투 장갑에 룬 돌기, 리오 마법 원반 빛 결, 네마 나뭇잎·정령 문양. 3명 각각 팔에 따라 움직이는 `WeaponDetail`, 머리 `HairDetail`, 가슴 `RuneEmblem`을 가진다.
2. **보조 모션** — 기존 권한 기반 10개 애니메이션 클립을 유지하면서 걷기 수직 바운스, 대기 호흡, 스킬 준비 기울기, 기본 공격 반동, 피격 수축, 죽음/부활의 시각적 보간을 추가한다. 모델 루트 위치 변화는 최대 약 0.12m, 게임 충돌/좌표 변경 0.
3. **시각 이펙트** — 같은 실제 효력 영역 안에서 3영웅×QWER의 룬/화염/수정/덩굴 보조 파형을 구별한다. 현재 시야와 LOS로 승인된 표본만 렌더링한다. 스킬 판정·선딜·쿨다운 변경 0.
4. **효과음** — 외부 라이선스가 없는 자체 생성 WAV 5종(근접, 비전, 자연, 피격, 레벨업)을 게임에 넣고, **로컬 조작 영웅**에 한해서 새 기본 공격/스킬 선딜/피격/레벨업 이벤트에서 한 번씩 소리 재생. 같은 이벤트 반복 방지, 선택 화면·리플레이/리뷰 무음, 원거리 미관측 적의 소리 누출 0.
5. F7 검토실의 헤더와 문서를 V4로 연결해 한 스크립트에서 캐릭터/모션/스킬을 재생한다.

## 보존 조건
- Godot 4.7.2 Standard 3D, 3라인·고저·시야·봇·타워·미니언·경제·성장·카메라, QWER 12개 원래 판정/시전/타이밍 그대로.
- `scripts/battle/*`, `battle_map.gd`와 기술 CONFIG 수정 금지.
- 영웅 피격 반경 0.45m, 시야 마스크·팀 가시성, 카메라 월드좌표 대응 유지.
- 모든 신규 자산은 원본/상업 이용 가능한 직접 합성, 개별 효과음 0.4초 미만, 파일 합계 1MB 이하.
- 시티 오브 템페스트의 **빠른 3라인 전투 손맛 참고**만 유지하며 원작 자산/캐릭터/스크립트 복제 없음.

## 확인 기준
- 모든 hero_key에서 `WeaponDetail`, `HairDetail`, `RuneEmblem`, 기존 10개 애니메이션 존재·실제 움직임.
- 모델 `pose()`는 입력 authority Dictionary를 바꾸지 않음.
- 실제 12스킬 시뮬레이션에서 차별화된 표본이 그려지고 시야 밖 표본 0.
- 오디오 5종 리소스 임포트, 로컬 공격/스킬/피격/레벨에만 재생; 여러 번 같은 상태를 관측해도 중복 카운트 0.
- 기존 전체 회귀/실제 렌더 캡처/Windows preview 빌드 통과.
