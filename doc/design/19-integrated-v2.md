## 2. 실제 경기와 연출의 연결

`hero_rig.gd`는 실제 영웅 phase/cast/phase_left/last_damage/alive 상태를 읽어 AnimationPlayer를 수동 샘플링한다. 애니메이션이 피해·자원·사거리·이동을 결정하지 않는다. 서로 다른 QWER 자세가 실제 관절 회전에 반영되는지 검사한다.

피격은 실제 HP 감소, 사망은 실제 alive=false, 부활은 권한 부활 타이머를 사용한다. 관측한 사망만 0.85초 동안 표현하고 적 시야를 잃으면 즉시 폐기한다. 다시 시야를 얻어도 사망 연출이 재생되지 않는다.

`skill_vfx.gd`는 실제 활성 효과의 형태/타이밍/벽 LOS/현재 팀 시야 안에서 장식을 그린다. 원래 조준/판정 경고는 유지한다. 바스/리오 돌진도 실제 dash 상태를 읽는다. 네마 W/R 시연은 실제 Q 두 번으로 핀 선행 조건을 만든다.

지형은 기존 평면 좌표+높이 필드의 2.5D 구조다. 모든 맵을 자유로운 3D 절벽으로 다시 제작한 것이 아니라 기존 고지/경사의 동작과 지지면을 연결한 범위다. 바스 언덕 시연은 실제 길찾기로 평지→경사→2.4m 상단을 이동한다.

## 3. F7 연출실과 경기 격리

연출실은 별도 battlefield와 BattleState를 만든다. 원래 경기의 시간/유닛/명령/자원을 보존하고, 종료 시 원래 화면·카메라·입력·일시정지를 복원한다. 전체 맵 공개와 재시연용 자원 초기화는 이 별도 상태에만 적용한다.

화면 검수에서 XP 셀이 연출실에 없는 문제를 재현했다. `_cells_spawned=true`만 지정해 실제 생성이 생략된 것이 원인이었다. 새 검사는 수정 전 5개 중 3개 실패, 수정 후 5개 전부 통과했다. 이제 별도 시계를 실제 30초 생성 경계까지 이동해 **권한 코드가 직접 생성한 20/30/40 XP 셀 각 2개**를 사용한다. 전체 맵에서는 6개 모두 표시하고 일반 연출 구도로 돌아오면 현재 시야 규칙을 복구한다. 원래 경기의 최초30초/재생성45초 규칙에는 변화가 없다.
