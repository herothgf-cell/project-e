# 통합 V2 — 연출실·캐릭터·스킬·지형

기준일: 2026-11-03 (Asia/Seoul). 상태: 중단된 작업 복구 후 검증 진행 중.

## 승인된 범위
사용자는 캐릭터 3명과 Q/W/E/R 12개, 피격·사망·부활 동작, 맵 고저차를 먼저 한 실행판에 연결하고 이후 하나씩 수정하는 방식을 선택했다. 시안 승인을 기다리며 개발을 중단하지 않는다. LOL/시티 오브 템페스트는 가독성·조작 시점의 참고 방향이며 원작 모델·스킬·정확한 카메라 수치를 복제했다고 주장하지 않는다.

## 구현 계약
- 기존 Godot 4.7.2와 2D 권한/2.5D 표현을 유지한다.
- 영웅별 실제 AnimationPlayer에 대기·이동·평타·QWER·피격·사망·부활을 연결한다.
- 스킬 장식은 권한 효과의 실제 범위·시간·벽·팀 시야를 따른다. 별도 피해를 만들지 않는다.
- 보행·고지·경사는 권한 ground_height와 같은 표면을 사용한다. 장식으로 경로를 바꾸지 않는다.
- F7 연출실은 독립 BattleState를 사용한다. 원래 경기 시간·자원·명령을 건드리지 않고 종료 시 카메라·입력·일시정지를 복원한다.
- 전체 맵 공개는 연출실에 한정한다.
- 기존 XP/타워/영웅/스킬 밸런스 수치는 바꾸지 않는다.

## 완료 증거
전체 Godot 검사, 세 영웅 12개 실제 시전, 고지 이동, 시야 상실, 사망/부활, 연출실 종료/재진입을 검증한다. 실제 렌더 캡처와 최신 Windows ZIP을 제공한다. 자동 검사와 실제 Windows 사람 플레이를 구분한다. 결과 수치는 최종 검증 뒤 기록한다.

## 품질 경계
모듈형 게임 메시와 관절 애니메이션의 1차 통합 제작본이다. 출시용 스컬프·스킨 웨이트·완성 텍스처·음향·전체 맵 미술을 완료 처리하지 않는다.
