# M01 수로 공방 — 3라인 전장

- 기준: [초기 M01 좌표 정본](../../docs/content/02-arena-and-objectives.md).
- 목표: 라인 전진, 3–5초의 인접 지원, 병력 동반 공성을 하나의 공간에서 확인한다.
- 실제 이동·사거리 판정과 컨셉 이미지의 장식은 분리한다.
- 2026-10-27 현재 셀 XP 20/30/40(R24), 공유 시야 표시(R25), 포탑 사거리 8.5m(R26)를 반영했다. 원래 좌표는 유지한다. 결정 배경은 [개발 기록](11-remaining-development.md), 실제 실행 증거는 [검증 기록](09-verification.md)을 따른다.

## 1. 좌표와 이동 가능 영역

| 항목 | 규격 |
|---|---|
| 경계 | X −60~60, 북쪽 좌표 −40~40; 전체 120×80m. 이 사각형 전체가 보행 지면은 아님 |
| 방향 | X 증가가 동쪽, 두 번째 좌표 증가가 북쪽 |
| 시뮬레이션→화면 | `Vector2(x, north)`를 Godot `(x, height, -north)`로 표시 |
| 핵 / 부활 | 서 (−50,0)/(−56,0), 동 (50,0)/(56,0) |
| 기지 바닥 | 서 [−59,−44]×[−8,8], 동 [44,59]×[−8,8] |
| 회복 구역 | 서 [−59,−53]×[−6,6], 동 [53,59]×[−6,6] |
| 영웅 반경 | 0.45m; 모델 크기가 판정 반경을 바꾸지 않음 |
| 구조물 반경 | 탑 1m, 핵 2m |

이동 가능한 바닥은 라인·연결로·기지·구조물 발판·셀 발판과 진입로의 합집합이다. 라인은 중심선 양쪽 3m(폭 6m), 연결로는 양쪽 2m(폭 4m)다. 꺾이는 라인은 반경 3m의 둥근 접합으로 잇는다. 세 라인의 중앙 X −6~6은 폭 9m 교전 공간을 갖는다.

탑·핵 주변 반경 3m 발판에서 구조물 충돌 원을 뺀다. 셀에는 반경 2.2m 발판과 같은 라인까지 폭 3m 진입로를 둔다. 나머지 수로·정원은 걸을 수 없으며 높이 차이·물살·도하 피해는 없다. 이동기 또한 유효 지면의 마지막 위치에서 정지한다.

## 2. 라인과 지원 경로

| 라인 | 서쪽 핵→동쪽 핵의 중심 경로 | 기준 길이 |
|---|---|---:|
| N | (−50,0)→(−26,18)→(26,18)→(50,0) | 112m |
| C | (−50,0)→(50,0) | 100m |
| S | (−50,0)→(−26,−18)→(26,−18)→(50,0) | 112m |

| 연결로 | 중앙 출입점 | 측면 출입점 | 중심선 길이 |
|---|---|---|---:|
| K01 서북 | (−22,0) | (−10,18) | √468 ≈ 21.63m |
| K02 동북 | (22,0) | (10,18) | √468 ≈ 21.63m |
| K03 서남 | (−22,0) | (−10,−18) | √468 ≈ 21.63m |
| K04 동남 | (22,0) | (10,−18) | √468 ≈ 21.63m |

기본 이동으로 연결로 중심 출입점 사이를 이동하는 계산값은 바스 3.73초, 리오 3.49초, 네마 3.61초다. 북↔남은 중앙을 거쳐 43.27m이며 각각 7.46/6.98/7.21초다. 전투 위치에서 입구까지의 접근·충돌·감속·이동기는 이 계산에 포함하지 않는다. 실제 클릭 경로와 도착 시간은 별도로 측정한다.

병력 생성 앵커는 핵에서 자기 라인을 따라 5m 전방이다. 최초 중앙선까지 명목 거리는 C 45m, N/S 51m다. 속도 3.2m/s·첫 생성 20초일 때 교전 없는 선두 도착은 C 34.06초, N/S 35.94초다. 이는 충돌·공격·편대 간격을 제외한 원본 계산이며 실제 도착 기록은 아니다. 병력은 연결로로 라인을 바꾸지 않는다.

## 3. 구조물 배치

| 라인 | 서 내곽 | 서 외곽 | 동 외곽 | 동 내곽 |
|---|---|---|---|---|
| N | (−26,21.5) | (−10,21.5) | (10,21.5) | (26,21.5) |
| C | (−30,−3.5) | (−10,−3.5) | (10,3.5) | (30,3.5) |
| S | (−26,−21.5) | (−10,−21.5) | (10,−21.5) | (26,−21.5) |

| 목표물 | 팀당 수량 | HP | 공격 |
|---|---:|---:|---|
| 외곽탑 | 3 | 2,000 | 8.5m / 원피해 180 / 1초 |
| 내곽탑 | 3 | 2,600 | 외곽과 동일; 같은 라인의 외곽 파괴 전 잠금 |
| 핵 | 1 | 4,000 | 공격 없음; 한 라인 외곽+내곽 파괴 후 해제 |

타워는 중심 라인의 옆 3.5m에 놓인다. 중심 경로를 막는 배치가 아니다. 구조물 HP는 자동 회복하지 않는다. 공격 사거리는 공격자 중심에서 표적 외곽까지, 병력 부재 보호 12m는 중심 간 거리로 잰다. [전투·공성 배율](03-combat.md)을 함께 적용한다.

## 4. 경험치 셀과 시야 차단체

| 라인 | 서 측 셀 / XP | 동 측 셀 / XP |
|---|---|---|
| N | (−18,24) / 40 | (18,24) / 20 |
| C | (−24,6) / 30 | (24,−6) / 30 |
| S | (−18,−24) / 20 | (18,−24) / 40 |

셀 6개는 첫 생성 30초, HP 180, 파괴 후 45초에 같은 XP 종류로 재생성된다. 북서↔남동은 40, 중앙 쌍은 30, 북동↔남서는 20 XP로 각 종류가 2개다. 한 번씩 모두 파괴할 때 총 XP는 180이며 서·동 측 배치 합은 각각 90이다. 셀당 크레딧 총 10과 처치 팀의 살아 있는 영웅에게 14m 안에서 균등 공유하는 규칙은 유지한다. 위치가 자기 측에 있어도 소유 팀은 없고 상대가 파괴해 보상을 얻을 수 있다.

| 차단체 | X 범위 | 북쪽 좌표 범위 |
|---|---|---|
| B01 | −6~6 | 6~12 |
| B02 | −6~6 | −12~−6 |
| B03 | −28~−22 | 9~12 |
| B04 | 22~28 | −12~−9 |
| B05 | −28~−22 | −12~−9 |
| B06 | 22~28 | 9~12 |

여섯 사각형은 이동·시야를 모두 차단한다. 다른 비이동 정원은 시야를 가리지 않는다. 시야는 영웅 12m, 살아 있는 구조물 12m, 라인 병력 8m이며 팀 공유다. 셀·네마 핀·리오 회수점은 시야를 만들지 않는다.

현재 전장 지면과 미니맵은 같은 1m 래스터로 팀 공유 관측 영역을 밝게, 비관측 영역을 어둡고 낮은 채도로 표시한다. 여러 제공원의 합집합과 벽 차단은 시뮬레이션의 같은 시야 판정으로 계산한다. 살아 있는 아군 시야원에는 체력바 왼쪽에 어두운 바탕 눈 모양 표식을 붙이며 마우스를 올리면 벽에 잘린 범위와 설명을 보여 준다. 포탑 공격 8.5m는 황색 점선으로 시야 12m와 구분한다.

이 음영은 지형을 읽기 위한 표시 근사다. 1m 셀 중심 샘플 때문에 임의의 지점과 경계가 약 0.71m 차이 날 수 있고, 이동에 따른 재계산은 250ms 간격(4Hz)으로 제한하며 마지막 샘플 대비 0.1m 이하 이동은 생략한다. 시야원 소멸·사망·팀 변경 등 제공원 집합 변화는 즉시 갱신한다. 표적 선택·유닛·HP·셀 XP 표시에는 래스터가 아닌 현재의 정확한 시야 판정을 적용한다. 성능과 원형 샘플링 한계는 [차이 기록](10-differences.md#3-현재-구현의-한계)을 따른다.
