# M01 수로 공방 — 3라인 전장

- 갱신: **2026-10-29, Asia/Seoul**.
- 기준: [초기 M01 좌표 정본](../../docs/content/02-arena-and-objectives.md).
- 목표: 세 라인 관리, 3–5초 인접 지원, XP 경합과 병력 동반 공성을 하나의 공간에서 확인한다.
- 현재 구현 증거: [R28 고저차](15-high-ground-verification.md) · [R30 지원 동선](16-r30-high-ground-flow-verification.md).

## 1. 좌표·보행·높이

| 항목 | 규격 |
|---|---|
| 경계 | X −60~60, 북쪽 좌표 −40~40; 전체120×80m. 사각형 전체가 보행 지면은 아님 |
| 방향 | X 증가가 동쪽, 두 번째 좌표 증가가 북쪽 |
| 화면 변환 | `Vector2(x,north)` → Godot `(x,height,-north)` |
| 핵 / 부활 | 서 `(−50,0)/(−56,0)`, 동 `(50,0)/(56,0)` |
| 기지 바닥 | 서 `[−59,−44]×[−8,8]`, 동 `[44,59]×[−8,8]` |
| 회복 구역 | 서 `[−59,−53]×[−6,6]`, 동 `[53,59]×[−6,6]` |
| 영웅 반경 |0.45m |
| 구조물 반경 | 탑1m, 핵2m |
| 일반 지면 |0m |
|40XP 고지 | 북서 `(−18,24)`, 남동 `(18,−24)`, 상단2.4m |

이동 가능 바닥은 라인·기존 연결로·기지·구조물 발판·셀 발판·셀 진입로의 합집합이다. 라인은 폭6m, 기존 지원 연결로는 폭4m, 셀 진입 경사는 폭3m다. 탑·핵·벽 충돌은 기존 규칙을 유지한다.

높이는 별도 3D 물리가 아니라 기존 2D 권한 위에 추가한 **2.5D 높이 필드**다. `battle_map.gd`의 보행 영역과 AStarGrid2D가 이동 권한을 결정하고, `ground_height()`를 유닛 발·마우스 지면 클릭·HP바·스킬 경고·시야 표현이 공유한다.

## 3. R28·R30 고지 동선

두 40XP 지점은 각각 라인 복귀 경사와 지원 회전 경사, 두 진입로를 가진다.

| 고지 | 라인 복귀 경사 | 지원 회전 경사 | 다음 연결점 |
|---|---|---|---|
| 북서40XP `(−18,24)` | `(−18,24)→(−18,18)` | `(−18,24)→(−12,18)` | K01 측면 출입점 `(−10,18)` |
| 남동40XP `(18,−24)` | `(18,−24)→(18,−18)` | `(18,−24)→(12,−18)` | K04 측면 출입점 `(10,−18)` |

네 경사는 폭3m이고 180도 회전 대칭이다. 고지 중심에서2.0m 떨어진 지점부터 높이가2.4→0m로 선형 감소한다. 시각 발판 반경2.2m와 높이 보간 시작점2.0m는 기존 R28 중간 높이 계약을 보존하기 위해 구분한다.

의도한 선택:

1. XP 획득 뒤 원래 라인으로 즉시 복귀한다.
2. 지원 경사로 내려가 인접 연결로를 통해 중앙 교전에 합류한다.
3. 상대 지원·포탑 위험을 보고 고지를 포기하거나 다시 올라간다.

R30은 **통행 위치만 변경**했다. 이동속도·스킬·XP 보상·타워 수치·벽 좌표는 바꾸지 않았다. 따라서 사람 테스트에서는 두 경사의 사용률, 지원 결정→교전 합류 시간, 비운 라인의 XP·포탑 손실을 함께 기록한다.

공통 규칙:

- HP180, 물리 반경0.55m.
- 첫 생성30초, 파괴 후45초 재생성.
- 처치 팀의 살아 있는 영웅 중14m 안 대상에게 XP와 크레딧10을 균등 공유.

이번 R30은 값과 생성 주기를 유지한다. 다음 R29는 등장·실제 분배·레벨업 피드백을 개선하고, R10 후속은 봇이 셀을 목표로 선택·포기·복귀하도록 한다.

## 6. 시야와 차단체

기존 사각 벽6개는 이동과 물리 LOS를 차단한다. 영웅·탑·핵 시야12m, 병력8m이며 팀 공유다.

고저차 규칙:

- 낮은 영웅·병력은 고지 상단을 팀 시야로 밝히지 못한다.
- 고지 영웅·병력은 아래쪽을 볼 수 있다.
- 탑·핵은 기존12m 안에서 고지를 감시해 일방 공성 사각을 막는다.
- 물리 투사체·지면 효과 LOS와 고저차 시야는 별도 판정이다.

전장·미니맵은 같은1m 현재 시야 마스크를 사용한다. 고지와 경사는 고정 지형이므로 미니맵에 공개되지만, 셀 생존·HP와 적 유닛은 기존 시야 규칙에 따라 숨긴다. 지원 경사는 기존 라인 복귀 경사와 다른 색으로 표시된다.
