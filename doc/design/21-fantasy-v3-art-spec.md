# Project E — 판타지 세미 카툰 아트 V3 명세 (2026-11-03)

## 목적
현재 Godot 4.7.2 Standard **3D 전장과 전투 권한을 그대로 유지**하면서 사용자가 확정한 미술 방향(A 중심 귀여운 판타지, D의 세미 카툰 캐릭터 비율, A+B의 밝은 판타지 배경)을 적용한다.

## 비주얼 필러
- 플레이 영웅은 머리:전신 약 1:3의 약 3등신, 과장된 무기와 장식, 읽히는 실루엣
- 상단 시점에서 작은 화면에도 구분되는 머리카락 색·외투·무기 실루엣
- 숲·석조·수정 유적의 밝은 하이 판타지. 지면은 낮은 채도, 스킬과 캐릭터는 높은 대비
- HUD는 심야 남색 판넬, 금색 테두리, 팀 청록/적 주황 경고, 아이콘 중심
- 카툰 VFX는 판정 및 현재 가시성 마스크와 동기화, 별도 피해 판정 없음

## 범위와 보존 조건
- **기존 실제 영웅**: 바스(전열/압력 장갑), 리오(원반/거리 제어), 네마(연결 핀/지원). 새 영웅(브람·리아 등)은 이번 패치에 추가하지 않는다.
- 모델: `hero_rig.gd`의 관절/클립과 `pose` 계약 보존. 3등신 실루엣 + 판타지 장비와 색.
- 맵: `workshop_arena.gd`에서 **장식만** 변경. 기존 M01 지형·고저차·길·시야·충돌·레이캐스트 유지.
- UI: `battle_hud.gd`, `hero_portrait.gd`의 색·아이콘·레이아웃 적용. QWER 기능/도움말/성장/상점과 누르기 영역 유지.
- 에셋: 프로젝트 소유 벡터 아이콘·초상·시안, Godot 내장 메시를 이용한 3D 오브젝트. 외부 다운로드·유료 리소스 없음.
- 기존 전투 템포, 3라인, 카메라 모드, QWER 판정/에너지/쿨다운, 시티 오브 템페스트를 참고한 체감 구조 유지. 원작의 모델/맵/UI 직접 복제 금지.

## 이번 패치의 완료 기준
1. 실제 플레이 영웅 3명의 머리 크기와 비율이 코드에 반영되고 기존 10클립 애니메이션 및 QWER 자세가 유지
2. 판타지 지면 색·석조·수정·나무/숲 장식으로 3D 맵 변경, 길/충돌/시야 데이터 수정 없음
3. 영웅 선택 초상 3장과 QWER 12개 아이콘을 **게임에서 실제 사용**
4. 고정 시안(로스터, HUD, 맵), 원본 SVG, 라이선스·파일 용량, 버전/확장 지침 저장
5. 검증 가능한 Godot 테스트와 CI 또는 가능한 검증 결과 제시. AI 이미지 시안은 실제 게임 스크린샷이라고 주장하지 않음.

## 제외
- 2D 전환, 네 번째 영웅, 신규 네트워크, 새로운 스킬 수치/경제, 완성 아트/모션 캡처/음향, 원작 화면 복제.
- 대형 PNG/PSD 원본은 별도 관리. 1회 Git 커밋 권장 자산 총량은 10 MiB 이내.

## 적용/복구
아트 변경은 씬 스크립트 및 UI에 국한하며, 게임플레이 로직 파일을 수정하지 않는다. F7 연출실에서 영웅별 대기·걷기·QWER·피격·사망과 맵을 검토한다.
