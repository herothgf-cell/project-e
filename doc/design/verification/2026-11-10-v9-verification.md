## 범위와 기준

V9 `0.9.0`은 시티 오브 템페스트의 세로 전장 근거를 표시·조작에 적용하고, 봇이 돌파한 라인으로 합류하지 못하던 공성 지연을 수정한다. 8명 로스터, 오프라인 3 대 3, 기존 성장·기술·미니언·구조물 수치는 유지한다. 기준 소스는 `debcd53c6d991ef568761761c38dae2095bc67d6`, 엔진은 공식 `4.7.2.stable.official.ed1daf0bf`다.

원작 확인, 프로젝트 수치, 실험값은 구분한다. 2011년 게임 스크린샷과 지정 영상의 약 10초 간격 정지 표본 143장에서 상하 진영, 좌·중·우 세로 통로, 큰 차폐 지형과 연결부를 확인했다. 연속 고해상도 영상 재생이나 정확한 거리·구조물 개수·원작 경기 시간 측정으로 확대 해석하지 않는다. [원본 근거](../assets/cot-audit-20261110/README.md) · [V8 감사](../29-cot-map-minion-siege-review.md)

## 재현

고정 엔진을 지정해 저장소 루트에서 실행한다.

```sh
python tools/check_godot.py --godot /absolute/path/to/Godot_v4.7.2-stable_linux.x86_64
python -m unittest discover -s tools/tests -p 'test_package_windows.py'

/absolute/path/to/Godot_v4.7.2-stable_linux.x86_64 \
  --headless --path game/project-e --script ../../tools/measure_siege.gd -- \
  --hero=bas --limit=3000 --output=/absolute/output-directory \
  --source=YOUR_CHECKOUT_REVISION --label=bas
```

`--hero=orin`, `--hero=tere`는 나머지 두 편성을 선택한다. 사람 슬롯을 포함해 여섯 영웅 전부 현재 AI로 조작하며, 승패를 강제하지 않는다. `0` 종료 코드는 자연 승패, `1`은 관찰 상한, `2`는 잘못된 입력 또는 출력 실패다. 기본 전투는 30 Hz, 관찰 호출 간격은 0.5초, 상태 표본은 5초다. 피해 사건 시각은 전투 판정 시점이고 체류 시간은 표본 정밀도의 영향을 받는다.

`--source`는 실행자가 제공한 설명이며 Git 커밋을 자동 검증하는 값이 아니다. 각 결과의 실제 전투 스크립트별 SHA-256과 관찰기 SHA-256으로 코드 일치 여부를 확인한다. 실험 코드를 재현할 때는 각 실험 README가 지정한 V8 기준 소스를 사용한다.

## 해석의 한계

- 고정 편성 세 경기의 자동 결과다. 사람 경기 평균, 승률 또는 영웅 전체 밸런스 검증으로 해석하지 않는다.
- 빠른 기본 조합의 종료는 회복·역전 기회가 충분한지 후속 사람 플레이에서 확인할 항목이다. 목표 12~18분을 맞추기 위해 강제 종료나 타이머 보정을 추가하지 않았다.
- 전장의 표시 방향과 조작을 맞췄다. 원작의 거리와 지형을 정밀 복제한 것은 아니다.
- 실제 렌더 검사는 Linux OpenGL 환경이며 Windows의 수동 플레이·Alt-Tab·GPU별 성능 검증과 구분한다.
