# 2026-11-09 V8 검증

## 대상과 현재 상태

버전 0.8.0의 총 8명 로스터, 신규 20개 액티브·5개 패시브, 모델·초상·선택 화면·아이콘·HUD·F7과 상세 기획을 검사한다. 기준 소스는 V7 main에서 분기한 V8 작업 트리다. 이 기록은 검사 완료마다 실제 결과와 빌드 링크를 갱신한다.

## 완료한 로컬 검사

| 검사 | 결과 |
|---|---|
| Godot 4.7.2 가져오기와 시작 장면 | 통과 |
| 전체 행동 회귀 | 36개 스위트, 6,835개 항목, 실패 0 |
| V8 편성과 시작 상태 | 48개 항목, 실패 0 |
| 신규 영웅의 실제 기술 효과 | 252개 항목, 실패 0 |
| V8 선택·모델·표현·F7 | 408개 항목, 실패 0 |
| 독립 코드 검토 | 전투·상태 정리·시야·편성·초상·촬영 스크립트 검토 완료 |
| 촬영 스크립트 구문 | Godot `--check-only` 통과 |

위 세 V8 스위트는 전체 행동 회귀 수치에 포함된다. 독립 검토에서도 해당 세 스위트를 다시 실행했다.

## 배포 화면과 Windows 실행

실제 배포 PCK의 3개 해상도 선택 화면, 8명 포인터 선택, 신규 모델과 32개 액티브 촬영을 CI로 확인한다. Windows에서는 내보낸 EXE의 120프레임 기동을 수행한다. 현재 단계는 실행 준비이며 완료된 실행과 아티팩트 링크를 이 문서에 추가한다.

## 실제 관측이 필요한 항목
