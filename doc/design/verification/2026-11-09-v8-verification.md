# 2026-11-09 V8 검증

## 대상과 실행 환경

버전 0.8.0의 총 8명 로스터, 액티브 32개·패시브 8개, 모델·초상·선택 화면·아이콘·HUD·F7과 상세 기획을 검사했다. 기준은 V7 main에서 확장한 V8 소스다. Godot 4.7.2 공식 엔진을 사용했다.

로컬 행동 검사는 Linux headless 환경에서 수행했다. 배포 PCK의 화면·포인터 검사는 Linux OpenGL 호환 렌더러에서, 내보낸 EXE의 기동 검사는 GitHub Actions의 Windows 환경에서 수행했다. 게시 소스의 자동 검사와 실행 파일 링크는 V8 PR에서 확인할 수 있다. [V8 배포와 검사](https://github.com/herothgf-cell/project-e/pull/10)

## 검사 중 발견하고 보완한 항목

| 재현 | 보완 | 확인한 결과 |
|---|---|---|
| 세라 기본공격 선딜 중 위력 투자 시 표식 추가 피해도 증가 | 기본공격 시작 시 저장한 위력을 표식 소비 피해에 전달 | 위력 100에서 시작한 공격은 투자 후에도 총 175 피해, 관련 회귀 7개 추가 |
| 기지와 라인 경계에서 복귀 명령을 받은 바스가 정지 | 길찾기의 직선 통과 검사에 실제 이동의 0.08 m 표본 사용 | 양 기지의 우회 경로와 도착 확인, 경로를 1 cm 간격으로 추가 검사 |
| 핵 옆에서 출발 영웅과 복귀 영웅이 서로 막음 | 기존 대각선 우회에 측면 우회 추가, 지형에 막히면 목적지 경로 재탐색 | 양 진영 재현에서 지형·영웅 충돌을 지키며 두 영웅 모두 도착 |
| 신규 5명의 얼굴·의상이 초기 모델에서 단순하게 보임 | 기존 얼굴·의상 텍스처, 개별 머리 장식·외투·무기, 상반신 초상 적용 | 실제 PCK에서 매핑·실루엣·960×540 선택 화면 확인 |
| 테르 E 연출실 시전이 더미 쪽으로 이동 | 후퇴 방향으로 시전하고 지연 반격 시점에 촬영 | 더미와 거리 증가 뒤 실제 반격 피해 확인 |
| 테르 R 연출실 범위가 아래 패널과 겹침 | 해당 기술의 연출실 카메라 거리 확대 | 전체 부채꼴과 두 모델이 패널 위에 표시됨 |
| 초상 후광의 역순 smoothstep 경계 | 정순 경계와 반전 수식 적용 | 그래픽 드라이버가 정의된 보간식을 사용하도록 수정 |

기지 경계의 정지는 V7 소스에서도 같은 좌표로 재현됐다. 실제 이동 보완 뒤에는 이전에 정지하던 영웅들도 성장과 교전에 참여했다.

## 전원 봇 경기

사람 조작 슬롯까지 봇에 맡겨 6명이 공용 명령을 사용했다. 내부 전투 판정은 30 Hz이며, 기록 시점의 승리는 실제 핵 파괴로 발생했다.

| 서쪽 팀 | 동쪽 팀 | 종료 초 | 승리 | 기술 시전 | 파괴된 탑 | 영웅 사망 |
|---|---|---:|---|---:|---:|---:|
| 바스·리오·네마 | 바스·리오·네마 | 2,077.3 | 동쪽 | 3,651 | 10 | 13 |
| 오린·바스·네마 | 바스·세라·무아 | 2,527.8 | 서쪽 | 5,079 | 10 | 19 |
| 테르·바스·네마 | 바스·루메·오린 | 1,798.1 | 동쪽 | 3,041 | 9 | 8 |

모든 경기에서 6명 전원이 레벨 12에 도달하고 QWER 전체를 사용했다. 신규 영웅의 관측치는 다음과 같다.

| 영웅 | 해당 경기의 Q / W / E / R | 실제 가한 피해 |
|---|---|---:|
| 오린, 오린 선택 경기 | 291 / 120 / 214 / 98 | 208,995.1 |
| 테르 | 153 / 86 / 77 / 65 | 90,857.0 |
| 무아 | 357 / 310 / 328 / 90 | 198,776.1 |
| 세라 | 258 / 293 / 250 / 107 | 127,070.7 |
| 루메 | 196 / 76 / 165 / 61 | 131,430.8 |

초기 테르 재현은 레벨 2에서 Q 3회·W 1회·E 307회·R 0회로 복귀 지점에 머물렀다. 보완 후 같은 조합에서 모든 기술과 성장·공성이 진행됐다.

기존 3종의 전술 봇 검사는 1,860초 시점에도 교전 중이었다. 연장 관측에서 2,077.3초에 자연 종료한 뒤, 해당 회귀의 관측 상한을 2,400초로 조정했다. 검사 실행 시간 한도는 420초다. 자연 핵 파괴를 요구하는 조건으로 통과 여부를 판정한다. [전술 경기 검사](../../../game/project-e/tests/test_tactical_lifecycle.gd) · [장기 검사 실행](../../../tools/check_godot.py)

자동 경기 29분 58초~42분 8초는 현재 봇 정책의 관측값이다. 긴 공성 구간과 회복 복귀 횟수는 후속 밸런스 실험의 우선 관찰 항목이다. [플레이테스트 기록](../content/10-playtest-and-balance.md)

## 배포 화면과 Windows 실행

실제 배포 PCK에서 319개 화면·입력 항목과 57장 촬영을 수행했다. 1280×720·1366×768·960×540 선택 화면, 8명 포인터 선택, 신규 모델, 32개 액티브, 전투 HUD, 상점과 소모품을 포함한다. Windows에서는 내보낸 EXE의 120프레임 headless 기동을 확인한다.

외형 보완 검토본은 소스 `db321f0867230ef06f3f1de89300ab3488598f25`의 PR 통합 빌드에서 촬영했다. 전체 촬영 파일의 SHA-256을 목록과 대조했고, 선택한 8장과 전체 목록을 게임허브에 보관했다. [실제 화면과 촬영 근거](../assets/v8/README.md) · [외형 검토 빌드](https://github.com/herothgf-cell/project-e/actions/runs/42574434669)

배포 ZIP에는 실행 파일과 PCK를 같은 폴더에 둔다. 실행 후 영웅을 선택하고 기술 체험으로 시작하면 레벨 3과 R 해금 상태에서 QWER를 시험할 수 있다. F7에서는 8명의 동작과 기술을 직접 재생할 수 있다. 최신 PR 빌드의 다운로드와 검사 결과는 배포 항목에 연결한다. [실행 파일·검사 링크](https://github.com/herothgf-cell/project-e/pull/10)

## 추가 관측 항목과 설계 선택

- 캐릭터 규모는 기존 3명을 포함한 총 8명으로 해석했고, 경기 편성은 팀당 3명으로 구성했다.
- 게임허브는 기존 GitHub `doc/design`에 정리했다.
- 신규 5명은 실제 모델 초상과 기존 얼굴·의상 텍스처를 재사용한 프로토타입이다.
- 신규 영웅의 수치, 고정 3인 조합과 긴 자동 경기의 균형은 사람 플레이에서 검토할 항목이다.
- 사람 조작의 학습·체감, 여러 GPU의 성능과 장시간 조작 기록은 예정 상태다.
- 원작의 정확한 XP 곡선·가스 사용처·상세 상품 가격과 버전 차이는 역기획의 확인 과제에 기록했다.
