# Fantasy V4 — 실제 전투 표현과 효과음 에셋 가이드

## 목표
기존 V3 [3등신 미술·게임용 SVG](22-fantasy-v3-asset-guide.md) 위에 재생 가능한 **3D 영웅 장비·모션·QWER 시전 효과·오디오**를 추가한 개발용 시각 검토판이다.

## 영웅 3종 (실제 게임 파츠)

| 영웅 | 게임 장비·표정 보강 | 움직임 | 효과 톤 |
|---|---|---|---|
| 바스 | 룬 문양이 박힌 거대한 오른손 장갑, 금속 단면, 갈색 골드 장식 | 묵직한 보폭·공격 반동·낮은 중심 | 주황 / 불꽃 / 균열 |
| 리오 | 마력 원반의 이중 궤도, 수정 바인딩, 마법사 모자, 은청색 머리 | 가벼운 발걸음·마법 시전 기울기 | 푸른색 / 월광 / 별빛 |
| 네마 | 나뭇가지·잎사귀 문양, 연결 룬, 숲 정령 머리 장식 | 부드러운 바운스·보호 동작 | 초록색 / 씨앗 / 덩굴 |

코드: `game/project-e/scripts/presentation/hero_rig.gd`. 이 장비는 기존 관절 아래 새 `WeaponDetail`, `HairDetail`, `RuneEmblem`으로 부착된다. 수치·권한 및 충돌 반경은 그대로다. 얼굴·캡슐·섬유 메시가 아직 프로시저럴 기반이므로 **출시용 스컬프·리깅을 대체하지 않는다**.

## QWER 전투 VFX
`skill_vfx.gd`의 원래 3라인 시야/LOS/판정 승인 표본마다 룬, 수직 잎 문양, 화염 단편 등을 추가한다. `style_for(hero,slot)`이 12개의 독립 모티프를 제공한다. 경고 영역은 `effects_view.gd`가 실제 기술 권한을 기준으로 그리므로 이 작업은 게임플레이 수치를 바꾸지 않는다.

| 영웅 | Q | W | E | R |
|---|---|---|---|---|
| 바스 | Ember Arc | Guardian Sigil | Flame Dash | Thunder Fissure |
| 리오 | Comet Disc | Nebula Loop | Moonstep | Constellation |
| 네마 | Seed Rune | Grove Pulse | Forest Guard | Vine Bind |

## 직접 합성한 Original WAV 5종
`game/project-e/assets/audio/` 폴더의 PCM mono / 16kHz / 16-bit 파일을 게임에서 직접 읽는다.

| 원본 | 재생 이벤트 | 길이 |
|---|---|---|
| slash.wav | 바스 기본 공격/스킬 시작 | 0.20초 |
| arcane.wav | 리오 기본 공격/스킬 시작 | 0.27초 |
| nature.wav | 네마 기본 공격/스킬 시작 | 0.27초 |
| hit.wav | 내 영웅이 새로 피격됨 | 0.18초 |
| level.wav | 내 영웅 레벨 증가 | 0.36초 |

소리 중복 재생 방지: 현재 조작 영웅의 ID/phase/cast slot/last_damage/level만 관측한다. 같은 상태를 프레임마다 두 번 재생하지 않는다. **적 영웅·미관측 적의 행동은 오디오 신호로 노출하지 않는다.** F7 분리 연출실은 소리 없이 화면만 검토한다. 지속 배경음악과 완성형 믹싱은 후속 범위다.

**라이선스:** 기존 상용 게임 효과음을 복제·샘플링하지 않고 이 프로젝트를 위해 순수 수학 함수와 노이즈로 직접 합성했다. 자체 게임에 수정·사용 가능. 소스 등록은 Git에서 바로 관리하며 Git LFS 불필요.

## F7 검토 체크
1. 바스/리오/네마에서 이동→대기 전환 시 발밑 충돌과 루트 바운스 분리.
2. QWER 12종에 서로 다른 관절 동작·VFX 모티프가 보이며 판정 종료 뒤 새 피해 효과가 남지 않는지.
3. 시야 밖 적과 구조물/장식의 오디오/시각 정보 누출 없음.
4. 로컬 기본 공격→Q→W→E→R, 피격/레벨업 SFX 각 1회/이벤트인지.
5. Windows preview에서 1280×720, 1920×1080 비교. 이전 V3 시안과 별도로 실제 인게임 캡처와 비교.

## 품질/크기 제약
- WAV는 5개 합계 약 41KB; 추가 3D 디테일은 코드생성 메시, 외부 FBX/PSD 없음.
- 실제 플레이/오디오 볼륨·취향은 사용자의 Windows에서 사람 검토가 필요하다.
- 전투 조작 리듬·카메라(F6)·스킬 권한과 게임 규칙은 이전 V3 그대로.
