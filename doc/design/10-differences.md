# 기존 설계와 현재 실행판의 차이

- 기준일: 2026-11-06. 초기 결정·소모품 계약은 보존하고 V5의 현재 구현 상태를 갱신했다.
- 목적: 기존 제안, 이번 결정, 현재 구현 한계를 구별해 다음 작업에서 잘못된 전제를 쓰지 않게 한다.
- 기존 `docs`를 삭제하거나 구현 차이에 맞춰 조용히 고쳐 쓰지 않는다. 새 콘텐츠의 현재 안내는 [이 문서 묶음](README.md)을 따른다.

## 3. 현재 구현의 한계

| ID | 현재 동작 | 분류와 다음 기준 |
|---|---|---|
| L01 | 이전에는 전체 원형·부채 윤곽을 표시했다. 현재는 같은 맵 차단체와 효과 원점·방향·각도·반경으로 조준/활성 효과의 벽 뒤 영역을 자른다 | 이전 표시 결함의 코드 수정 기록. 곡선·채움은 샘플링 표현이며 최종 벽 모서리/관측 경계 렌더 결과는 [검증 기록](09-verification.md) 참조 |
| L02 | 길찾기는 1m AStar 격자와 연속 구간 검사를 조합한다 | 구현 방식의 한계. 자유공간 최단 경로나 모든 좁은 모서리 통과를 보장하지 않음; 실제 출발/복귀·타워 접근을 검증 |
| L03 | 봇은 라인 전투·기지 복귀·자동 성장·소모품 외에 관측한 셀 수집, 아군 지원, 핵 방어와 부활 뒤 상태 초기화를 수행한다 | 전역 빈 라인 판단, 적 핀 집중 파괴, 팀 공성 조율과 난이도별 반응은 후속. 봇 동작 구현은 사람 경기 밸런스 검증과 구분한다 |
| L04 | 기본 공격·Q/W/E/R·피격·사망·부활은 관절 동작, 아이콘·효과·전투 음향과 연결되어 있다 | V5의 3D 표현은 구현됨. 자연스러운 발 접지·관절 변형·혼전 가독성·음향 피로도와 튜토리얼은 실제 플레이로 검토해야 한다 |
| L05 | 전장/미니맵 현재 시야 음영은 동일 권한 판정을 1m 셀 중심에 샘플링한다. 이동 재계산은 250ms(4Hz) 간격 제한과 0.1m 이하 이동 생략을 사용하며 제공원 집합 변화는 즉시 반영한다 | 위치 경계가 약 0.71m 차이 나거나 이동 반영이 지연될 수 있는 표시 근사. 클릭·유닛·HP·셀 XP는 정확한 현재 시야 판정, 적 경고는 현재 시야 기하의 보수적 영역으로 제한한다. 마우스오버 범위도 128방향 샘플이다 |
| L06 | 초기 측정 이력:  Linux debug/headless의 68유닛·아군 시야원 34개 프로필에서 1m 음영 갱신 중앙값 27.8ms, 최대 36.4ms를 측정했다. 정지 상태 60회 표시 갱신에서는 재계산 0회였다 | 4Hz 갱신에도 CPU 부하 급증이 가능한 프로토타입 성능 한계. 전체 프레임 시간·특정 기기 60fps·Windows/사람 플레이의 증거가 아니다; 상세 근거와 후속 게이트는 [검증 기록](09-verification.md) 참조 |

L01은 적중 규칙 변경이 아니라 이전 표시 결함의 수정 기록이다. L05/L06은 현재 남아 있는 표시 근사와 성능 한계다. 새로 발견한 결함도 의도적 축소로 재분류하지 않고 이 표나 실제 검증 기록에서 추적한다.

## 4. 유지하는 기준

M01 좌표, 기본 HP/이동/공격, 에너지, 기술의 핵심 기하·타이밍·비용, 레벨 1–12와 투자 상한, 20초/18초 웨이브, 탑/핵 HP와 공성 보호, 사망·부활 공식은 기존 정본에서 이어받는 기준이다. 소스 대조와 별개로 상세 경계의 동작은 실제 테스트로 확인한다. 편의상 체력을 낮추거나 타워를 처음부터 노출해 끝나는 경기를 일반 규칙으로 쓰지 않는다.

기술 표에서 위력 100으로 계산한 피해 예는 공식 검산이다. 정상 R은 레벨 3부터 열리므로 자동 성장만으로도 위력 106 이상이다. 기술 체험의 표시 피해를 100 기준 예와 직접 비교해 버그로 판단하지 않는다.

## 5. 이 실행판으로 아직 입증하지 않은 것

사람 6명의 재미와 균형, 12–18분 경기 길이, 낮은 지연·패킷 손실에서의 공정성, 재접속, Steam 인증/로비/배포, Windows 사용자 PC의 수동 플레이, 특정 하드웨어 60fps, 출시용 아트·음향·접근성은 별도 게이트다. 하나의 기능이 미구현이면 작동하는 메뉴처럼 노출하지 않는다.

차이를 추가할 때는 원래 근거, 현재 실제 동작, 의도적 결정인지 결함인지, 추후 통과 기준을 함께 적는다. ‘간소화’라는 말만으로 알려진 판정 결함을 숨기지 않는다.

## 6. 이전 입력 차이의 수정 기록

초기 검토에서는 겹친 적을 화면 거리만으로 고르고 잠긴 구조물이 후보에 포함되는 차이가 있었다. 현재는 정확한 공유 시야 안의 살아 있는 적과 잠금 해제 대상을 검사한 뒤 영웅→병력→공격 가능한 구조물→셀→핀 순으로 고른다. 같은 우선순위는 화면 거리, 동률은 ID 순서다. 대상 순환 키 T는 여전히 미구현이다.

A 공격 이동과 F1 경기 도움말을 현재 조작에 추가했다. 도움말은 읽는 동안 시간을 멈추고 닫으면 열기 전 정지 상태를 복원한다. G 성장·레벨 3/1포인트 R 해금·B 걷기 복귀·셀·시야·탑 잠금/병력 보호를 안내한다. 이번 묶음에는 P 상점→구매→종류 슬롯 선택→D 사용 안내를 추가했다. 이 단계의 입력 검사와 720p/1080p 검수 기록은 [소모품 검증 이력](13-consumables-verification.md)에 남아 있다. 현재 입력·형상·렌더·내보내기의 수행 결과와 Windows 사용자 PC/사람 플레이의 미수행 상태는 [V5 검증](verification/2026-11-05-v5-verification.md)을 따른다. 이 문서의 코드 반영 상태로 해당 게이트의 통과를 대신하지 않는다.

## 7. 유지하는 기지 경제 계약

P 상점은 기지 밖·사망 중에도 설명을 열어 로컬 경기를 멈추며, 닫을 때 직전 일시정지 상태를 복원한다. 실제 구매는 살아 있는 영웅이 자기 기지 회복 구역 안에 있을 때만 가능하다. 최근 피해·사용 쿨타임은 구매를 막지 않는다. 두 슬롯은 I01/I02의 종류별 수량과 선택을 표시하며, 빈 종류 선택과 사용 후 선택을 유지한다. D는 다른 품목으로 자동 교체하지 않는다.

사용·선택은 조준과 현재 이동·공격·시전·예약 명령을 보존하고 기절·속박 자체로 막지 않는다. 적 영웅의 장치·지속 피해와 보호막으로 흡수한 유효 피해도 I02를 중단한다. 병력/탑·무효/중복/무적 피해·제어만 적용한 경우는 중단하지 않는다. 사망은 진행 효과만 종료하고 재고·선택을 보존하며 공유12초 쿨타임은 사망 중 감소한다. 실패는 비용을 쓰지 않고 승인 뒤 중단은 환급하지 않는다.

봇은 자기 기지에서 패치1개+병1개를 목표로 빈 종류를 채우고 기지 밖에서 자기 자원과 최근 피해를 보고 사용한다. 조작 영웅을 자동 소비 대상으로 삼지 않는다. 소모품 구현 당시에는 핵 방어·지원 등이 후속이었으나 현재는 핵 방어·아군 지원·관측 셀 수집이 구현되어 있다. 전역 빈 라인 판단·팀 공성 조율·난이도는 여전히 후속이다. 당시 소모품 단계의 자연6봇 경기는431.8초 서쪽 핵 파괴 승리였고 이전 소모품 없는27:18 동쪽 승리와 차이가 크다. 한 봇 조건에서의 큰 변화로 기록하며 사람 경기 목표·가격·진영 균형의 검증으로 해석하지 않는다. 세부 계약과 수치는 [성장·경제](05-growth-and-economy.md), [봇](04-units-and-ai.md), [UI](06-ui-and-controls.md)를 따른다.

## 8. V5 표현 복구와 남은 차이

현재 실행판은 얼굴·의상 텍스처를 내장한 영웅 GLB 3종, 환경 GLB 11종, 수로 표면, 현재 초상화를 사용한다. 영웅당 10개 관절 클립과 12개 Q/W/E/R 동작, 스킬 효과와 전투 음향도 연결되어 있다. ‘임시 도형만 있다’, ‘봇의 지원·핵 방어가 없다’, ‘음향 전체 미구현’이라는 이전 단계의 설명은 현재 상태에 적용하지 않는다. 자세한 자산과 소스 연결은 [V5 안내](25-illustrated-canal.md)를 따른다.

모델은 `AnimationPlayer`로 이름이 있는 3D 노드 관절을 움직인다. 형상과 얼굴·의상 텍스처를 수정할 때는 복구된 영웅 생성기와 WebP를 사용한다. [V5 모델 제작 안내](25-illustrated-canal.md#5-모델과-텍스처-수정-계약)

새 실제 렌더는 스크립트로 배치한 경기와 독립 검토실에서 촬영했다. 자동 검사·렌더·패키지 확인의 수행 결과는 [2026-11-05 검증](verification/2026-11-05-v5-verification.md)에 기록한다. Windows 사용자 PC의 수동 플레이, 사람 간 밸런스, 대상 하드웨어 성능, 네트워크·재접속·Steam 완료를 주장하지 않는다. 이어서 할 일은 [남은 개발](11-remaining-development.md)에 정리한다.
