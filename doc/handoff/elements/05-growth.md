# 05. 성장 — XP, 레벨과 투자 선택

정리일: **2026-11-19**. 대조 기준: `main`의 `e29c36296abf6d365353401dd0cbee411edc531d`, V9 `0.9.0`.
이 문서는 다른 개발 환경에서 성장 규칙과 검증 경계를 이어받기 위한 요약이다. 기존 [성장 상세](../../design/content/05-growth.md)를 보존하며, 이번 작업에서는 게임 테스트를 실행하지 않았다.

## 1. 의도와 상태 구분

짧은 기술 순환, 라인에서의 수급, 셀을 위한 이동과 합류가 한 경기의 성장 선택으로 이어져야 한다.
경험을 얻는 속도와 얻은 성장량을 사용하는 결정을 나누어, 조작 성과와 투자 판단을 함께 관찰한다.

| 상태 | 이 문서에서의 의미 |
|---|---|
| **현재 코드 확인** | 위 기준 소스의 조건·상수·상태 변화를 읽어 확인한 규칙 |
| **기존 검증 기록** | 과거 날짜와 소스에 대해 저장소에 남은 실행 결과; 이번 재실행 결과가 아님 |
| **후속 제안** | 비교 실험이나 사람 플레이로 평가할 작업; 채택 수치가 아님 |
| **미확인** | 사람 체감, 원작 미확정 값 등 현재 근거로 결론 내릴 수 없는 항목 |

## 2. 세 자원의 책임

| 자원 | 코드 필드 | 획득과 용도 | 서로 바꿀 수 있는가 |
|---|---|---|---|
| XP | `xp` | 처치 보상을 받아 다음 레벨로 진행 | 직접 투자하거나 상점에 지불하지 않음 |
| 성장 포인트 | `points` | 시작 지급·레벨업으로 얻고 능력치 또는 R에 투자 | 골드와 교환하는 기능 없음 |
| 골드 | `credits` | 시작·정기 수입·처치 보상으로 얻고 소모품 구매 | 능력치·R 투자의 비용이 아님 |

**현재 코드 확인:** 성장 투자는 경기 동안 유지되는 수치와 R 사용 가능 여부를 바꾼다. XP는 투자 후 줄어드는 지갑이 아니며, 포인트를 사용해도 레벨이 낮아지지 않는다. 골드의 세부 흐름은 [골드·아이템](06-gold-items.md)에서 다룬다.

## 3. 시작·레벨업·상한

| 항목 | 현재 실행값 |
|---|---|
| 일반 경기 시작 | 레벨 1, XP 0, 성장 2포인트, R 잠금 |
| 다음 레벨 필요 XP | 현재 레벨 `L`에서 `100 + 25 × (L − 1)` |
| 레벨업 1회 | 성장 +1포인트, 최대 HP +40, 위력 +3 |
| 생존 중 레벨업 | 현재 HP도 +40, 새 최대 HP 이내로 제한 |
| 사망 중 레벨업 | 최대 HP·위력·포인트는 증가; 현재 HP는 회복하지 않음 |
| 최대 레벨 | 12; 도달하면 잔여 XP 0, 이후 추가 XP·포인트 없음 |
| 일반 경기 총 공급 | 시작 2 + 11회 레벨업 = 13포인트 |
| 기본 자원 | 최대 마나 100, 자연 마나 회복 초당 8, 자연 HP 회복 0 |
| 기술 체험 시작 | 경기 참가 6명 모두 레벨 3, 최대 HP +80, 위력 106, 잔여 3포인트, R 해금·R 투자 1회 |

기술 체험은 일반 경기의 성장 속도를 측정하는 조건이 아니다. R에 사용한 1포인트를 포함하면 레벨 3의 누적 4포인트와 맞는다.

| 1 | 0 | 2 | 0 | 0 |
| 2 | 100 | 3 | 40 | 3 |
| 3 | 225 | 4 | 80 | 6 |
| 4 | 375 | 5 | 120 | 9 |

상한까지 수용할 XP를 먼저 계산하므로, 레벨 11·XP 340에서 40을 받아도 실제 수용량은 10이며 12레벨·XP 0이 된다.

## 4. XP 획득과 공유의 경계

| 처치 대상 | 총 XP | 공유 조건 |
|---|---:|---|
| 근접 병력 / 원거리 병력 | 각 20 | 처치 팀의 생존 영웅 중 사망 위치에서 14m 이내 |
| 공성 병력 | 35 | 같은 조건 |
| 낮음 / 중간 / 높음 셀 | 20 / 30 / 40 | 같은 조건 |
| 적 영웅 | 60 | 같은 조건; 처치자의 골드 보상과 별도 |
| 탑 / 정령목 | 해당 처치 분기에 XP 지급 없음 | 탑은 별도 팀 골드 보상이 있음 |

**현재 코드 확인:** 대상 주변의 적격 영웅 수로 XP를 균등 분할한다. 14m 경계는 포함하고, 사망·거리 밖 영웅은 제외한다. 적격자가 없으면 주변 공유 보상을 지급하지 않는다.
레벨 12 영웅도 공유 인원에는 포함된다. 그 몫은 `award_xp()`가 수용하지 않으며 나머지 영웅에게 재분배하지 않는다. 해당 영웅의 골드 공유 자격은 유지된다.
셀은 첫 30초에 생성되고 파괴 후 45초에 같은 보상으로 돌아온다. 수급 선택과 이동 비용은 [기존 성장 상세](../../design/content/05-growth.md) 및 [보상 코드](../../../game/project-e/scripts/battle/battle_rules.gd)를 함께 본다.

## 5. 투자 목록과 승인 순서

모든 항목은 1회에 **1포인트**다. 경기 진행 → 유효 영웅 → 항목·잔여 포인트·상한·R 요구 레벨 검사 → 포인트 차감과 효과 적용 순서다.

| 메뉴 / 코드 키 | 1회 효과 | 상한 | 최대 투자 효과 |
|---|---|---:|---|
| 위력 / `power` | +10 | 5 | +50 |
| 최대 HP / `hp` | 최대 HP +80; 생존 중 현재 HP +80 | 5 | +400 |
| 방어 / `armor` | +5 | 4 | +20 |
| 마나 회복 / `regen` | 초당 +1 | 3 | 초당 +3, 기본 포함 11 |
| 이동속도 / `speed` | +0.15m/s | 3 | +0.45m/s |
| R / `R` | 레벨 3 이상에서 해금 | 1 | 네 번째 액티브 사용 |

전체 상한은 21회이고 일반 경기 공급은 13포인트이므로 전 항목 최대 투자는 불가능하다. R을 열면 능력치에 쓸 수 있는 총량은 최대 12포인트다.
레벨 3 도달만으로 R이 열리지 않는다. 해당 시점에 포인트를 모두 썼다면 다음 포인트를 얻기 전까지 해금할 수 없다.
기지 방문·생존은 투자 조건이 아니므로 사망 중에도 투자할 수 있다. 종료 경기, 포인트 부족, 상한 초과, 레벨 3 미만 R 요청은 투자를 적용하지 않는다.
재분배·환불 기능은 현재 투자 API에 없다. Q/W/E의 별도 기술 레벨 투자도 없다. 근거: [투자 함수 `invest()`](../../../game/project-e/scripts/battle/battle_state.gd).

## 6. 다른 전투 규칙과의 접점

- **현재 코드 확인:** 기본 공격 피해는 `60 + 0.30 × 위력`이다. 위력 투자 1회는 이 기본 부분을 3 높이고 기술은 각각의 계수만큼 변한다.
- 기술의 위력과 기본 공격 피해는 승인 시 저장된다. 선딜 중 위력 투자가 이미 승인된 피해를 올리지 않는다. 자동 패시브 보호막 등 별도 효과의 위력 참조는 영웅 구현을 따른다.
- 방어 적용 피해는 `원피해 × 100 / (100 + max(0, 방어))`다. 방어 20의 감소율 약 16.67%는 이 식의 계산값이며 고정 20% 감소가 아니다.
- 사망 후에도 레벨·투자·남은 포인트는 유지된다. 부활 시 증가한 최대 HP와 최대 마나로 복구한다.
- 자기 기지에서는 마지막 유효 피격 후 2초, 자신이 적 영웅에게 피해를 준 뒤 3초가 모두 지나면 초당 최대 HP·최대 마나의 20%를 회복한다. 자연 마나 재생은 별도로 더해진다.
- 모든 조건을 초기화하는 새 경기는 일반/체험 시작값을 다시 사용한다. 기지 회복과 소모품은 XP·성장 포인트를 지급하지 않는다.

근거: [피해·성장 권한](../../../game/project-e/scripts/battle/battle_rules.gd), [공격·부활·회복](../../../game/project-e/scripts/battle/battle_state.gd), [기술 위력 저장](../../../game/project-e/scripts/battle/hero_abilities.gd).

## 7. 사용자 흐름과 피드백

**현재 코드 확인:** 수급 → 개인 XP 획득 표시 → 레벨업과 포인트 안내 → `G` 성장창 → 투자 선택 → 현재 수치·횟수·상한 갱신 흐름이다.
HUD는 현재 XP/다음 필요량, 최고 레벨, 남은 포인트와 K/D/A를 표시한다. 성장창은 현재 위력·방어·이동·마나 회복, 각 투자 횟수/상한과 증가량, R 잠금 이유를 표시한다.
XP 피드백은 권한이 기록한 실제 개인 지급량과 공유 인원을 사용한다. 레벨 12에서 버린 초과 XP를 획득한 것처럼 표시하지 않으며, 숨은 처치 목표의 위치를 보상으로 노출하지 않는다.
근거: [HUD](../../../game/project-e/scripts/presentation/battle_hud.gd), [XP 피드백](../../../game/project-e/scripts/presentation/xp_feedback_view.gd), [기존 UI 기획](../../design/content/08-ui-and-camera.md).

## 8. 원작 근거와 Project E 선택의 구분

| 항목 | 저장소의 원작 조사 | Project E 현재값 |
|---|---|---|
| 투자 자원 | 광물 시작 1; 25레벨 전후 지급 2→1, 전환 경계 미확인 | 시작 2; 매 레벨 +1 |
| 자동 HP / HP 투자 | 생명력 등급별 90~110 / 220~280 | 공통 40 / 80 |
| 마나 투자 | 최대 마나 +50 및 재생 증가, 재생량 추가 확인 | 최대치 유지, 초당 재생 +1 |
| 방어 투자 | +2, 자료별 투자 상한 차이 존재 | +5, 상한 4, 비선형 피해식 |
| 최대 레벨·XP 곡선 | 확보 근거로 확정하지 못함 | 레벨 12, 누적 2,475 XP |

원작의 이동속도 단위를 Project E의 m/s와 직접 환산하지 않는다. 위 비교는 저장소 조사 내용을 구분해 인계한 것이며 이번에 원자료를 새로 검증한 결과가 아니다. [원작 성장·경제와 근거](../../design/reverse-design/03-growth-and-economy.md).

## 9. 후속 과제와 완료 기준

**후속 제안:** 성장 빈도, HP 투자 체감, 최대 마나 투자, 치유량의 성장 연동, 시야·사거리 투자는 각각 독립 실험 후보다. 수치나 채택 여부는 미확정이다.
같은 영웅·편성·진영·시작 조건에서 한 축만 바꾸고 첫 R 시각, 포인트 미사용 시간, 투자 분포, 생존 시간, 마나 부족 시간, 합류 이후 수급을 기록한다.
**미확인:** 사람 플레이에서 투자 선택의 차이를 설명할 수 있는지, 열세 팀이 회복할 기회가 충분한지, 영웅별 필수 투자로 굳는지는 아직 결론 내리지 않는다.

| 이어받은 환경의 완료 기준 | 확인 방법 |
|---|---|
| 시작·다중 레벨업·상한이 표와 일치 | 225 XP→레벨 3, 2,475 XP→레벨 12, 잔여량·포인트 검산 |
| 공유와 실제 지급이 일치 | 14m 경계, 사망·만렙 혼합, 40/3 분할, 초과 XP 처리 |
| 투자가 원자적으로 승인·거절 | 부족·상한·R 잠금 때 수치 불변, 성공 시 정확히 1포인트 차감 |
| 사망과 승인 시점이 일관됨 | 사망 중 HP 투자·부활, 선딜 중 위력 투자 비교 |
| 화면이 같은 상태를 설명 | 성장창·HUD·개인 XP 이벤트·R 안내 대조 |
| 선택의 체감을 사람에게 확인 | 투자 이유와 교전 결과를 참가자 기록으로 남김 |

## 10. 기존 검증 기록과 근거

**기존 검증 기록:** [2026-11-10 V9](../../design/verification/2026-11-10-v9-verification.md)에 전체 38개 행동 스위트·6,997개 검사·실패 0이 기록되어 있다. V9은 기존 성장 수치를 유지했다. 이 수는 성장 기능만의 검사 수가 아니며 이번 문서 정리의 실행 결과도 아니다.
이어받을 검사 경로는 [전투 규칙](../../../game/project-e/tests/test_battle_rules.gd), [XP 피드백](../../../game/project-e/tests/test_xp_feedback.gd)이다. 이번 작업은 소스·기존 문서 대조와 상대 링크 정리까지 수행하며 테스트 재통과나 사람 밸런스 승인을 주장하지 않는다.
