# 01. 경기 흐름과 승패 인수 기획서

기준은 **V9 0.9.0**, 정리 대상 커밋은 `e29c36296abf6d365353401dd0cbee411edc531d`다. 작성일은 2026-11-19다.

- **현재 코드 확인**: 해당 커밋의 소스를 읽어 확인한 구현이다.
- **기존 검증 기록**: 저장소에 보존된 이전 실행 결과다. 이번 문서 작성에서 게임이나 회귀 검사를 실행하지 않았다.
- **후속 제안**: 다음 작업자가 검토할 작업 또는 완료 조건이며 새 확정 사양이 아니다.
- **미확인**: 사람 플레이나 새 환경에서 아직 직접 확인하지 않은 사항이다.

## 목표와 플레이 흐름

라인에서 얻은 성장과 교전 우위를 병력 동반 공성으로 전환하고, 적 마법 핵을 파괴해 경기를 끝낸다. 오프라인 3 대 3에서 사용자는 하단 팀 영웅 한 명을 조작하고 나머지 다섯 영웅은 봇이 맡는다. 선택 가능한 영웅은 8명이다.

| 구간 | 플레이어의 판단 | 다음 구간으로 이어지는 조건 |
|---|---|---|
| 선택 | 영웅과 일반 경기·기술 체험 선택 | 선택한 영웅으로 새 경기 생성 |
| 기지 준비 | 성장 투자, 소모품 구매 | 이동으로 세 라인에 진입 |
| 라인 성장 | 병력 마무리, 견제, 셀 또는 지원 선택 | 레벨·포인트·골드 확보 |
| 첫 돌파 | 병력과 외곽탑 공격 | 같은 라인 내곽탑 잠금 해제 |
| 핵 진입 | 내곽탑 파괴, 병력과 재집결 | 어느 한 내곽탑이 파괴되면 핵 노출 |
| 마무리 | 적 영웅·병력과 핵 공격 사이 선택 | 핵 파괴로 승패 확정 |
| 결과 | 같은 영웅 재시작 또는 선택 화면 복귀 | 이전 경기 상태를 버리고 새로 시작 |

현재 게임은 전체 팀 드래프트 화면을 제공하지 않는다. 선택 영웅에 따른 편성은 `hero_roster.gd`의 `team_for()`로 정해진다. 같은 팀 중복 없이 3명이며, 양 팀에 같은 영웅이 나오는 것은 가능하다. [로스터 소스](../../../game/project-e/scripts/battle/hero_roster.gd)

## 현재 코드 확인: 경기 생성과 시계

| 항목 | 일반 경기 | 기술 체험 |
|---|---|---|
| 시작 레벨·XP | 레벨 1, XP 0 | 레벨 3, XP 0 |
| 남은 성장 포인트 | 2 | 3 |
| R | 미해금; 레벨 3 이상에서 1포인트 투자 | 해금, R 투자 1회 기록 |
| 시작 위력 | 100 | 106 |
| 시작 최대 HP | 영웅별 기본값 | 기본값 +80 |
| HP·마나 | 최대치로 시작 | 최대치로 시작 |
| 시작 골드 | 100 | 100 |
| 적용 대상 | 출전 영웅 6명 | 출전 영웅 6명 모두 |

플레이어는 하단 팀의 중앙 라인으로 배정되고 두 아군은 왼쪽·오른쪽에 배정된다. 이는 시작 배정이며 플레이어 이동을 라인 안으로 제한하는 규칙은 아니다. 새 경기는 영웅 6명, 탑 12개, 핵 2개로 시작한다.

| 시간 규칙 | 현재 값 |
|---|---|
| 전투 판정 | 고정 `1 / 30`초 간격 |
| 첫 웨이브 / 이후 | 20초 / 18초마다 |
| 첫 경험치 셀 | 30초 |
| 정기 골드 | 5초마다 영웅당 5; 사망 중에도 지급 |
| AI 판단 | 0.4초마다 |
| 일시 정지 | 경기 화면이 `step()`을 호출하지 않아 시계 정지 |

경기 시간에 따른 강제 승패나 12~18분 종료 타이머는 없다. **12~18분은 기존 기획의 사람 경기 길이 가설**이며 현재 달성 판정으로 사용하면 안 된다. [경기 상태](../../../game/project-e/scripts/battle/battle_state.gd) · [경기 화면](../../../game/project-e/scripts/presentation/battlefield.gd)

## 현재 코드 확인: 구조물 진행

| 대상 | 시작 HP | 피해를 받을 수 있는 조건 |
|---|---:|---|
| 외곽탑 | 2,000 | 살아 있는 적대 구조물이며 공격 조건 충족 |
| 내곽탑 | 2,600 | 같은 라인의 외곽탑 파괴 |
| 핵 | 4,000 | 적 팀 내곽탑 중 하나 이상 파괴 |

일반적인 경기에서는 외곽탑을 거쳐 내곽탑을 파괴하므로 한 라인을 완전히 돌파하면 핵이 열린다. 잠금 해제는 되돌리지 않는다. 구조물의 잠금과 병력 부재 보호는 별개다.

- 구조물 중심 **12 m 안의 공격 팀 살아 있는 병력**이 병력 부재 보호를 해제한다.
- `has_siege_minion()`은 함수명과 달리 공성 병력만 검사하지 않는다. 근접·원거리 병력도 인정한다.
- 영웅 또는 정령목 출처의 구조물 피해는 방어 계산 후 0.5배다.
- 공격 팀 병력이 없으면 추가로 0.3배다. 영웅의 합성 배율은 0.15배다.
- 셀·정령목·물감 구역은 동반 병력으로 인정하지 않는다.
- 잠긴 구조물에는 이 배율 계산 이전에 피해 0을 반환한다.

정확한 피해식과 예외는 [전투 기획](03-combat.md), 병력과 봇의 접근 판단은 [미니언·AI·공성](04-minions-ai-siege.md)에 둔다. [잠금 소스](../../../game/project-e/scripts/battle/battle_state.gd) · [피해 소스](../../../game/project-e/scripts/battle/battle_rules.gd)

## 현재 코드 확인: 사망·회복·복귀

부활 대기는 사망 당시 레벨 `L`에 대해 `8 + 2 × L`초다. 레벨 1은 10초, 레벨 6은 20초, 레벨 12는 32초다. 기지의 라인별 위치에서 최대 HP·마나로 돌아오며 3초 보호를 받는다.

| 상태 | 사망 또는 복귀 처리 |
|---|---|
| 레벨·XP·성장 투자·골드 | 유지 |
| 기술 재사용·정기 수입 | 사망 중에도 진행 |
| 진행 중 공격·시전·이동 명령 | 취소·정리 |
| 자신에게 걸린 보호막·제어·밀치기 | 정리 |
| 소유 설치물·표식·예약 타격 | 영웅별 소유 상태 정리 규칙 적용 |
| 이미 발사한 일반 기본 탄 | 소유자 사망만으로 일괄 취소하지 않음 |
| 다른 아군에게 부여한 보호막 | 그 아군의 만료 시각까지 유지 |
| 부활 보호 | 기본 공격 또는 적대 기술 승인 시 해제; 지원 기술은 속성에 따름 |

기지 회복은 마지막 피해 이후 2초, 마지막 적 영웅 대상 유효 피해 이후 3초 조건을 함께 검사한다. 조건 충족 중 초당 최대 HP·최대 마나의 20%를 회복한다. `B`는 합법적인 지상 경로로 기지까지 걷는 명령이며 즉시 귀환 기술이 아니다. [상태·회복](../../../game/project-e/scripts/battle/battle_state.gd) · [사망 정리](../../../game/project-e/scripts/battle/battle_rules.gd)

## 현재 코드 확인: 결과와 재시작

한 틱의 유닛 행동·투사체·설치물·예약 효과를 처리한 뒤 핵 생존을 검사한다. 한 팀 핵만 파괴됐으면 반대 팀 승리, 같은 틱에 양 핵이 파괴됐으면 무승부다. 결과 확정 뒤 시뮬레이션 진행과 새 전투 명령은 중단된다.

`reset()`은 시계·유닛·투사체·예약 타격·적중 중복 기록·시야 캐시·피드백 이벤트·승패를 새로 만든다. 같은 영웅 재시작은 영웅 키와 모드를 입력으로 다시 전달하며, 선택 화면에서 영웅을 바꿀 수 있다.

## V9에서 처리한 것과 남은 것

**현재 코드 확인:** 아군 하단·적군 상단의 세로 진행 표시를 사용한다. 회복한 봇은 기지 출발 때 열린 라인으로 최대 2명까지 합류할 수 있다. 미니언·탑·핵의 수치와 승리 조건은 유지됐다.

**기존 검증 기록:** 2026-11-10 최종 V9의 세 자동 편성은 8:06.6, 18:01.3, 22:22.7에 자연 종료했다. 기본 편성의 첫 외곽·내곽 파괴 시각은 V8과 같았으며 후반 공성 공백이 줄었다. [V9 검증 기록](../../design/verification/2026-11-10-v9-verification.md)

**미확인:** 사람 경기의 학습 곡선, 빠른 돌파 뒤 수비·회복 기회, 느린 편성의 체감, 목표 12~18분 충족은 확정되지 않았다.

## 후속 제안: 기록할 항목과 작업 완료 판정

첫 영웅 피해, 첫 처치, 첫 R, 첫 외곽 파괴, 첫 내곽 파괴, 첫 핵 노출, 실제 파괴된 핵의 노출·첫 피해·파괴를 따로 기록한다. 양 핵의 노출 시각이 다르면 같은 대상으로 취급하지 않는다.

- [ ] 일반·체험 시작에서 6명의 레벨·R·포인트와 플레이어 영웅이 일치한다.
- [ ] 잠금 해제, 병력 부재 보호, 동일 틱 양 핵 파괴를 독립적으로 확인한다.
- [ ] 사망·부활·결과·재시작을 거쳐 이전 경기 효과가 남지 않는다.
- [ ] 실제 사람 경기 기록에 빌드·편성·진영·숙련도·중단 여부를 함께 남긴다.
- [ ] 경기 시간이 변하면 초반 돌파와 핵 노출 후 공성 중 어느 구간이 변했는지 설명한다.

위 체크리스트는 다음 변경의 완료 조건 제안이다. 이번에 통과한 검사 목록이 아니다. 재현과 증거 관리의 공통 기준은 [밸런스·검증](10-balance-tests.md)을 따른다.
