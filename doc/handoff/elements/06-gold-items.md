# 06. 골드·아이템 — 다음 교전을 준비하는 경제

정리일: **2026-11-19**. 대조 기준: `main`의 `e29c36296abf6d365353401dd0cbee411edc531d`, V9 `0.9.0`.
기존 [골드와 아이템 상세](../../design/content/06-gold-and-items.md)를 보존하는 인계 요약이다. 이번 작업은 문서·소스 대조이며 게임 테스트를 실행하지 않았다.

## 1. 의도와 상태

골드는 다음 라인·합류·교전에 가져갈 회복 수단을 고르는 자원이다. 영구 능력치와 R은 성장 포인트가 담당하고, XP는 레벨 진척을 담당한다.
이 분리 덕분에 회복품의 가격·수입·효과를 조정할 때 성장 투자 비용을 직접 바꾸지 않고 비교할 수 있다. 이는 현재 구조에서 도출한 설계 해석이다.

| 상태 | 읽는 법 |
|---|---|
| **현재 코드 확인** | 현 소스에서 확인한 수치·조건·처리 순서 |
| **기존 검증 기록** | 과거 저장된 실행 결과; 이번 실행 결과가 아님 |
| **후속 제안** | 관측·실험 후 채택 여부를 정할 항목 |
| **미확인** | 사람 체감·원작 경제의 미확정 관계 등 |

**현재 코드 확인:** 표시명은 골드, 내부 필드는 `credits`다. 마나는 내부 `energy`이며, 예전 기록의 크레딧·에너지 병·수리 패치는 현재 골드·별샘 영약·숲빛 치유약과 구분해 읽는다.
구매는 성장 포인트를 소모하지 않고 XP를 주지 않는다. 현재 품목은 회복 소모품 2종이며 영구 장비·카드 상점으로 확대 구현된 상태가 아니다. [성장 인계](05-growth.md).

## 2. 수입 규칙

| 수입원 | 골드 | 지급 대상·조건 |
|---|---:|---|
| 경기 시작 | 100 | 일반·기술 체험의 모든 영웅 |
| 정기 수입 | 5초마다 5 | 모든 영웅; 사망 중에도 지급 |
| 근접 / 원거리 병력 | 각 12 | 사망 위치에서 14m 이내의 처치 팀 생존 영웅에게 균등 공유 |
| 공성 병력 | 20 | 같은 공유 조건 |
| 영웅 소유 피해의 병력 막타 | 추가 4 | 최종 피해의 영웅 소유자; 주변 공유와 별도 |
| 셀 | 10 | 같은 14m 공유 조건 |
| 영웅 처치 | 60 | 처치자 |
| 어시스트 | 각 20 | 최근 6초의 유효 피해 기여자 중 처치자 제외 |
| 탑 파괴 | 각 30 | 공격 팀의 모든 영웅; 거리·생존 제한 없음 |

근거: [초기값·정기 수입·병력 보상](../../../game/project-e/scripts/battle/battle_state.gd), [처치·공유 보상](../../../game/project-e/scripts/battle/battle_rules.gd).
최종 피해 소유자가 영웅이면 그 영웅을 처치자로 삼는다. 그렇지 않으면 최근 6초 유효 기여자 중 가장 최근 영웅을 찾는다. 소유 장치의 피해는 `owner_id`로 영웅에게 귀속된다.
영웅 처치의 60 XP는 주변 생존 영웅에게 공유하지만 처치 골드 60은 처치자 개인 보상이다. 두 숫자가 같아도 지급 조건은 다르다.
공유 골드는 소수로 누적할 수 있다. HUD는 `floori(credits)`로 정수 표시하고 구매 판정은 내부 잔액을 사용한다. 레벨 12에서도 골드 수입은 계속된다.
패배·승리로 경기가 끝나면 시뮬레이션 진행이 멈춘다. 시간 경과 수입을 실시간 벽시계 수입으로 구현하지 않는다.

## 4. 구매·선택·사용 흐름

1. `P`로 상점에서 효과·가격·현재 잔액과 구매 가능 이유를 읽는다.
2. 자기 기지에서 구매하면 골드가 즉시 차감되고 해당 재고가 1 증가한다.
3. 상점을 닫고 인벤토리에서 품목을 선택한다. 선택 자체는 아이템을 소비하지 않는다.
4. `D` 또는 사용 버튼으로 선택 품목을 사용한다.
5. 재고·공용 대기·남은 회복 시간과 완료·중단 알림을 확인한다.

| 요청 | 승인 조건 | 거절 시 계약 |
|---|---|---|
| 구매 | 진행 중 경기, 유효·생존 영웅, 유효 품목·재고·잔액, 자기 기지, 총 재고 2 미만, 가격 이상 잔액 | 골드·재고 불변, 사유 표시 |
| 종류 선택 | 유효 영웅·품목·재고 상태 | 소비 없음; 없는 재고도 선택 가능 |
| 사용 | 진행 중 경기, 생존, 선택 재고 1 이상, 공용 대기 0, 해당 자원이 최대치 미만 | 재고·대기·회복 효과 불변, 사유 표시 |
| 효과 진행 | 생존, 유효한 남은 효과 시간 | 완료·피격·사망 원인에 맞게 효과 종료 |

**현재 코드 확인:** 구매와 사용은 요청 순간 조건을 다시 검사한다. 마나 또는 HP가 1만 부족해도 사용 가능하고 초과 회복은 버리므로 효율은 사용자가 판단한다.
소모품 사용에 기절·속박 검사나 기술 선딜 취소가 없다. 이미 하던 이동·공격·시전·예약 명령을 별도로 덮어쓰지 않는다. 상점 열람과 구매 가능 여부는 구분한다.
상점은 로컬 경기를 일시정지하며 닫을 때 이전 정지 상태를 복원하는 흐름이다. 온라인 경기의 구매·일시정지 규칙은 이 구현으로 확정하지 않는다. [현재 UI 상세](../../design/content/08-ui-and-camera.md), [기존 상점 구현 기록](../../design/13-consumables-verification.md).

## 5. 회복·피격·사망의 예외

- **현재 코드 확인:** 회복은 매 틱 `min(delta, 남은 시간)`만큼 지급한 뒤 효과 시간을 줄인다. 마지막 부분 틱을 생략하지 않는다.
- 숲빛 치유약은 HP가 줄지 않아도 보호막에 흡수된 유효 적 영웅 피해로 중단된다. 소유 장치의 피해도 실제 영웅 소유자를 따른다.
- 일반 병력·타워의 독립 피해, 무효·중복·보호 상태로 거절된 피해, 피해 없는 제어는 치유약 중단 사유가 아니다.
- 별샘 영약은 같은 적 영웅 피해에도 계속된다. HP 회복품과 마나 회복품의 차이를 하나의 규칙으로 합치지 않는다.
- 같은 틱에서 타이머 단계가 이미 지급한 회복은 이후 공격으로 중단되더라도 소급 취소하지 않는다.
- 사망은 진행 효과를 종료하지만 보유 재고·선택을 지우지 않는다. 공용 대기는 사망 중에도 감소하고 부활로 초기화되지 않는다.
- 공용 대기는 30Hz의 360번째 틱에 12초가 끝나도록 미세 잔여값을 0으로 정리한다. 새 경기는 재고·대기·효과를 초기화한다.
- 같은 품목 회복의 중첩은 현재 정상 사용 흐름에서 발생하지 않는다. 회복 2/4초보다 공용 대기 12초가 길다.

근거: [회복·사용 권한](../../../game/project-e/scripts/battle/battle_consumables.gd), [피해 소유자와 중단](../../../game/project-e/scripts/battle/battle_rules.gd), [틱·부활 처리](../../../game/project-e/scripts/battle/battle_state.gd).

## 6. UX와 관찰할 비용

**현재 코드 확인:** HUD에는 골드, 보유 합계/2, 품목별 수량, 선택 상태, 공용 대기와 효과 잔여 시간이 있다. 상점은 구매 불가 사유와 실제 데이터의 설명을 보여준다. 개인 소모품 사건은 조작 영웅에 한해 알린다. [HUD 구현](../../../game/project-e/scripts/presentation/battle_hud.gd).
**후속 제안:** 구매 성공 횟수뿐 아니라 구매를 포기한 사유, 기지 방문 시점, 사용 후 추가 시전, 유효 회복량, 중단으로 잃은 회복량을 기록한다. 잔액만 높다고 바로 가격이나 수입을 바꾸지 않는다.

| 현재값으로 계산한 예 | 해석 범위 |
|---|---|
| 시작 100 − 영약 40 − 치유약 50 = 잔액 10 | 두 종류 1개씩 준비 가능 |
| 정기 수입만으로 90을 모으는 시간 90초 | 추가 보상·지출이 없다는 가정 |
| 10분 정기 수입 600 + 시작 100 = 700 | 구매·추가 수입이 없다는 가정 |
| 자연 마나 8/초로 40 회복에 5초 | 영약은 40을 2초 동안 자연 재생에 추가 |
| HP 1,000의 치유약 200 = 20%, HP 1,250은 16% | 실제 부족분·피격 중단 전 이론 최대 비율 |

## 7. 원작과의 구분

원작 조사에는 광물을 쓰는 능력치·궁극기 성장, 포션·카드 구매, 가스 보상표가 각각 있다. 가스가 정확히 어떤 상점 결제와 연결되는지, 품목별 가격·보유 한도는 **미확인** 항목이다.
저장소가 기록한 원작 체력포션 약 10초간 HP 2,000·중첩, 마나포션 3초 급회복은 Project E의 200/4초·40/2초와 별개의 근거다. 원작 값을 현 게임의 승인된 목표로 취급하지 않는다.
이번 정리는 원작 자료를 새로 검증하지 않았다. [원작 성장·경제](../../design/reverse-design/03-growth-and-economy.md), [원작 아이템·카드](../../design/reverse-design/04-units-siege-and-items.md)를 근거 등록과 함께 유지한다.

## 8. 후속 과제와 완료 기준

**후속 제안:** 가격·수입·보유량·회복 지속·피격 중단·성장 연동을 한 번에 바꾸지 않고 한 변수씩 비교한다. 신규 카드나 장비는 기존 2종으로 해결되지 않는 구매 목적이 관측될 때 정의한다.
신규 품목은 ID, 구매 위치·가격, 사용 대상·조건, 수치·지속·중단·중첩, 보유 한도·공용 대기, 사망·시야, UI·소리를 한 시트에 기록한다.
**미확인:** 8명별 구매·사용 빈도, 고레벨 고정 치유량의 가치, 복귀 비용과 합류 손실, 실제 사람 경기의 골드 체감은 밸런스 승인 전 관찰 대상이다.

| 이어받은 환경의 완료 기준 | 확인 사례 |
|---|---|
| 구매의 합산 한도·가격·기지 조건 일치 | 혼합 재고 2개, 가격 정확 경계, 양 팀 기지 경계, 죽음·종료 |
| 거절로 자원이 바뀌지 않음 | 부족 잔액·빈 재고·가득 찬 자원·대기 중 사용 |
| 회복과 중단 정확성 | 부분 틱, 최대치 절삭, 보호막 피해·소유 장치·병력·타워 구분 |
| 상태가 사망·부활을 통과 | 효과 종료, 재고 보존, 대기 감소·비초기화 |
| UI와 권한 일치 | P 구매→선택→D 사용, 한국어 사유, 보유량·대기·잔여 효과 |
| 경제 효과를 사람에게 확인 | 영웅별 유효 회복·추가 시전·복귀·지출을 같은 빌드로 기록 |

## 9. 기존 검증과 근거
