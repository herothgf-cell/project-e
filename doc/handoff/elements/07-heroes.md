# 07. 영웅 — 8명 선택 풀과 3대3 전투 패턴

정리일: **2026-11-19**. 대조 기준: `main`의 `e29c36296abf6d365353401dd0cbee411edc531d`, V9 `0.9.0`.
이 문서는 [기존 로스터 기획](../../design/content/07-roster-and-drafting.md)과 [개별 8명 시트](../../design/characters/README.md)를 보존하는 요약이다. 이번 작업에서는 게임 테스트·수동 플레이를 실행하지 않았다.

## 1. 의도와 상태

PC/Steam을 목표로 하는 Godot 프로젝트에서 짧은 스킬 순환과 조작, 라인 유지·합류·성장을 서로 다른 행동으로 경험하게 한다.
8명은 선택 가능한 영웅의 수다. 현재 경기는 **팀당 3명, 총 6명, 사람 1명과 봇 5명**이며 8대8이 아니다.
표현 방향은 **3등신 세미카툰 판타지**다. 큰 무기·실루엣·마법 재질·예고 형태로 역할을 읽히게 한다. [캐릭터 공통](../../design/characters/README.md).

| 상태 | 적용 범위 |
|---|---|
| **현재 코드 확인** | 로스터·시작값·기술명·효과·편성 조건을 현 소스와 대조 |
| **기존 검증 기록** | V8·V9의 저장된 실행 결과; 이번 재실행 결과가 아님 |
| **후속 제안** | 아래 패턴을 실제 참가자가 익히고 대응할 수 있는지 관찰 |
| **미확인** | 사람 조작의 난도·상성·승률·최종 밸런스 승인 |

**오린·테르·무아·세라·루메의 신규 수치는 V8 프로토타입 실험값이며 밸런스 미승인이다.** 코드에 존재하는 것과 최종 수치 채택은 다른 상태다.
아래 전투 패턴·위험·대응은 현 규칙에서 도출한 플레이 설명이다. 실제 유불리 통계나 추천 승리 조합으로 제시하지 않는다.

## 4. 바스 — 진입 뒤 공격을 이어 버티기

- **현재 코드 확인 / 패시브:** Q·E·R이 보이는 적 영웅에게 유효 피해를 주면 시전당 룬 1, 최대 2, 마지막 획득부터 6초. 2중첩에서 영웅 평타 적중 시 소비하고 `80+0.25P` 보호막 2초.
- **Q/W:** Q는 3.2m·80도, `80+0.55P`, 20% 둔화 0.7초. W는 3m 안 반경 2.2m 아군 영웅에 `100+0.35P` 보호막 1.5초.
- **E/R:** E는 최대 4.2m, 첫 영웅 앞 정지; 적 접촉 `45+0.40P`, 최대 0.8m·0.12초 밀기. R은 길이 7m·폭 2.8m, 예고 0.65초, `150+0.85P`, 속박 0.65초.
- **패턴·위험·대응:** E→Q로 룬을 준비하고 평타로 방어를 얻는다. 진입에 E를 쓰면 재사용까지 탈출 수단이 제한되며 아군도 돌진을 막는다. 상대는 경로 옆과 R 띠 측면으로 피하고 평타 거리 밖에서 재교전한다.
- **개별 상세:** [바스 시트](../../design/characters/01-bas.md). E 접촉만으로 R 적중이 보장되지 않으며 룬은 병력·셀·구조물로 충전되지 않는다.

## 5. 리오 — 출발·귀환을 따로 맞히기

- **현재 코드 확인 / 패시브:** 동일 Q의 왕복이 두 적중 순간 모두 보이는 같은 적 영웅에게 맞으면 마나 8, 원반당 1회.
- **Q/W:** Q 출발 최대 8m·`70+0.45P`, 귀환 `50+0.35P`; 0.2초 선회, 수명 2.2초, 소유자당 1개. W는 5m 안 반경 1.2m에 `40+0.25P`·20% 둔화 0.6초와 닻 2초.
- **E/R:** E는 최대 3.2m 이동 뒤 1.5초 안 다음 평타에 `40+0.25P` 추가. R은 조준 2~7m 삼각형의 폭 0.8m 테두리만 `140+0.80P`, 30% 둔화 1초; 중앙은 안전하다.
- **패턴·위험·대응:** Q 비행 중 W 닻이나 E 위치로 귀환 각을 만든다. 귀환 시작 때 원반에서 13m 이내 닻을 소비해 목적지를 고정하며 이후 따라 움직이지 않는다. 상대는 귀환선을 다시 피하고 벽으로 궤도를 끊는다.
- **개별 상세:** [리오 시트](../../design/characters/02-rio.md). 소유자 사망은 Q 원반을 없애며, 강화 평타는 정상 발사 때 소비하므로 이후 벽에 막혀도 환급되지 않는다.

## 6. 네마 — 파괴 가능한 연결을 유지하기

- **현재 코드 확인 / 패시브:** 연결에 새로 들어온 아군 영웅에 `60+0.20P` 보호막 1.2초; 같은 대상 재발동은 4초 뒤 재진입 필요.
- **Q/W:** Q는 사거리 6m, 반경 1.25m에 `65+0.35P`, HP 160·수명 8초 정령목 설치, 최대 2그루. W는 1그루 반경 1.5m 또는 두 그루 연결 폭 1.4m에 `75+0.45P`, 25% 둔화 0.9초.
- **E/R:** E는 자신과 전방 6m·70도 아군에 `100+0.40P` 보호막 1.8초, 범위·직선 시야 안 자기 정령목 HP +50. R은 연결 폭 2.2m에 `120+0.65P`, 속박 0.6초 후 참여 정령목 2개 소비.
- **패턴·위험·대응:** Q 두 번으로 길목을 준비하고 W·E를 반복한 뒤 R로 소모한다. 연결 길이는 1~8m와 직선 시야를 요구하며 W/R은 연결 최근접점에서 8m 이내여야 한다. 상대는 정령목 파괴나 연결 바깥 교전으로 준비를 끊는다.
- **개별 상세:** [네마 시트](../../design/characters/03-nema.md). 세 번째 정령목은 오래된 것을 지우며 W/R 선딜 중 참여 정령목이 사라지면 취소된다. R 정상 발동은 빗맞혀도 두 그루를 소비한다.

## 7. 오린 — 준비 파동과 강화 사격 (V8 실험값)

- **현재 코드 확인 / 패시브:** Q 정상 발동 뒤 3초 안 다음 평타에 `30+0.20P` 추가 1회. W 준비와 평타 강화는 별도 상태다.
- **Q/W:** Q는 기본 길이 8m·폭 0.7m, `70+0.45P`. W는 3.5m·90도 `35+0.20P`, 25% 둔화 0.8초; 정상 발동 시 5초 준비를 얻어 다음 Q가 5m·폭 2.4m로 바뀐다.
- **E/R:** E는 보행 속도 +35% 2초. R은 길이 8m·폭 1.6m에 각 `85+0.40P` 두 번, 첫 예고 0.6초·타격 간격 0.45초.
- **패턴·위험·대응:** W 준비→짧고 넓은 Q→강화 평타 후 E로 거리 조절. 준비 Q는 긴 사거리를 포기하므로 상대는 5m 밖이나 얇은 Q의 측면을 선택하고 R 둘째 파동 전 이탈한다.
- **개별 상세:** [오린 시트](../../design/characters/04-orin.md). W는 빗맞혀도 준비를 주며 Q 형상은 승인 시 고정한다. E는 순간 이동이 아니며 속박 중 이동은 불가능하다.

## 8. 테르 — 후방 보호와 출발점 반격 (V8 실험값)

- **현재 코드 확인 / 패시브:** W로 다른 아군 영웅을 보호하면 자신에게 `50+0.15P` 보호막 2초, 아군 수와 무관하게 1회.
- **Q/W:** Q는 3m·90도 `65+0.35P`, 25% 둔화 0.8초. W는 자기 자신과 조준 반대쪽 5m·100도 아군에 `110+0.30P` 보호막 2초.
- **E/R:** E는 조준 방향 최대 3m 이동; 정상 정지 0.35초 뒤 출발점에서 이동 반대 방향 3.5m·100도에 `65+0.30P`. R은 6m·100도, 예고 0.8초, `120+0.55P`, 속박 0.8초.
- **패턴·위험·대응:** 적을 향해 W를 조준해 뒤의 아군을 감싸고 후퇴 E로 추격로를 반격한다. 상대는 후방 부채 밖 측면을 압박하고 E 출발점 경고·긴 R 예고를 벗어난다.
- **개별 상세:** [테르 시트](../../design/characters/05-tere.md). E 접촉 자체에는 피해가 없고 이동 중 제어 취소는 반격을 예약하지 않는다. 정상 정지 후 이미 예약된 반격은 후속 기절에 유지되지만 소유자 사망에 취소된다.

## 9. 무아 — 두 지원 구역을 교대하기 (V8 실험값)

- **현재 코드 확인 / 패시브:** 활성 구역 새 진입 아군에 `35+0.15P` 보호막 1.2초, 소유자·대상별 4초 간격. 계속 서 있으면 반복 발동하지 않는다.
- **Q/W:** Q는 6m 안 반경 2m에 `55+0.30P`, 수명 8초·최대 2개 구역, 최신 활성. W는 다른 구역을 활성화하고 그 순간 구역 안 아군에 보행 +25% 2초; 하나면 같은 구역 유지.
- **E/R:** E는 자신 주변 4m에 `80+0.30P` 보호막 1.8초, 대상이 활성 구역 안이면 `40+0.15P` 추가. R은 활성 구역을 반경 3.5m로 예고 0.65초 후 `130+0.60P`·속박 0.6초, 해당 구역 소비.
- **패턴·위험·대응:** Q로 두 후보 위치→W로 다음 합류 위치 활성→E 보호→R 소모 후 남은 구역 사용. 상대는 비활성 쪽으로 교전을 옮기거나 구역 만료를 기다린다.
- **개별 상세:** [무아 시트](../../design/characters/06-mua.md). 구역은 HP·시야·보상 없는 바닥 상태여서 네마처럼 파괴하지 못한다. W/R은 지정 구역 중심 8m·직선 시야가 필요하며 선딜 중 구역 만료는 취소다.

## 10. 세라 — 표식 소비 수단을 선택하기 (V8 실험값)

- **현재 코드 확인 / 패시브:** 자기 표식은 보이는 적 영웅별 최대 2중첩·5초. 2중첩 영웅 평타는 `55+0.30P` 추가 후 소비한다.
- **Q/W:** Q는 2.8m·60도 `65+0.40P`, 유효 피해가 난 보이는 적 영웅에 표식 1. W는 자기 `90+0.30P` 보호막 1.5초.
- **E/R:** E는 최대 4m 돌진, 첫 영웅 앞 정지; 적 접촉 `50+0.30P`와 가시 조건의 표식 1. R은 3.5m·55도 `100+0.50P`에 보이는 대상의 자기 표식당 `35+0.15P` 추가 후 유효 피해 시 소비.
- **패턴·위험·대응:** E·Q로 두 표식을 만든 뒤 평타 또는 R로 회수하고 W로 반격을 버틴다. 기본 사거리가 짧고 진입 E가 막힐 수 있어 상대는 경로를 통제하고 5초간 거리를 벌리며 좁은 R 측면을 피한다.
- **개별 상세:** [세라 시트](../../design/characters/07-sera.md). 숨은 대상은 표식 추가·추가 피해·소비 조건을 충족하지 않는다. 다른 세라의 표식을 소비하지 않으며 사망·만료에 정리한다.

## 11. 루메 — 세 번 준비 후 포격 강화 (V8 실험값)

- **현재 코드 확인 / 패시브:** Q·W·R 정상 발동 3회 뒤 다음 공격기의 모든 단계 피해 +25%, 이후 0으로 순환. 빗맞힘은 횟수에 포함하고 E는 쌓거나 소비하지 않는다.
- **Q/W:** Q는 7m 안 반경 2m, 예고 0.55초 후 `80+0.45P`. W는 자신 주변 3m에 `35+0.20P`, 30% 둔화 0.9초.
- **E/R:** E는 자기 `80+0.25P` 보호막 1.8초와 보행 +25% 2초. R은 8m 안 반경 2.5m, 첫 예고 0.65초 후 각 `70+0.30P` 세 번; 추가 타격은 +0.45/+0.90초.
- **패턴·위험·대응:** 이동 경로에 Q 예고, 접근한 적에게 W, E로 새 위치를 잡고 준비된 Q/R을 사용한다. 상대는 원형 예고를 순서대로 벗어나고 가속·보호 종료 뒤 접근한다.
- **개별 상세:** [루메 시트](../../design/characters/08-lume.md). Q는 별도 비행 병 투사체가 아닌 고정 지면 타격이다. 예약 포격은 후속 기절에 계속되지만 소유자 사망에 취소된다.

## 12. 공통 흐름·예외와 UX

**현재 코드 확인:** QWER로 조준 선택→좌클릭 확정→권한 검사→비용·재사용 시작→예고·발동·후딜 흐름이다. R은 레벨 3과 성장 1포인트가 필요하다. 승인 후 선딜 취소에는 비용·재사용 환급이 없다.
바스·리오·테르·세라 E는 이동기다. 속박 중 승인되지 않고 벽·첫 아군/적 영웅 앞에서 멈춘다. 속박·기절·밀치기의 하드 제어는 1회 최대 1초·최근 3초 합계 1.5초 규칙을 따른다. 둔화는 별도 상태이며 이 시간 예산에 합산하지 않는다.
다회 타격은 단계별 대상 1회 적중이다. 같은 출처 보호막은 높은 잔량과 새 만료를 유지하고 다른 출처는 함께 존재한다. 시전자 사망 뒤에도 이미 아군에게 준 보호·가속은 수명까지 유지될 수 있다.
기술명·설명·아이콘은 선택 화면·HUD·F7에 연결된다. HUD는 바스 룬, 리오 원반/닻, 네마 연결, 오린 준비, 테르 보호막, 무아 구역, 세라 보이는 표식, 루메 잔열을 표시한다. [HUD](../../../game/project-e/scripts/presentation/battle_hud.gd).
**후속 제안:** 준비 신호·활성/비활성·반격 출발점·귀환선·지연 타격이 장식보다 먼저 읽히는지 확인한다. 시각적 가독성과 실제 회피 가능성을 같은 판정 장면에서 평가한다.

## 13. 현재 자동 편성과 해석 경계

| 플레이어 선택 | 아군 출전 풀 | 상대 출전 풀 |
|---|---|---|
| 바스 / 리오 / 네마 | 바스·리오·네마 | 바스·리오·네마 |
| 오린 | 오린·바스·네마 | 바스·세라·무아 |
| 테르 | 테르·바스·네마 | 바스·루메·오린 |
| 무아 | 무아·바스·네마 | 바스·테르·루메 |
| 세라 | 세라·바스·네마 | 바스·오린·테르 |
| 루메 | 루메·바스·네마 | 바스·무아·세라 |

선택 영웅은 아군 중앙, 아군 봇은 나머지 두 라인, 상대는 배열 순서의 세 라인에 배치된다. 현재는 고정 시험 편성으로 자유 드래프트·밴·매칭을 구현한 상태가 아니다. [편성 권한](../../../game/project-e/scripts/battle/hero_roster.gd).
기존 V8 상세 시트의 서쪽/동쪽·북/중앙/남 표기는 당시 방향이다. V9 화면은 상하 진영과 좌·중·우 라인을 사용한다. 영웅 구성은 유지하며 이전 표현을 현재 화면 방향으로 복사하지 않는다. [V9 변경](../../design/30-v9-vertical-siege.md).

## 14. 후속 과제·완료 기준·검증 근거

**후속 아트 제안:** [2026-11-19 D 혼합형 8영웅 아트 바이블](../../design/31-subculture-fantasy-hero-art-direction.md)은 이 8명의 ID·역할·QWER 판정을 유지한 채 외형·실루엣·전용 텍스처를 개선하는 계획이다. 인게임 3~3.5등신과 2D 키아트 6~7등신을 분리하며, 아래 전투 수치가 변경되거나 새 클래스 8종으로 대체된 것으로 해석하지 않는다.

**후속 제안:** 핵심 연계 1회와 상대 대응 1회를 영웅마다 사람 조작으로 수행한다. 진영을 교환해 마나 부족 시간·미사용 기술·유효 보호·처치·공성·합류 기여를 기록한다. 제안 조합과 56개 가능한 3인 조합을 현재 선택 가능한 자동 편성으로 혼동하지 않는다.
**미확인:** 고정 봇 경기 결과로 영웅 승률·정답 조합·초심자 난도·최종 수치 승인을 내릴 수 없다. 원작 영웅 수치와 이름을 이 8명의 원형으로 단정하지 않는다. [원작 플레이 패턴 조사](../../design/reverse-design/05-heroes-and-play-patterns.md).

| 이어받은 환경의 완료 기준 | 근거·방법 |
|---|---|
| 8명 선택·초기값·32개 액티브·8개 패시브 일치 | 로스터·명령·실제 상태 변화를 대조 |
| 소유 상태·시간·사망 정리 일치 | 룬·원반·정령목·구역·표식·잔열·예약 타격 경계 검사 |
| 패턴별 상대 대응 성립 | 경고 회피·벽·거리·설치물 파괴·제어 사례 기록 |
| UI·F7·기술 체험이 같은 규칙을 사용 | 이름·아이콘·선행 조건·피해·보호·편성 대조 |
| 사람 조작의 학습·가독성 확인 | 영웅별 연계와 대응 과제·참가자 피드백 기록 |

**기존 검증 기록:** [2026-11-09 V8](../../design/verification/2026-11-09-v8-verification.md)은 신규 기술 259개, 편성·시작 48개, 선택·모델·표현·F7 425개 검사와 전체 회귀를 기록한다. [2026-11-10 V9](../../design/verification/2026-11-10-v9-verification.md)은 전체 38개 스위트·6,997개 검사·실패 0을 기록하며 기존 영웅 수치를 유지했다. 모두 과거 기록이고 이번 재실행 결과가 아니다.
핵심 소스는 [기존 3명·공용 기술](../../../game/project-e/scripts/battle/hero_abilities.gd), [신규 5명 효과](../../../game/project-e/scripts/battle/expanded_abilities.gd), [전투 권한](../../../game/project-e/scripts/battle/battle_rules.gd), [상태·기본 공격](../../../game/project-e/scripts/battle/battle_state.gd)다. 후속 회귀 경로는 [V8 기술 검사](../../../game/project-e/tests/test_hero_abilities_v8.gd)와 [전투 규칙 검사](../../../game/project-e/tests/test_battle_rules.gd)이며, 이번 작업은 이들을 실행하지 않았다.
