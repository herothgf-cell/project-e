# 03. 전투 판정·상태·명령 인수 기획서

기준은 **V9 0.9.0**, 정리 대상 커밋은 `e29c36296abf6d365353401dd0cbee411edc531d`다. 작성일은 2026-11-19다.

**현재 코드 확인**은 소스에서 읽은 구현, **기존 검증 기록**은 이전 실행의 보존 결과, **후속 제안**은 검토할 작업, **미확인**은 새 환경이나 사람 플레이로 확인하지 않은 사항이다. 이번에 게임과 회귀 검사를 실행하지 않았다.

## 목표와 플레이 흐름

명령 승인 → 선딜과 경고 → 실제 효과 → 후딜 → 다음 명령의 흐름을 예측할 수 있게 한다. 영웅마다 형태·비용·선행 상태·대응법은 달라도, 사람·봇·기본 공격·투사체·예약 타격은 같은 피해와 상태 판정 함수를 사용한다.

공통 전투를 바꿀 때는 영웅별 수치만 비교하지 않는다. 비용이 소비되는 시점, 이미 승인된 위력, 시야가 사라진 표적, 소유자 사망과 경기 종료까지 계약에 포함한다. 영웅별 QWER 수치는 [캐릭터 원본](../../design/characters/README.md)을 별도로 참조한다.

## 현재 코드 확인: 명령 승인 경계

| 경계 | 현재 처리 |
|---|---|
| `command_cast()` 진입 | 진행 중 경기, 살아 있는 영웅, 유효한 ID 확인 |
| `get_cast_preview()` | 기술별 `preview()`로 슬롯·유한 좌표·형상·거리·선행 상태 등을 먼저 검사 |
| 공통 자격 | 생존·경기, 기절, 이동 기술의 속박, R 해금, 쿨다운, 마나 검사 |
| 행동 중 명령 | `windup`·`dash`·`recovery`·`basic` 중 기술은 대기 명령으로 저장 |
| 실제 시전 승인 | 마나 차감, 쿨다운 시작, 현재 위력과 형상 저장, 경고 생성 |
| 대기 명령 실행 | 원래 명령 함수를 다시 호출해 실행 시점에 재검사 |
| 취소 | 이미 승인된 시전이 제어·사망으로 취소돼도 비용을 환불하지 않음 |

거절된 명령은 마나·쿨다운을 소비하지 않는다. 대기 명령 저장 자체도 아직 시전 비용 지불이 아니다. 범위 밖 지점 시전을 자동 접근 시전으로 바꾸지 않는다. 기존 상세 기획의 승인 순서는 개념 설명이며 오류 메시지 우선순위까지 고정한 호출 순서는 아니다. [명령 소스](../../../game/project-e/scripts/battle/battle_state.gd) · [기술 미리보기](../../../game/project-e/scripts/battle/hero_abilities.gd)

## 현재 코드 확인: 기본 공격

| 항목 | 값·규칙 |
|---|---|
| 영웅 원피해 | `60 + 0.30 × 승인 시점 위력` |
| 일반 시작 예 | 위력 100 → 원피해 90 |
| 영웅 공격 간격 | 시작 승인 시점부터 1초 |
| 마나 | 소비 없음 |
| 근접 | 바스·테르·세라 |
| 원거리 | 리오·네마·오린·무아·루메 |
| 일반 원거리 탄 | 속도 20 m/s, 수명 최대 3초 |
| 사거리 판정 | 공격자 중심과 대상 중심 거리 ≤ 공격 사거리 + 대상 반경 |
| 직접 지정 대상 | 현재 보이는 적 영웅·병력·셀·정령목·잠금 해제 구조물 |

근접은 선딜 끝에 생존·시야·사거리·벽을 다시 확인한다. 원거리는 실제 탄을 만들고 매 틱 표적 위치를 추적한다. 이미 발사한 기본 탄은 표적 사망·소멸, 벽, 수명으로 종료하며 시야 상실만으로 일괄 제거하지 않는다.

일반 공격 선딜을 취소해도 `attack_left`를 초기화하지 않는다. 강화 기본 공격의 부여·소비는 각 영웅 상태로 처리하며 공통 공격 간격을 새로 제공하지 않는다. 화면에 숨은 탄·적중을 공개하는지는 별도 시야 표시 계약이다. [기본 공격 소스](../../../game/project-e/scripts/battle/battle_state.gd)

## 현재 코드 확인: 피해 계산의 단일 권한

| 순서 | 계산 또는 차단 |
|---|---|
| 대상 자격 | 종료된 경기, 잘못된 ID·피해, 사망·아군·잠금·부활 보호 대상은 피해 0 |
| 중복 | 시전 ID·단계·대상 조합은 한 번만 처리 |
| 방어 | `raw × 100 / (100 + max(0, armor))` |
| 구조물 배율 | 영웅 또는 정령목 출처면 ×0.5 |
| 동반 병력 부재 | 공격 팀 살아 있는 병력이 구조물 중심 12 m 안에 없으면 추가 ×0.3 |
| 일반 병력 유보 | 근접·원거리 병력의 피해량을 `보호막 + max(0, HP−1)` 이하로 제한 |
| 흡수·HP | 보호막을 먼저 소비하고 남은 피해를 HP에 적용; HP 최저 0 |
| 후속 처리 | 실제 유효 피해, 소유자, 보상·어그로·피드백·사망 처리 |

방어 20이면 원피해의 약 83.33%를 받는다. 일반 시작 기본 공격 90을 방어 0 구조물에 가하면, 병력이 있을 때 45, 없을 때 13.5가 된다. 이는 식을 적용한 예시이며 이번 실행 측정값이 아니다.

일반 병력의 1 HP 유보는 피해 대상 종류를 병력으로 한정하지 않는다. 영웅·구조물에 대해서도 같은 소스 조건을 적용한다. 공성 병력에는 이 제한이 없다. 원작 수치와 동일하다고 단정하지 않는다. [피해 권한 소스](../../../game/project-e/scripts/battle/battle_rules.gd)

## 현재 코드 확인: 보호막·회복·제어

| 상태 | 현재 계약 |
|---|---|
| 같은 출처 보호막 | 기존 잔량과 새 양의 큰 값으로 갱신하고 만료 갱신 |
| 다른 출처 보호막 | 함께 보유 |
| 보호막 소비 | 만료가 빠른 순서, 같은 만료면 생성 순서 |
| HP·마나 회복 | 최대치를 넘지 않음; 내부 소수 유지 |
| 기절 | 이동·새 공격·시전 제한, 진행 중 시전 취소 |
| 속박 | 보행·이동 기술 제한; 제자리 공격·비이동 기술 가능 |
| 감속 | 가장 강한 감속 사용, 감속률 최대 60% |
| 넉백 | 강제 이동·행동 제약; 합법 지형 경계에서 중단 |
| 시간제 가속 | 기본 이동속도 투자와 별도 만료 상태 |

기절·속박·넉백의 단일 적용은 최대 1초다. 최근 3초의 제어 구간 합집합을 계산해 신규 연장에 1.5초 예산을 적용한다. 겹친 시간을 중복 합산하지 않으며 감속은 이 예산과 별도다. 속박은 이동기 선딜과 이미 진행 중인 돌진도 취소 조건에 포함한다.

숲빛 치유약 중단, 아이템 공용 재사용과 부분 틱 회복은 소모품 권한에서 처리한다. 이 문서의 피해 계산을 우회해 UI에서 회복·피해를 직접 적용하면 안 된다. [제어·보호막](../../../game/project-e/scripts/battle/battle_rules.gd) · [소모품 처리](../../../game/project-e/scripts/battle/battle_consumables.gd)

## 현재 코드 확인: 공격 이동과 일반 추격의 차이

`A → 지면 좌클릭`은 최종 목적지를 보존하고 주변 8 m의 보이는 영웅·병력·열린 구조물을 탐색한다. 가장 가까운 대상을 선택하고 거리 동률은 ID로 결정한다. 셀·정령목은 직접 지정해야 한다.

공격 이동은 획득 위치로부터 8 m 추격 한도, 시야 상실 시 표적 해제, 목적지 도착 후 새 추격 금지를 적용한다. 일반 지정 공격과 병력 AI에는 마지막 관측 이후 1초 유지 규칙이 있으므로 모든 추격을 같은 규칙으로 서술하지 않는다.

목적지에 도착한 공격 이동은 기본 사거리와 벽 조건을 충족한 적만 공격한다. 플레이어 기술은 별도 명령으로 실행되며 공격 이동이 자동으로 QWER을 사용하지 않는다. [공격 이동 소스](../../../game/project-e/scripts/battle/battle_state.gd)

## 현재 코드 확인: 다회 타격과 소유자 수명

- 왕복 혜성은 출발·귀환 단계를 구분한다. 소유자 사망 시 종료한다.
- 예약된 다회 파동·포격·반격은 타격 단계마다 식별하고 소유자 생존을 확인한다.
- 물감 구역·월영 표식·시간제 준비·예약 타격은 `clear_owner()`와 각 만료 규칙을 따른다.
- 사망한 영웅의 일반 기본 탄과 다른 아군에게 이미 부여한 보호막은 별도 수명 규칙을 따른다.
- 재시작은 투사체·예약 타격·적중 기록을 모두 새로 만든다.

경고·이펙트의 형상과 판정 형상은 같은 시전 정보를 사용한다. 시야 밖 피해가 내부에서 성립하더라도 적 위치·HP·표식·음향을 노출할 근거가 되는 것은 아니다. [기본 기술](../../../game/project-e/scripts/battle/hero_abilities.gd) · [추가 영웅 기술](../../../game/project-e/scripts/battle/expanded_abilities.gd)

## 기존 검증 기록과 미확인 범위

**기존 검증 기록:** 최종 V9 기록은 기존 전투·성장·시야·입력 회귀를 포함해 38개 스위트 6,997개 검사, 실패 0을 보고한다. V9는 미니언·영웅 기술·구조물 피해 수식을 조정한 패치가 아니다. [V9 검증 기록](../../design/verification/2026-11-10-v9-verification.md)

**미확인:** 8명 전체의 사람 교전 밸런스, 기술 겹침의 가독성, 대응 가능한 시간과 새 실행 환경의 입력 체감은 이 기록만으로 확정할 수 없다.

## 후속 제안: 열린 과제와 작업 완료 판정

입력 실패·신호 오해·실제 수치 문제를 분리한다. 보호막이 과하다는 피드백이면 출처별 양·지속·중첩·마나·재사용을 먼저 기록하고 한 번에 주요 변수 하나를 바꾼다. 빠른 처치 문제는 선딜과 대응 입력의 실제 타이밍까지 기록한다.

- [ ] 거절·대기·실제 시전·취소마다 비용과 쿨다운이 계약대로 변한다.
- [ ] 같은 단계 중복 피해는 막히고 서로 다른 예약 단계는 각각 처리된다.
- [ ] 같은 출처·다른 출처 보호막과 제어 구간 중첩을 구분해 확인한다.
- [ ] 이동기 선딜·돌진 중 속박, 벽·영웅 충돌, 시야 상실을 재현한다.
- [ ] 두 소유자가 같은 표식·구역 기술을 써도 상태가 섞이지 않는다.
- [ ] 사망·결과·재시작 후 남은 효과를 확인하고 숨은 정보가 표시되지 않는다.

이는 다음 변경의 완료 조건 제안이다. 수치 확정이나 이번 검사 통과 선언이 아니다.
