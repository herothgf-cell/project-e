# 제품 방향·사용자 요구·결정 이력

정리일 2026-11-19. 현재 구현 기준은 [V9 main e29c362](https://github.com/herothgf-cell/project-e/tree/e29c36296abf6d365353401dd0cbee411edc531d)다. 이 문서는 목표, 현재 채택한 규칙, 아직 정하지 않은 사항을 구분한다.

## 1. 만들려는 게임

참고작은 시티 오브 템페스트다. 보존하려는 경험은 짧은 기술 순환을 활용한 조작, 세 라인의 성장 기회, 빠른 합류, 경기 중 성장 투자, 병력과 함께 마무리하는 공성이다.

새 게임의 캐릭터, 세계관, 장비, 기술의 세부 조합, 맵 표현, UI와 소리는 독자적으로 만든다. 원작과의 비교는 행동과 선택의 구조를 확인하는 데 사용한다. 원작 자료에 없는 수치를 원작 실측값으로 채워 넣지 않는다.

현재 표현은 “아스트라 수로 전장”이며 밝은 판타지 수로·공방의 시각 방향을 사용한다. 공개 제품명, 상표·가격·출시일이 확정됐다는 의미는 아니다. [초기 제품 개요](../../docs/00-project-brief.md), [현재 아트](../design/content/09-art-and-audio.md)

## 3. 현재 채택되어 있는 구현 기준

| 항목 | V9 현재 기준 | 결정의 성격 |

| 영웅 수 | 바스·리오·네마·오린·테르·무아·세라·루메 | 선택 풀 8명 |

| 전장 | 아군 하단·적군 상단, 좌·중·우 세 라인 | 화면 기준; 내부 좌표는 별도 |

| 성장 자원 | XP, 성장 포인트, 골드의 역할 분리 | 경기 내 성장과 재보급 선택 |

| 공성 AI | 회복 후 기지 출발 시 열린 라인 최대 2명 합류 | V9 채택 정책 |
| 엔진 | Godot 4.7.2 Standard, GDScript, Compatibility | 엔진은 사용자 선택, 세부 구성은 구현 기준 |

세부 수치는 [요소별 문서](README.md#4-요소별-기획-바로가기)와 현행 코드에서 확인한다. 현재 채택과 영구 확정은 다르며 이후 플레이테스트에 따라 조정할 수 있다.

## 4. 목표·가설·미정 항목

2026-11-19 저장소에 추가된 [D 혼합형 캐릭터 아트 디렉션](../design/31-subculture-fantasy-hero-art-direction.md)은 **인게임 3.0~3.5등신 SD / 선택·상세·키아트 6~7등신**의 이중 표현을 제안한다. 기존 8영웅 ID·스킬·판정·세로 전장을 유지하며 외형·전용 텍스처·모션을 개선하는 계획이다. 현재 런타임 반영이나 사용자의 최종 아트 승인으로 해석하지 않는다.

| 항목 | 상태 | 다음 결정에 필요한 것 |
|---|---|---|
| 한 판 12~18분 | 기존 목표 가설 | 사람 경기, 조합·진영별 표본, 빠른 종료의 만족도 |
| 8영웅의 최종 수치와 조합 균형 | 미확인 | 기술 학습·상대 대응·전체 경기 관측 |
| 일러스트 수준의 실제 모델·맵 완성도 | 사용자 요구, 수용 미확인 | 동일 구도의 실제 화면·동작 비교 |
| 온라인 3대3 | 장기 개발 | 연결·권한·지연·재접속 검증 |
| Steam 연동과 공개 출시 | 장기 개발 | 실제 연동 빌드, 배포·운영 준비 |
| 출시 로스터 수 | 미정 | 현재 8명 프로토타입의 검증 결과 |
| 공개 이름·가격·사업모델·출시일 | 미정 | 제품과 제작·운영 조건 |
| 게임패드·다른 OS·Steam Deck | 미정 | 해당 환경에서의 입력·화면·성능 검증 |

## 5. 이전 기준을 그대로 쓰면 안 되는 경우

초기 문서의 3명 프로토타입·6명 출시 후보, 가로 맵, 예전 조작키는 당시 계획이다. 현재 8명 선택 풀과 V9 세로 전장을 덮어쓰는 근거로 쓰지 않는다. Unity 기술 문서도 초기 검토 이력이며 현재 엔진 지시가 아니다.

원작 영상의 143개 정지 표본 분석은 저장소의 과거 조사 기록이다. 연속 고해상도 전체 영상 검증이나 원작 평균 경기 시간 실측을 뜻하지 않는다. [V9 근거](../design/30-v9-vertical-siege.md), [맵·미니언 감사](../design/29-cot-map-minion-siege-review.md)
